Argumento con nombre
Un dato que se pasa diciendo qué es. epochs=25: «el número de épocas es 25». Si no lo pones, se usa el valor por defecto.
Lista [ ] y tupla ( )

Sangría
Los espacios al principio de una línea. Dicen qué líneas van dentro de un def, un for o un if.
def y return
def escribe una receta con nombre (una función); return dice qué devuelve. No hace nada hasta que la llamas. s=1 en la cabecera es un valor por defecto.

En la cabecera de un def, *capas recoge «todas las que me den». Delante de una lista, *lista la vacía en su sitio, elemento a elemento.

Un bucle: repite las líneas sangradas una vez por cada elemento. Si en cada vuelta salen varias cosas, se reparten en varios nombres: for n, k, s, d, pad in casos:. El nombre _ significa «no me importa cuál».

Índices y cortes [ ]
Se cuenta desde 0. [0] el primero; [-1] el último; [:150] los 150 primeros; [1:] todos menos el primero; [::-1] al revés; [..., None] añade un eje al final.
Operaciones
* multiplica, / divide, // divide quedándose con la parte entera (25 // 2 = 12), % da el resto (7 % 2 = 1), += suma a lo que ya había. 1e-3 es 0,001.
True, False y None
Verdadero, falso y «nada». En una forma, None significa «las imágenes que sean».
isinstance, len y float
«¿Es esta cosa de este tipo?», «¿cuántos elementos tiene?» y «conviértelo en número decimal».

Paso 1 · La fórmula del tamaño con dilatación, comprobada con Conv2D (fragmento 1)

Para qué sirve Comprobar, caso por caso, que la fórmula del tamaño de salida (con salto, marco y dilatación) da lo mismo que Conv2D, y que dilatar no añade parámetros.

def tam_salida(n, k, s=1, d=1, padding="valid"):
    if padding == "same":
        return math.ceil(n / s)
    k_ef = k + (k - 1) * (d - 1)          # tamaño efectivo del filtro dilatado
    return (n - k_ef) // s + 1

def bloque(x, filtros, stride=1, residual=True):
    atajo = x
    x = layers.Conv2D(filtros, 3, strides=stride, padding="same", use_bias=False)(x)

keras.backend.clear_session()
def bloque(x, filtros, stride=1, residual=True):
    atajo = x
    x = layers.Conv2D(filtros, 3, strides=stride, padding="same", use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.Activation("relu")(x)
    x = layers.Conv2D(filtros, 3, padding="same", use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    if not residual:
        return layers.Activation("relu")(x)
    if stride != 1 or atajo.shape[-1] != filtros:
        atajo = layers.Conv2D(filtros, 1, strides=stride, use_bias=False)(atajo)
        atajo = layers.BatchNormalization()(atajo)
    x = layers.Add()([x, atajo])
    return layers.Activation("relu")(x)

def mini_resnet(residual=True):
    entrada = keras.Input(shape=(8, 8, 1))
    x = layers.Conv2D(8, 3, padding="same", activation="relu")(entrada)
    x = bloque(x, 8, residual=residual)
    x = bloque(x, 16, stride=2, residual=residual)
    x = layers.GlobalAveragePooling2D()(x)
    salida = layers.Dense(10, activation="softmax")(x)
    return keras.Model(entrada, salida, name="resnet" if residual else "plana")

def unos(capa, n):
    """Aplica la capa a una entrada de unos n x n con kernel de unos: cuenta cuántos 'sellos' caen en cada píxel."""

Fragmento 7 · Gradiente por capa: red plana frente a red con atajos

Para qué sirve Medir con tf.GradientTape cuánto gradiente llega a cada capa en una red de 22 capas con pesos, con y sin atajos. Es la demostración numérica de por qué \(y=x+F(x)\) permite entrenar redes profundas.

import numpy as np
import keras
import tensorflow as tf
from keras import layers

def red(profundidad, residual):
    entrada = keras.Input(shape=(16,))
    x = layers.Dense(16, activation="sigmoid")(entrada)
    for _ in range(profundidad):
        h = layers.Dense(16, activation="sigmoid")(x)
        x = layers.Add()([x, h]) if residual else h
    return keras.Model(entrada, layers.Dense(1)(x))

rng = np.random.default_rng(0)

y = rng.normal(size=(64, 1)).astype("float32")

    keras.utils.set_random_seed(1)
    modelo = red(20, residual)
    with tf.GradientTape() as cinta:
        perdida = tf.reduce_mean(keras.losses.mean_squared_error(y, modelo(X)))
    grads = cinta.gradient(perdida, modelo.trainable_variables)
    normas = [float(tf.norm(g)) for g, v in zip(grads, modelo.trainable_variables)
              if "kernel" in v.path]
    nombre = "con atajos" if residual else "plana     "
    print(nombre, " ".join(f"capa{i + 1:2d}={normas[i]:.1e}" for i in (0, 4, 9, 14, 19)),
          f"| primera/última = {normas[0] / normas[19]:.1e}")

Fragmento 22 · Mini U-Net: segmentación píxel a píxel con transpuestas y atajos

Para qué sirve Construir una U-Net en miniatura (bajar con pooling, subir con Conv2DTranspose y recuperar detalle con atajos de Concatenate) y entrenarla para decir, píxel a píxel, dónde hay un objeto en imágenes con ruido.

import numpy as np
import keras
from keras import layers

def fabricar(n, rng, lado=24):
    """n imágenes con ruido y un rectángulo o un círculo algo más claro; la máscara marca dónde está."""
    yy, xx = np.mgrid[0:lado, 0:lado]
    imgs = rng.normal(0.35, 0.15, (n, lado, lado, 1)).astype("float32")
    masks = np.zeros((n, lado, lado, 1), dtype="float32")
    for i in range(n):
        cy, cx = rng.integers(6, lado - 6, 2)
        r = rng.integers(3, 6)
        if rng.random() < 0.5:
            m = (abs(yy - cy) <= r) & (abs(xx - cx) <= r + 1)
        else:
            m = (yy - cy) ** 2 + (xx - cx) ** 2 <= r * r
        imgs[i, m, 0] += 0.35
        masks[i, m, 0] = 1.0
    return imgs, masks
