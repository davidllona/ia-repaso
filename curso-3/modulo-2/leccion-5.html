Cargar datos de verdad: carpetas, tf.data y tf.image

En todos los ejemplos hasta ahora los datos venían ya cargados en un array de NumPy. Pero los pósters de tu catálogo están en una carpeta del disco, en miles de archivos. ¿Cómo los convierte Keras en lotes para entrenar?

Una carpeta por clase

El formato estándar es una carpeta por cada clase; el nombre de la carpeta es la etiqueta. En el catálogo de una plataforma tendrías comedia/, terror/, animacion/…; en el fragmento usamos formas geométricas para no necesitar descargar nada:

fotos/
├── circulo/
│   ├── 0.png
│   └── 1.png
├── cruz/
└── cuadrado/

keras.utils.image_dataset_from_directory lee esa estructura y devuelve un tf.data.Dataset de lotes. Lo que debes saber (comprobado en el fragmento 9):

  • Las clases salen en orden alfabético: ['circulo', 'cruz', 'cuadrado'] (aunque en el disco la cruz estuviera creada después), y su posición es la etiqueta 0, 1, 2.
  • Las imágenes llegan como float32 con valores 0-255 (no 0-1: habrá que escalar), con forma (lote, alto, ancho, canales), todas redimensionadas a image_size.
  • Las etiquetas son enteros int32 por defecto (label_mode="int"), que combinan con sparse_categorical_crossentropy. Con label_mode="categorical" serían one-hot.
  • Para separar validación: validation_split=0.25 con subset="training" en una llamada y subset="validation" en otra, con la misma seed, o se solaparían.

tf.data: el tubo de datos

Un tf.data.Dataset es una cadena de transformaciones aplicadas a los lotes mientras se entrena, de modo que la GPU no espera al disco. Dos que casi siempre usarás: .map(f) aplica una función a cada lote (aquí, la augmentation) y .prefetch(tf.data.AUTOTUNE) prepara el siguiente lote mientras el modelo trabaja con el actual. Nota que la augmentation se aplica solo al conjunto de entrenamiento: nunca al de validación.

La caja de herramientas tf.image

Cuando necesitas más control que las capas, tf.image tiene las operaciones elementales: convert_image_dtype (de enteros 0-255 a decimales 0-1), resize, flip_left_right, rot90, central_crop, adjust_brightness, adjust_contrast, rgb_to_grayscale y per_image_standardization. El fragmento 10 comprueba cada una con una cuenta a mano (el 15 pasa a \( 15/255=0{,}0588 \); el gris de un píxel es \( 0{,}299R+0{,}587G+0{,}114B \); la estandarización deja media 0 y desviación 1). Hay también versiones random_… y stateless_random_…: estas últimas reciben una semilla y dan siempre el mismo resultado, lo que importa en segmentación, donde la misma transformación debe aplicarse a la imagen y a su máscara. Para leer una imagen del disco a bajo nivel existen tf.io.read_file y tf.io.decode_image (aquí no los ejecutamos: image_dataset_from_directory ya lo hace por ti).

9 · De una carpeta de imágenes a un Dataset: la forma moderna y la antigua

Para qué sirve Crear una carpeta con imágenes sintéticas (una subcarpeta por clase), leerla con image_dataset_from_directory (Keras 3), aplicar augmentation dentro del pipeline y comparar con el viejo ImageDataGenerator, que ya no está donde lo buscaban los cursos antiguos.

import os
import tempfile
import numpy as np
import keras
import tensorflow as tf
from keras import layers

# --- 1) Fabricamos una carpeta de imágenes sintéticas: una subcarpeta por clase ---
rng = np.random.default_rng(0)
raiz = tempfile.mkdtemp()
yy, xx = np.mgrid[0:32, 0:32]
for clase in ("circulo", "cuadrado", "cruz"):
    os.makedirs(os.path.join(raiz, clase))
    for i in range(12):
        cy, cx = rng.integers(10, 22, 2)
        if clase == "circulo":
            mascara = (yy - cy) ** 2 + (xx - cx) ** 2 <= 36
        elif clase == "cuadrado":
            mascara = (abs(yy - cy) <= 6) & (abs(xx - cx) <= 6)
        else:
            mascara = ((abs(yy - cy) <= 1) & (abs(xx - cx) <= 7)) | ((abs(xx - cx) <= 1) & (abs(yy - cy) <= 7))
        imagen = np.zeros((32, 32, 3), dtype="uint8")
        imagen[mascara] = rng.integers(120, 255, 3)
        keras.utils.save_img(os.path.join(raiz, clase, f"{i}.png"), imagen)

# --- 2) La forma moderna: image_dataset_from_directory + capas de augmentation ---
train = keras.utils.image_dataset_from_directory(
    raiz, image_size=(32, 32), batch_size=8, validation_split=0.25, subset="training", seed=1)
print("clases:", train.class_names)

augment = keras.Sequential([layers.RandomFlip("horizontal"), layers.RandomRotation(0.1)])
train_aug = train.map(lambda x, y: (augment(x, training=True), y)).prefetch(tf.data.AUTOTUNE)
for lote, etiquetas in train_aug.take(1):
    print("lote:", lote.shape, lote.dtype, "| etiquetas:", etiquetas.shape, etiquetas.dtype)

# --- 3) La forma antigua del curso: ImageDataGenerator (hoy "legacy") ---
try:
    from keras.preprocessing.image import ImageDataGenerator
except ImportError as error:
    print("ImportError:", error)
from tensorflow.keras.preprocessing.image import ImageDataGenerator
generador = ImageDataGenerator(rescale=1 / 255, rotation_range=20, width_shift_range=0.1,
                               horizontal_flip=True, fill_mode="nearest")
flujo = generador.flow_from_directory(raiz, target_size=(32, 32), batch_size=8, class_mode="categorical")
lote, etiquetas = next(flujo)
print("class_indices:", flujo.class_indices)
print("lote:", lote.shape, lote.dtype, "máx", round(float(lote.max()), 2), "| etiquetas:", etiquetas.shape)

10 · La caja de herramientas tf.image

Para qué sirve Probar las operaciones de tf.image más útiles (tipos de dato, redimensionar, voltear, recortar, brillo, contraste, gris, estandarizar y aleatoriedad reproducible) y verificar cada una con una cuenta que se puede hacer a mano.

import numpy as np
import tensorflow as tf

# Una imagen RGB de 4x4 con valores 0-255 (entero de 8 bits, como un PNG leído del disco)
valores = np.arange(48, dtype="uint8").reshape(4, 4, 3) * 5
img = tf.constant(valores)
print("original  :", img.shape, img.dtype, "| píxel [0,1] =", img[0, 1].numpy())

f = tf.image.convert_image_dtype(img, tf.float32)       # uint8 0-255 -> float32 0-1
print("a float32 :", f.dtype, "| píxel [0,1] =", np.round(f[0, 1].numpy(), 4), "(15/255 = %.4f)" % (15 / 255))

print("redimension:", tf.image.resize(f, (8, 8)).shape, "| con 'nearest':",
      tf.image.resize(f, (8, 8), method="nearest").shape)
print("volteo izq-der: columna 0 pasa a ser la 3:",
      np.array_equal(tf.image.flip_left_right(f).numpy()[:, 0], f.numpy()[:, 3]))
print("rot90     :", tf.image.rot90(f).shape, "| recorte central 50%:", tf.image.central_crop(f, 0.5).shape)

# Brillo y contraste, con la fórmula a mano
b = tf.image.adjust_brightness(f, 0.1)
print("brillo +0.1 :", np.round(f[0, 1].numpy(), 3), "->", np.round(b[0, 1].numpy(), 3))
c = tf.image.adjust_contrast(f, 2.0)
media = f.numpy().mean(axis=(0, 1))                    # media por canal
manual = (f.numpy() - media) * 2.0 + media
print("contraste x2: coincide con (x - media)*2 + media:", np.allclose(c.numpy(), manual, atol=1e-6))

g = tf.image.rgb_to_grayscale(f)
print("gris      :", g.shape, "| píxel [0,1] =", round(float(g[0, 1, 0]), 4),
      "(0.299R+0.587G+0.114B = %.4f)" % (0.299 * f[0, 1, 0] + 0.587 * f[0, 1, 1] + 0.114 * f[0, 1, 2]))
s = tf.image.per_image_standardization(f)
print("estandarizada: media %.2f, desviación %.2f" % (abs(float(tf.reduce_mean(s))), float(tf.math.reduce_std(s))))

# Versión aleatoria reproducible: las "stateless" reciben una semilla de 2 números
a1 = tf.image.stateless_random_flip_left_right(f, seed=(1, 2))
a2 = tf.image.stateless_random_flip_left_right(f, seed=(1, 2))
print("misma semilla -> mismo resultado:", np.array_equal(a1.numpy(), a2.numpy()))

14 · preprocess_input: cada modelo espera los píxeles a su manera

Para qué sirve Calcular a mano y con las funciones de Keras el preprocesado de VGG16, ResNet50, MobileNetV2 y EfficientNet sobre un píxel naranja, y ver qué pasa con el error más frecuente: dividir entre 255 y pasárselo a VGG16.

import numpy as np
from keras.applications import vgg16, resnet50, mobilenet_v2, efficientnet

# Una "imagen" de 1x1 píxel con un naranja: R=200, G=100, B=50 (valores 0-255, en formato RGB)
pixel = np.array([[[[200.0, 100.0, 50.0]]]], dtype="float32")        # forma (1, 1, 1, 3)

print("VGG16      :", vgg16.preprocess_input(pixel.copy()).ravel().round(3))
print("ResNet50   :", resnet50.preprocess_input(pixel.copy()).ravel().round(3))
print("MobileNetV2:", mobilenet_v2.preprocess_input(pixel.copy()).ravel().round(4))
print("EfficientNet:", efficientnet.preprocess_input(pixel.copy()).ravel().round(3))

# A mano: VGG16 y ResNet50 -> pasar RGB a BGR y restar la media de ImageNet [B=103.939, G=116.779, R=123.68]
a_mano_caffe = np.array([50 - 103.939, 100 - 116.779, 200 - 123.68])
print("a mano (BGR - media):", a_mano_caffe.round(3))
# MobileNetV2 -> escalar de [0, 255] a [-1, 1]:  x / 127.5 - 1
print("a mano (x/127.5 - 1):", (np.array([200, 100, 50]) / 127.5 - 1).round(4))

# El error típico: dividir entre 255 y dárselo a un modelo que esperaba otra escala
mal = pixel / 255.0
print("VGG16 con x/255 (MAL):", vgg16.preprocess_input(mal.copy()).ravel().round(3))
