TensorFlow 2.x, Keras 3 y por qué un tutorial antiguo falla

Copias el código de un tutorial de hace tres años y falla en la primera línea con un error que no entiendes. ¿Has hecho algo mal? Casi nunca: es como seguir una guía antigua de Netflix que dice «pulsa el botón de arriba a la derecha» cuando la app ya lo ha cambiado de sitio. Lo que ha cambiado son las herramientas. Antes de construir nada conviene saber qué es cada pieza y cuál es su versión.

Analogía

TensorFlow es la sala de máquinas de Netflix: los servidores y los cables que de verdad mueven el vídeo, es decir, el código que multiplica matrices, calcula derivadas y usa la tarjeta gráfica. Keras es la app: pulsas «play» o «añadir a mi lista» (aquí, «una capa Dense de 16 neuronas») sin pensar en servidores. Lo normal es quedarse en la app. Pero cuando quieres algo que la app no ofrece (una red con dos entradas, una capa nueva, una pérdida a medida), hay que saber entrar en la sala de máquinas. Eso es este módulo.

Qué es cada cosa

  • TensorFlow es la librería de cálculo numérico: define los tensores (los arrays de números), sabe calcular derivadas automáticamente (GradientTape), compila funciones para que vayan rápido (tf.function) y las ejecuta en CPU o GPU.
  • Keras es la API de alto nivel para redes: capas (layers), modelos (Model), compile, fit, save… Desde la versión 3, Keras es una librería independiente con varios backends posibles (TensorFlow, JAX o PyTorch): el motor que hace las cuentas por debajo se elige al arrancar. En este curso el backend es TensorFlow.
  • «TensorFlow 2.x» es una forma de trabajar: las operaciones se ejecutan al instante como en NumPy (eager execution, «ejecución inmediata»), y si quieres velocidad se «compila» una función con tf.function. En TensorFlow 1 había que construir primero un grafo y ejecutarlo después, mucho más incómodo.

Ojo · tf.keras y keras

En los cursos y tutoriales antiguos se escribe tf.keras.layers.Dense o from tensorflow.keras import layers. Hoy conviene escribir import keras y from keras import layers. En la versión instalada, tf.keras redirige al mismo Keras 3 (las clases son las mismas: tf.keras.layers.Dense is keras.layers.Dense da True), pero el módulo tf.keras no es el objeto keras (tf.keras is keras da False), y mezclar ambos estilos en un mismo programa es una fuente de confusiones. Elige uno; aquí usamos import keras.

1 · Versiones, tf.keras, tensores simbólicos y guardado antiguo: lo que cambia en Keras 3

Para qué sirve Ver con qué versiones se ha ejecutado todo el módulo y reproducir tres cosas que rompen el código de tutoriales antiguos: usar tf.keras, aplicar funciones de TensorFlow a un tensor simbólico y guardar en .h5.

import os
import tempfile
import numpy as np
import tensorflow as tf
import keras
from keras import layers, ops

print("TensorFlow", tf.__version__, "| Keras", keras.__version__, "| backend:", keras.backend.backend())
print("tf.keras es el mismo objeto que keras:", tf.keras is keras)
print("pero sus clases son las mismas:", tf.keras.layers.Dense is keras.layers.Dense, "| versión de tf.keras:", tf.keras.__version__)

entrada = keras.Input(shape=(3,))
print(type(entrada).__name__, entrada.shape)

try:
    tf.reduce_sum(entrada, axis=-1)
except ValueError as e:
    print("ValueError:", str(e).split(".")[0])

cuadrado = ops.square(entrada)
suma = layers.Lambda(lambda t: ops.sum(t, axis=-1, keepdims=True), name="suma")(cuadrado)
modelo = keras.Model(entrada, suma)
print("con keras.ops:", modelo.predict(np.array([[1.0, -2.0, 3.0]], "float32"), verbose=0).tolist())

ruta = os.path.join(tempfile.mkdtemp(), "modelo.h5")
modelo.save(ruta)
print("guardado en .h5 (formato antiguo):", os.path.exists(ruta))

Primera línea: la versión usada en todo el módulo (TensorFlow 2.21.0, Keras 3.15.1, backend tensorflow). tf.keras is keras da False pero las clases son idénticas (True), así que tf.keras redirige al mismo Keras 3. El tensor simbólico es de tipo KerasTensor y forma (None, 3). La función de TensorFlow falla con «A KerasTensor cannot be used as input to a TensorFlow function»; con keras.ops el modelo funciona: para [1, −2, 3] la salida es 1² + (−2)² + 3² = 1 + 4 + 9 = 14. Por último, el .h5 se guarda (True), aunque sea el formato antiguo.
