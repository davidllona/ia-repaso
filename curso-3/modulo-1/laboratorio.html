Antes de empezar: las piezas

Python es el lenguaje en el que se escribe todo. El ordenador lee sus órdenes de arriba abajo, una por línea.

Python, solo, sabe hacer poco. Por eso se usan librerías: paquetes de código que otra gente ya escribió. La orden import mete una librería en tu programa; desde ese momento puedes usar sus herramientas. En este laboratorio salen cuatro, más unas pocas que ya vienen con Python:

  • NUMPYdatos y cuentas
  • TENSORFLOWtensores y derivadas
  • KERAScapas y modelos
  • SCIKIT-LEARNdatos de prueba

Piensa en TensorFlow como la sala de máquinas de Netflix (los servidores que mueven el vídeo) y en Keras como la app (el botón de «play»). Este módulo entra en la sala de máquinas. No hace falta memorizar las fichas: vuelve aquí cuando una palabra te suene rara.

np.ones
Una tabla llena de unos, de la forma que digas.
np.allclose

TensorFlow: tensores, derivadas y grafos

TensorFlow (tf)
La librería de Google para redes neuronales. Hace cuentas como NumPy, pero además deriva sola y usa la tarjeta gráfica. El nombre: los «tensores» fluyen (flow) por la red. Su apodo es tf.
Tensor
Una tabla de números de cualquier nº de ejes, todos del mismo tipo. Se describe por rango (.ndim, nº de ejes), forma (.shape) y tipo (.dtype). tf.size = cuántos números.
tf.constant
Un tensor fijo: no se puede cambiar. Los datos.
tf.Variable
Un tensor que se puede cambiar en su sitio: assign_add (sumar), assign_sub (restar). trainable dice si se entrena. Los pesos.
.numpy()
Convierte un tensor en un array de NumPy, para imprimirlo o compararlo.
tf.zeros, tf.ones, tf.range
Tensores de ceros o de unos con la forma que digas; números seguidos (tf.range(1, 25) = 1…24).
tf.float32, tf.int32, tf.cast
Decimales y enteros de 32 bits. tf.cast convierte de un tipo a otro: TensorFlow no lo hace solo.
tf.reshape
Reagrupa los mismos números en otra forma. Un -1 = «calcula tú este eje».
tf.reduce_sum y tf.reduce_mean
Suma y media. Con axis=k borran el eje k; con keepdims=True lo dejan con tamaño 1.
tf.matmul
Producto de matrices, igual que @: (m, n) @ (n, k) → (m, k). La cuenta de una capa Dense.
tf.concat y tf.stack
Pegar por un eje que ya existe; apilar en un eje nuevo.
tf.argmax
La posición del número más alto en cada fila.
tf.broadcast_to, broadcast_static_shape, TensorShape
Estirar un tensor a otra forma; calcular qué forma saldría de juntar dos; una forma suelta, sin datos.
tf.errors.InvalidArgumentError
El error de TensorFlow para «argumento no válido»: formas que no encajan o tipos mezclados.
tf.GradientTape
La cinta: graba las cuentas y, con tape.gradient(L, [w, b]), las rebobina y da las derivadas. tape.watch(c) vigila una constante; persistent=True permite usarla varias veces.
tf.stop_gradient
Hace que un trozo de la cuenta cuente como constante al derivar.
tf.nn.relu
La ReLU: los negativos pasan a 0 y el resto se queda igual.
tf.function
Convierte una función de Python en un grafo: la monta (traza) una vez por firma y luego solo la reproduce. experimental_get_tracing_count() cuenta los trazados.
tf.print
El print de TensorFlow: forma parte del grafo y sale en cada llamada.
tf.TensorSpec e input_signature
Describen de antemano qué tensores acepta un grafo (forma y tipo). Así no se traza otra vez.
tf.data.Dataset
Un flujo de datos. from_tensor_slices lo crea fila a fila; .shuffle baraja; .batch(32) sirve de 32 en 32.
tf.saved_model.load
Carga un modelo exportado en formato SavedModel, sin necesitar Keras.
tf.keras y __version__
tf.keras es el camino antiguo a Keras; hoy redirige al mismo Keras 3. __version__ dice qué versión tienes.

Keras: capas y modelos

Keras (keras)
La librería que monta redes con piezas: capas, pérdidas, optimizadores. Desde la versión 3 es independiente y usa un motor por debajo (keras.backend.backend()); aquí, TensorFlow. «Keras» es «cuerno» en griego.
keras.Input y KerasTensor
Un tensor simbólico: un enchufe sin datos que solo recuerda su forma, como (None, 8). None = el tamaño del lote, aún sin decidir.
layers
El cajón de capas de Keras. Una capa es un grupo de neuronas que calculan a la vez.
layers.Dense
Capa densa: cada neurona conectada con todas las entradas. Dense(8, activation="relu") = 8 neuronas con ReLU. Sus pesos son kernel (la matriz W) y bias (b).
"relu", "sigmoid", "softmax"
Activaciones: ReLU; sigmoide (una probabilidad de 0 a 1); softmax (varias probabilidades que suman 1).
Add, Subtract, Concatenate
Capas que juntan ramas: sumar, restar (exigen la misma forma) o pegar (suma los anchos).
layers.ReLU
La activación ReLU como capa suelta.
Dropout y BatchNormalization
Dos capas que cambian según training: Dropout apaga neuronas al azar al entrenar; BatchNorm deja los números con media 0 y desviación 1.
layers.Lambda
Convierte una función de una línea en una capa. Cómodo, pero no se carga por defecto al guardar.
keras.ops
Las operaciones matemáticas de Keras (square, sum, abs, mean, where, matmul, array). Funcionan con cualquier motor y con tensores simbólicos.
keras.Sequential
Un modelo que es una fila de capas: lo que sale de una entra en la siguiente.
keras.Model
Dos usos: keras.Model(entradas, salidas) recoge un grafo (API funcional); y como clase de la que heredar (subclassing).
call y training
call es el cálculo de un modelo o capa. training le dice si se está entrenando (True) o prediciendo (False).
layers.Layer
La clase base de todas las capas. Heredas de ella para escribir la tuya.
build y add_weight
build(input_shape) se ejecuta una vez, con los primeros datos; dentro, add_weight crea cada peso con su forma, su valor inicial ("glorot_uniform" al azar, "zeros", "ones") y si se entrena.
built
¿Tiene ya sus pesos? False hasta la primera llamada.
get_config y from_config
La receta de una capa o modelo (sus argumentos), y fabricar uno nuevo a partir de ella.
keras.activations.get y serialize
De un nombre como "relu" a la función, y de la función otra vez al nombre.
summary y count_params
La tabla del modelo (capas, formas, parámetros, conexiones) y el total de parámetros.
layers, get_layer, input, output
Las capas de un modelo; buscar una por su nombre; su entrada y su salida. output_shape y output_names = forma y nombres de las salidas.
weights, get_weights, set_weights
Los pesos; sacarlos como arrays; ponerlos a mano. trainable_weights y non_trainable_weights separan los que se entrenan. w.path = nombre completo de un peso.
trainable = False
Congela una capa o un modelo: sus pesos dejan de entrenarse.
compile
Prepara el entrenamiento: optimizer (cómo se mueven los pesos), loss (qué se baja), metrics (qué se enseña) y loss_weights (cuánto cuenta cada pérdida). No entrena aún.
Adam y "sgd"
Dos optimizadores. keras.optimizers.Adam(0.01) = Adam con paso 0,01.
Pérdidas y métricas por nombre
"mse" (error al cuadrado), "binary_crossentropy" (sí o no), "sparse_categorical_crossentropy" (varias clases dadas como 0, 1, 2…), "accuracy" (acierto), "mae" (error medio sin signo).
fit e historial
Entrena. epochs = vueltas; batch_size = ejemplos por lote; validation_split o validation_data = datos para vigilar; verbose=0 = en silencio. Devuelve un historial: hist.history["loss"].
evaluate y predict
Poner nota con unos datos (return_dict=True = con nombres); y predecir.
keras.utils.set_random_seed
Fija a la vez el azar de Python, NumPy y TensorFlow.
keras.utils.plot_model
Dibuja el modelo en una imagen. Necesita pydot y Graphviz.
save y .keras
modelo.save("x.keras") guarda receta y pesos en un archivo. .h5 es el formato antiguo.
keras.models.load_model
Carga un .keras. custom_objects le da tus clases; safe_mode=False permite cargar Lambda (solo si te fías del archivo).
save_weights y load_weights
Guardar y cargar solo los pesos, en un archivo que debe acabar en .weights.h5.
register_keras_serializable
Apunta tu clase en el registro de Keras para que load_model la encuentre sola. get_registered_name dice con qué nombre quedó.
export
Exporta el modelo como SavedModel, el formato de TensorFlow para ponerlo en producción.

import tensorflow as tf

A = tf.constant([[1., 2., 3.], [4., 5., 6.]])
B = tf.constant([[1., 0.], [0., 1.], [1., 1.]])

print("suma total:", float(tf.reduce_sum(A)))
print("axis=0    :", tf.reduce_sum(A, axis=0).numpy())
print("axis=1    :", tf.reduce_sum(A, axis=1).numpy())
print("keepdims  :", tf.reduce_sum(A, axis=1, keepdims=True).shape)

x = tf.range(1, 25)

from keras import layers

class CapaDensa(layers.Layer):
    def __init__(self, unidades, activacion=None, **kwargs):
        super().__init__(**kwargs)
        self.unidades = unidades
        self.activacion = keras.activations.get(activacion)

    def build(self, input_shape):
        n_in = input_shape[-1]
        self.W = self.add_weight(name="W", shape=(n_in, self.unidades), initializer="glorot_uniform")
        self.b = self.add_weight(name="b", shape=(self.unidades,), initializer="zeros")

    def call(self, x):
        return self.activacion(tf.matmul(x, self.W) + self.b)

    def get_config(self):
        config = super().get_config()
        config.update({"unidades": self.unidades, "activacion": keras.activations.serialize(self.activacion)})
        return config

@keras.saving.register_keras_serializable(package="c3m1")
class CapaDensa(layers.Layer):
    def __init__(self, unidades, activacion=None, **kwargs):
        super().__init__(**kwargs)
        self.unidades = unidades
        self.activacion = keras.activations.get(activacion)

    def build(self, input_shape):
        self.W = self.add_weight(name="W", shape=(input_shape[-1], self.unidades), initializer="glorot_uniform")
        self.b = self.add_weight(name="b", shape=(self.unidades,), initializer="zeros")

    def call(self, x):
        return self.activacion(keras.ops.matmul(x, self.W) + self.b)

    def get_config(self):
        config = super().get_config()
        config.update({"unidades": self.unidades, "activacion": keras.activations.serialize(self.activacion)})
        return config

class CapaDensa(layers.Layer):
    def __init__(self, unidades, activacion=None, **kwargs):
        super().__init__(**kwargs)
        self.unidades = unidades
        self.activacion = keras.activations.get(activacion)

    def build(self, input_shape):
        n_in = input_shape[-1]
        self.W = self.add_weight(name="W", shape=(n_in, self.unidades), initializer="glorot_uniform")
        self.b = self.add_weight(name="b", shape=(self.unidades,), initializer="zeros")

        return self.activacion(tf.matmul(x, self.W) + self.b)

    def get_config(self):
        config = super().get_config()
        config.update({"unidades": self.unidades, "activacion": keras.activations.serialize(self.activacion)})
        return config

import numpy as np
import keras
from keras import layers, ops

@keras.saving.register_keras_serializable(package="c3m1")
class BloqueResidual(layers.Layer):
    def __init__(self, unidades, **kwargs):
        super().__init__(**kwargs)
        self.unidades = unidades
        self.d1 = layers.Dense(unidades, activation="relu", name="d1")
        self.d2 = layers.Dense(unidades, name="d2")

    def build(self, input_shape):
        self.d1.build(input_shape)
        self.d2.build((input_shape[0], self.unidades))

    def call(self, x):
        return x + self.d2(self.d1(x))

    def get_config(self):
        config = super().get_config()
        config["unidades"] = self.unidades
        return config

@keras.saving.register_keras_serializable(package="c3m1")
class Escala(layers.Layer):
    def build(self, input_shape):
        self.escala = self.add_weight(name="escala", shape=(), initializer="ones", trainable=True)
        self.llamadas = self.add_weight(name="llamadas", shape=(), initializer="zeros", trainable=False)

    def call(self, x):
        self.llamadas.assign_add(1.0)
        return x * self.escala

def huber(y_true, y_pred):
    err = y_true - y_pred
    pequeno = ops.abs(err) <= 1.0
    return ops.mean(ops.where(pequeno, 0.5 * err ** 2, ops.abs(err) - 0.5))
