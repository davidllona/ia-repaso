Parte 2 · Un clasificador de imágenes con transfer learning

Quieres que Netflix clasifique por género las carátulas de películas nuevas, pero solo tienes unas decenas de carátulas etiquetadas. Entrenar una CNN desde cero con tan pocos ejemplos parece una locura. ¿Hay alguna manera de aprovechar lo que otra red ya aprendió con millones de imágenes?

Analogía

Fichar a un empleado que lleva años clasificando carátulas de cine de acción. Ya sabe reconocer rostros, explosiones, tipografías y composiciones: no le enseñas qué es un rostro ni un título. Solo le explicas lo específico de tu catálogo (qué géneros usas). El transfer learning (aprendizaje por transferencia) hace lo mismo con una red: la primera parte, que ya sabe «ver» bordes, curvas y texturas, se reutiliza; solo se entrena la parte final, que decide a qué clase pertenece cada imagen.

Cómo se parte una red para reutilizarla

Una CNN tiene dos zonas con trabajos distintos (módulo 2):

  • La base convolucional: capas de convolución y pooling que convierten una imagen en un mapa de características. Las primeras capas detectan cosas muy generales (bordes, esquinas); las últimas, cosas más específicas (partes de objetos).
  • La cabeza: las capas finales (Flatten, Dense…) que miran esas características y deciden la clase. Es lo más pegado a la tarea concreta.

El transfer learning conserva la base y cambia la cabeza. Y se hace en dos fases, que verás con detalle más abajo: primero se entrena solo la cabeza nueva con la base congelada (sus pesos no cambian) y, si merece la pena, después se «descongelan» las últimas capas de la base y se afinan con un learning rate muy pequeño (fine-tuning).

Los datos de este proyecto, con honestidad

Lo normal sería partir de una base entrenada con ImageNet (1,2 millones de fotos de 1.000 clases) y de fotos tuyas. Aquí no podemos descargar ni los pesos de ImageNet ni fotos reales, así que montamos una versión a escala pequeña que conserva toda la mecánica:

Tarea A (la «experiencia previa»)Tarea B (tu problema)
Qué reconoceDígitos 0, 1, 2, 3, 4Dígitos 5, 6, 7, 8, 9
Imágenes720 de entrenamiento y 181 de validación75 de entrenamiento, 75 de validación y 746 de test
PapelEntrenar la base (hace el papel de ImageNet)Reutilizar la base con muy pocas imágenes

Piensa en cada dígito como una carátula diminuta en gris y en la cifra como su género: reconocer qué cifra es será nuestro «reconocer el género de la carátula». Las imágenes vienen de load_digits de scikit-learn: 1.797 dígitos de 8 × 8 píxeles con valores de 0 a 16. Una CNN pensada para fotos espera, por convención, imágenes de tamaño mayor con tres canales de color, así que las adaptamos.

Ejemplo numérico · de 8×8 a 32×32×3, píxel a píxel
  1. Un píxel de la carátula original vale, por ejemplo, 8 (de un máximo de 16). Dividido entre 16 queda en 0,5.
  2. np.kron(imagen, np.ones((4, 4))) reemplaza cada píxel por un bloque de 4 × 4 iguales: el tamaño pasa de 8 × 8 a (8·4) × (8·4) = 32 × 32. El bloque entero vale 0,5.
  3. Multiplicar por 255 deja ese valor en 0,5 · 255 = 127,5: la escala 0–255 de una foto.
  4. Repetir el canal tres veces da la forma (32, 32, 3): tres canales idénticos, es decir, una carátula en blanco y negro guardada como si fuera en color.
  5. Para todo el conjunto, la forma pasa de (1797, 8, 8) a (1797, 32, 32, 3). En float32 son 1.797 · 32 · 32 · 3 · 4 bytes ≈ 22 MB. Cabe de sobra en memoria.

El fragmento 13 hace estos pasos, reparte los datos en las dos tareas (con stratify para que cada cifra esté igual de representada) y deja la tarea B con unas 15 imágenes por cifra. Observa también dos cosas del reparto de B: el test (746 imágenes) es mucho mayor que el entrenamiento a propósito, para que la nota final sea fiable aunque entrenemos con poco, y las etiquetas se desplazan (5→0, …, 9→4) porque una salida de 5 neuronas espera clases numeradas desde 0.

Ojo · un juguete honesto, no una prueba de ImageNet

Que una base entrenada con dígitos 0–4 ayude con los 5–9 no demuestra que un modelo de ImageNet ayude con tus fotos de gatos. Sirve para ver la mecánica (congelar, cabeza, descongelar, recompilar, medir) con datos que podemos usar sin internet. Más abajo verás que, con una base tan pequeña, el resultado del transfer learning es más matizado de lo que promete el mito.

19 · La pregunta incómoda: ¿gana el transfer learning a entrenar desde cero?

Para qué sirve Entrenar la tarea B de cuatro maneras (desde cero, solo fase 1, fases 1 y 2 con el bloque 3 y fases 1 y 2 con toda la base) con tres semillas cada una, para ver la media y la dispersión. Usa construir_base y las funciones auxiliares de los fragmentos 15 y 17.

def entrenar_en_B(modo, semilla):
    keras.utils.set_random_seed(semilla)
    if modo == "desde cero":
        b = construir_base()
    else:
        b = keras.models.load_model("base_digitos_0a4.keras")
        b.trainable = False
    m = modelo_con_cabeza(b, 5)
    if modo == "desde cero":
        compilar(m, 1e-3)
        ajustar(m, 90)
        return acierto_test(m)
    compilar(m, 1e-3)
    ajustar(m, 60)
    if modo == "solo fase 1":
        return acierto_test(m)
    b.trainable = True
    for capa in b.layers:
        capa.trainable = capa.name.startswith("bloque3") or modo == "fase 1 + 2 (todo)"
    compilar(m, 1e-4)
    ajustar(m, 30)
    return acierto_test(m)

modos = ["desde cero", "solo fase 1", "fase 1 + 2 (bloque 3)", "fase 1 + 2 (todo)"]
for modo in modos:

22 · Barrido de la fase 2: cuántos bloques descongelar y con qué learning rate

Para qué sirve Para tres semillas, entrenar la fase 1 una vez, guardar sus pesos y, a partir de ellos, probar nueve configuraciones de la fase 2 (descongelar el bloque 3, los bloques 2 y 3 o todos, con learning rate 1e-5, 1e-4 y 1e-3). Imprime la media y la desviación de cada una. Es el experimento más largo del módulo.

def barrido(semilla):
    keras.utils.set_random_seed(semilla)
    b = keras.models.load_model("base_digitos_0a4.keras")
    b.trainable = False
    m = modelo_con_cabeza(b, 5)
    compilar(m, 1e-3)
    ajustar(m, 60)
    m.save_weights("fase1.weights.h5")
    filas = {"solo fase 1": acierto_test(m)}
    for nombre, bloques in [("bloque 3", ("bloque3",)), ("bloques 2-3", ("bloque2", "bloque3")), ("todo", ("bloque",))]:
        for lr in [1e-5, 1e-4, 1e-3]:
            keras.utils.set_random_seed(semilla)
            b2 = keras.models.load_model("base_digitos_0a4.keras")
            m2 = modelo_con_cabeza(b2, 5)
            m2.load_weights("fase1.weights.h5")
            b2.trainable = True
            for capa in b2.layers:
                capa.trainable = capa.name.startswith(bloques)
            compilar(m2, lr)
            ajustar(m2, 30)
            filas[f"{nombre} | lr {lr:g}"] = acierto_test(m2)
    return filas
