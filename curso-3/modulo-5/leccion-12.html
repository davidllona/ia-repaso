Reproducibilidad: fijar el azar

El entrenamiento tiene mucho azar escondido: los pesos iniciales, el orden de los lotes, las máscaras de Dropout, el aumento de datos, la partición entrenamiento/validación. (Es como el modo aleatorio de una lista de reproducción: si dos personas usan la misma «semilla», la lista sale en el mismo orden.) Con una sola llamada se fijan a la vez el generador de Python, el de NumPy y el del backend:

Ojo · reproducible no es lo mismo que portable

Con la misma semilla, el mismo código y las mismas versiones y hardware, se obtienen los mismos números. Si cambias de CPU a GPU, o de versión de TensorFlow, los números pueden diferir (suman en otro orden y los decimales cambian en las últimas cifras). Anota las versiones (keras.__version__, tf.__version__) junto con la semilla. En el fragmento 14 la llamada a enable_op_determinism() va por seguridad: en esta CPU los resultados ya se repetían idénticos sin ella, pero eso no está garantizado.

Los otros tres casos del fragmento 14

  • Solo los pesos: save_weights("pesos.weights.h5"); en un modelo nuevo construido con el mismo código, load_weights da las mismas predicciones (True).
  • Exportar para servir: modelo.export("servir") escribe un SavedModel con las firmas ['serve', 'serving_default']; cargado con tf.saved_model.load, sm.serve(...) predice lo mismo. export imprime un resumen largo con rutas temporales; el fragmento lo silencia con contextlib.redirect_stdout.
  • Una capa propia sin registrar: load_model falla con TypeError: Could not locate class 'SinRegistrar' y se arregla pasando custom_objects={"SinRegistrar": SinRegistrar} (carga bien y predice [[3.0, 6.0, 9.0]], es decir, \( [1,2,3]\cdot3 \)).

13 · tf.data: map, cache, shuffle, batch, prefetch y fit con un Dataset

Para qué sirve Mide con contadores qué ejecuta cada etapa, comprueba que cache evita repetir trabajo, enseña por qué el orden de shuffle y batch importa y entrena con un pipeline completo.

import numpy as np
import tensorflow as tf
import keras

X = np.arange(10, dtype="float32").reshape(-1, 1)          # 0, 1, ..., 9
y = (X * 2).astype("float32")                               # el doble

ds = tf.data.Dataset.from_tensor_slices((X, y))
print("element_spec:", ds.element_spec)
print("primer elemento:", [t.numpy().tolist() for t in next(iter(ds))])

# map: una transformación por elemento. Contamos cuántas veces se ejecuta de verdad la función de Python
llamadas = {"n": 0}
def escalar(x, y):
    llamadas["n"] += 1                                      # esto solo corre al TRAZAR el grafo
    return x / 9.0, y / 18.0

ds_map = ds.map(escalar, num_parallel_calls=tf.data.AUTOTUNE)
for _ in ds_map:                                            # recorremos el dataset entero
    pass
print("elementos recorridos: 10 | veces que Python ejecutó escalar:", llamadas["n"])

# cache: la 2.ª pasada no vuelve a ejecutar el map (contamos con py_function, que sí corre en cada elemento)
contador = {"n": 0}
def lento(x, y):
    contador["n"] += 1
    return x, y
def con_py(x, y):
    return tf.py_function(lento, [x, y], [tf.float32, tf.float32])

for nombre, d in [("sin cache", ds.map(con_py)), ("con cache", ds.map(con_py).cache())]:
    contador["n"] = 0
    for _ in range(2):                                      # dos épocas
        for _ in d:
            pass
    print(f"{nombre}: el map se ejecutó {contador['n']} veces en 2 épocas de 10 elementos")

# El orden de las etapas importa: shuffle ANTES de batch baraja ejemplos; después solo baraja lotes enteros
tf.random.set_seed(0)
a = ds.shuffle(buffer_size=10, seed=0).batch(5)
b = ds.batch(5).shuffle(buffer_size=2, seed=1)
print("shuffle -> batch :", [lote[0].numpy().ravel().astype(int).tolist() for lote in a])
print("batch -> shuffle :", [lote[0].numpy().ravel().astype(int).tolist() for lote in b])

# batch con drop_remainder, take, repeat
print("batch(4):              ", [len(l[0]) for l in ds.batch(4)])
print("batch(4, drop_remainder):", [len(l[0]) for l in ds.batch(4, drop_remainder=True)])
print("repeat(2).take(13) tiene", len(list(ds.repeat(2).take(13))), "elementos")

# Pipeline típico y su uso directo en fit
tf.random.set_seed(1)
pipeline = (ds.map(escalar, num_parallel_calls=tf.data.AUTOTUNE)
              .cache()
              .shuffle(buffer_size=10, seed=1)
              .batch(4)
              .prefetch(tf.data.AUTOTUNE))
print("cardinalidad del pipeline (lotes por época):", pipeline.cardinality().numpy())

keras.utils.set_random_seed(0)
modelo = keras.Sequential([keras.Input(shape=(1,)), keras.layers.Dense(1)])
modelo.compile(optimizer=keras.optimizers.SGD(0.5), loss="mse")
h = modelo.fit(pipeline, epochs=40, shuffle=False, verbose=0)               # fit acepta el Dataset directamente: no se pasa y ni batch_size
print("loss época 1 -> 40:", round(h.history["loss"][0], 4), "->", f'{h.history["loss"][-1]:.1e}')
print("predicción para x = 9 / 9 = 1.0 (debería acercarse a 1.0):", round(float(modelo.predict(np.array([[1.0]]), verbose=0)[0, 0]), 3))

14 · Guardar, reanudar, semillas, exportar y capas propias

Para qué sirve Comprueba que la misma semilla da los mismos pesos, que un modelo guardado reanuda con su optimizador, que se pueden guardar solo los pesos o exportar un SavedModel y qué pasa con una capa propia sin registrar.

import contextlib, io, os, tempfile
import numpy as np
import tensorflow as tf
import keras

tf.config.experimental.enable_op_determinism()      # operaciones deterministas (más lentas en GPU)

@keras.saving.register_keras_serializable(package="curso3")
class EscalaYSesgo(keras.layers.Layer):
    def __init__(self, factor=2.0, **kwargs):
        super().__init__(**kwargs)
        self.factor = factor
    def call(self, x):
        return x * self.factor
    def get_config(self):                           # lo que hace falta para reconstruir la capa
        return {**super().get_config(), "factor": self.factor}

def construir():
    return keras.Sequential([keras.Input(shape=(3,)), keras.layers.Dense(8, activation="relu"),
                             EscalaYSesgo(0.5), keras.layers.Dense(1)])

rng = np.random.default_rng(0)
X = rng.normal(size=(64, 3)).astype("float32")
y = X.sum(axis=1, keepdims=True)

def entrenar(semilla=None):
    if semilla is not None:
        keras.utils.set_random_seed(semilla)
    m = construir()
    m.compile(optimizer=keras.optimizers.Adam(0.01), loss="mse")
    m.fit(X, y, epochs=3, batch_size=16, verbose=0)
    return m

# 1) Reproducibilidad: misma semilla -> mismos pesos; sin semilla -> distintos
a, b = entrenar(0), entrenar(0)
print("misma semilla: diferencia máxima de pesos =", max(float(np.abs(p - q).max()) for p, q in zip(a.get_weights(), b.get_weights())))
c = entrenar(1)
print("otra semilla : diferencia máxima de pesos =", round(max(float(np.abs(p - q).max()) for p, q in zip(a.get_weights(), c.get_weights())), 3))

carpeta = tempfile.mkdtemp()

# 2) Guardar y cargar el modelo entero (arquitectura + pesos + optimizador)
a.save(os.path.join(carpeta, "modelo.keras"))
cargado = keras.models.load_model(os.path.join(carpeta, "modelo.keras"))        # la capa registrada se encuentra sola
print("predicciones idénticas tras cargar:", bool(np.allclose(a.predict(X, verbose=0), cargado.predict(X, verbose=0))))
print("pasos del optimizador guardados:", int(a.optimizer.iterations.numpy()), "->", int(cargado.optimizer.iterations.numpy()))
cargado.fit(X, y, epochs=1, batch_size=16, verbose=0)
print("tras 1 época más: pasos =", int(cargado.optimizer.iterations.numpy()), "(sigue contando donde lo dejó)")

# 3) Solo los pesos: hay que reconstruir la arquitectura a mano
a.save_weights(os.path.join(carpeta, "pesos.weights.h5"))
nuevo = construir()
nuevo.load_weights(os.path.join(carpeta, "pesos.weights.h5"))
print("pesos cargados en un modelo nuevo:", bool(np.allclose(a.predict(X, verbose=0), nuevo.predict(X, verbose=0))))

# 4) Exportar para servir (formato SavedModel de TensorFlow)
with contextlib.redirect_stdout(io.StringIO()), contextlib.redirect_stderr(io.StringIO()):
    a.export(os.path.join(carpeta, "servir"))        # imprime un resumen largo con rutas temporales: lo silenciamos
sm = tf.saved_model.load(os.path.join(carpeta, "servir"))
print("firmas del SavedModel:", list(sm.signatures.keys()))
print("el SavedModel predice lo mismo:", bool(np.allclose(a.predict(X[:4], verbose=0), sm.serve(tf.constant(X[:4])).numpy(), atol=1e-5)))

# 5) Qué pasa si la capa propia NO está registrada
class SinRegistrar(keras.layers.Layer):
    def call(self, x):
        return x * 3.0
m = keras.Sequential([keras.Input(shape=(3,)), SinRegistrar()])
m.save(os.path.join(carpeta, "malo.keras"))
try:
    keras.models.load_model(os.path.join(carpeta, "malo.keras"))
except TypeError as e:
    mensaje = str(e)
    print("TypeError ...", mensaje[mensaje.index("Could not locate"):][:62], "...")
arreglado = keras.models.load_model(os.path.join(carpeta, "malo.keras"), custom_objects={"SinRegistrar": SinRegistrar})
print("con custom_objects carga bien:", arreglado.predict(np.array([[1.0, 2.0, 3.0]]), verbose=0).tolist())
