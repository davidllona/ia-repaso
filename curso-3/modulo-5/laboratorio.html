Keras: capas, optimizadores, callbacks y guardado

Keras (keras)
La librería que monta redes con piezas: capas, pérdidas, optimizadores. Desde la versión 3 usa un motor por debajo; aquí, TensorFlow. «Keras» es «cuerno» en griego.
keras.utils.set_random_seed
Fija a la vez el azar de Python, NumPy y TensorFlow. Va antes de crear el modelo.
keras.Sequential y keras.Input
Un modelo que es una fila de capas (.add añade otra); la entrada dice qué forma tiene cada ejemplo: shape=(2,) = 2 números.
keras.Model
Modelo general. Se crea con keras.Model(entrada, salida) o se hereda de él para cambiar su train_step/test_step.
layers.Dense
Capa densa: cada neurona mira todas las entradas. activation = su función ("relu", "tanh", "sigmoid"); kernel_initializer = cómo nacen sus pesos; kernel_regularizer = su multa. Sus pesos: kernel y sesgo.
layers.Dropout
Apaga al azar una fracción de neuronas al entrenar y multiplica las demás para compensar. Al predecir, no hace nada.
layers.BatchNormalization
Normaliza cada lote a media 0 y desviación 1. Al predecir usa moving_mean y moving_variance, que se mueven según momentum.
layers.Activation y layers.Layer
Una activación como capa suelta; la clase base para escribir tu propia capa (call = su cuenta, get_config = su receta).
training=True/False
Le dice al modelo si entrena o predice. Cambia Dropout y BatchNorm.
keras.Variable
Un peso de Keras: un número que el optimizador puede cambiar.
compile
Prepara el entrenamiento: optimizer, loss y metrics. No entrena aún.
fit
Entrena. epochs = vueltas; batch_size = ejemplos por lote; validation_split o validation_data = datos para vigilar; callbacks; shuffle; verbose=0 = en silencio. Devuelve un historial (h.history["loss"]).
evaluate, predict, count_params
Medir con unos datos ([pérdida, métricas]); predecir; contar los pesos.
layers[0], get_weights, trainable_variables, losses
La primera capa; sus pesos como arrays; todos los pesos que se entrenan; la lista de multas.
Pérdidas
MeanSquaredError/"mse" (error al cuadrado), "binary_crossentropy" (sí o no), SparseCategoricalCrossentropy (varias clases dadas como 0, 1, 2…; from_logits=True = las salidas aún no son probabilidades).
Métricas
keras.metrics.Mean hace medias: update_state apunta, result da la media, reset_state borra. SparseCategoricalAccuracy y "accuracy" cuentan aciertos.
train_step, test_step, compute_loss, metrics
Dentro de un modelo heredado: el paso de un lote al entrenar y al validar; la pérdida del compile más las multas; la lista de métricas.
keras.optimizers
SGD (con momentum y nesterov), Adam, AdamW (weight_decay), RMSprop. Opciones de recorte: clipnorm, clipvalue, global_clipnorm.
apply_gradients, iterations, build, learning_rate
Dar un paso con parejas (gradiente, peso); cuántos pasos lleva; crear sus variables por adelantado; el paso actual.
optimizers.schedules
Planificadores: ExponentialDecay, PiecewiseConstantDecay, CosineDecay (con warmup_steps), PolynomialDecay. Se pasan como learning_rate y cuentan pasos.
keras.callbacks
Objetos que fit avisa en momentos fijos: ModelCheckpoint (guardar), ReduceLROnPlateau (frenar), EarlyStopping (parar), CSVLogger, TensorBoard, LearningRateScheduler. Callback es la base para los tuyos (self.model, stop_training).
keras.regularizers
Multas: l2(λ) (suma de cuadrados), l1(λ) (suma de valores absolutos), l1_l2 (las dos).
keras.initializers
Cómo nacen los pesos: RandomNormal(stddev=…), "glorot_uniform" (el de serie), "he_normal" (para ReLU).
keras.mixed_precision
set_global_policy("mixed_float16") = calcular en 16 bits y guardar pesos en 32. El optimizador queda envuelto en un LossScaleOptimizer.
save, load_model, save_weights, load_weights, export
Guardar todo en .keras y cargarlo (custom_objects = tus clases); solo pesos en .weights.h5; exportar un SavedModel para producción.
register_keras_serializable
Apunta tu clase en el registro de Keras para que load_model la encuentre sola.

Paso 1 · Un bucle de entrenamiento propio: un paso a mano y cinco épocas (fragmento 1)

Para qué sirve Escribir a mano lo que hace fit. Primero un único paso con números que puedes comprobar con lápiz; después el bucle completo, con lotes, apply_gradients y la métrica Mean.

import numpy as np
import tensorflow as tf
import keras

keras.utils.set_random_seed(42)

# Datos sintéticos: y = 3*x1 - 2*x2 + 1 + ruido
rng = np.random.default_rng(0)
X = rng.normal(size=(256, 2)).astype("float32")
y = (3 * X[:, 0] - 2 * X[:, 1] + 1 + 0.1 * rng.normal(size=256)).astype("float32")
y = y.reshape(-1, 1)

# Un solo paso a mano con números pequeños: w = 1, b = 0, x = 2, y = 7
w = tf.Variable([[1.0]])
b = tf.Variable([0.0])
x1, y1 = tf.constant([[2.0]]), tf.constant([[7.0]])
with tf.GradientTape() as tape:
    pred = x1 @ w + b
    perdida = tf.reduce_mean(tf.square(y1 - pred))
grad_w, grad_b = tape.gradient(perdida, [w, b])
print("pérdida =", perdida.numpy(), "| dL/dw =", grad_w.numpy().ravel(), "| dL/db =", grad_b.numpy())
opt0 = keras.optimizers.SGD(learning_rate=0.1)
opt0.apply_gradients(zip([grad_w, grad_b], [w, b]))
print("tras apply_gradients: w =", w.numpy().ravel(), "b =", b.numpy())

# El bucle completo
modelo = keras.Sequential([keras.Input(shape=(2,)), keras.layers.Dense(1)])
optimizador = keras.optimizers.SGD(learning_rate=0.1)
funcion_perdida = keras.losses.MeanSquaredError()
media_perdida = keras.metrics.Mean(name="loss")
datos = tf.data.Dataset.from_tensor_slices((X, y)).batch(32)

for epoca in range(1, 6):
    media_perdida.reset_state()
    for lote_x, lote_y in datos:
        with tf.GradientTape() as cinta:
            pred = modelo(lote_x, training=True)
            perdida = funcion_perdida(lote_y, pred)
        grads = cinta.gradient(perdida, modelo.trainable_variables)
        optimizador.apply_gradients(zip(grads, modelo.trainable_variables))
        media_perdida.update_state(perdida)
    print(f"época {epoca}: loss = {media_perdida.result().numpy():.4f}")

pesos, sesgo = modelo.layers[0].get_weights()
print("w aprendidos:", pesos.ravel().round(2), "| b:", sesgo.round(2), "| pasos del optimizador:", int(optimizador.iterations.numpy()))

    with tf.GradientTape() as cinta:
        logits = modelo(x, training=True)                    # training=True activa Dropout

    m_loss.update_state(perdida)
    m_acc.update_state(y, logits)

@tf.function

    v_loss.update_state(perdida_fn(y, logits))
    v_acc.update_state(y, logits)

def build_model(hp):
    modelo = keras.Sequential([keras.Input(shape=(2,))])
    n_capas = hp.Int("n_capas", 1, 3)
    activacion = hp.Choice("activacion", ["relu", "tanh"])

    def __init__(self, factor=2.0, **kwargs):
        super().__init__(**kwargs)
        self.factor = factor

        return x * self.factor

import numpy as np

ds_val = tf.data.Dataset.from_tensor_slices((X_val, y_val)).batch(64)

modelo = keras.Sequential([
    keras.Input(shape=(64,)),
    keras.layers.Dense(64, activation="relu", kernel_regularizer=keras.regularizers.l2(1e-4)),
    keras.layers.Dropout(0.2),
    keras.layers.Dense(10),                                  # logits: sin softmax
])
pasos_por_epoca = len(ds_ent)
plan = keras.optimizers.schedules.CosineDecay(0.01, decay_steps=pasos_por_epoca * 8)
optimizador = keras.optimizers.Adam(plan, clipnorm=1.0)
optimizador.build(modelo.trainable_variables)                # crear las variables del optimizador ANTES de tf.function
perdida_fn = keras.losses.SparseCategoricalCrossentropy(from_logits=True)

m_loss = keras.metrics.Mean(name="loss")
m_acc = keras.metrics.SparseCategoricalAccuracy(name="acc")
v_loss = keras.metrics.Mean(name="val_loss")
v_acc = keras.metrics.SparseCategoricalAccuracy(name="val_acc")

@tf.function
def paso_entrenamiento(x, y):
    with tf.GradientTape() as cinta:
        logits = modelo(x, training=True)                    # training=True activa Dropout
        perdida = perdida_fn(y, logits) + tf.add_n(modelo.losses)    # + penalización L2
    grads = cinta.gradient(perdida, modelo.trainable_variables)
    optimizador.apply_gradients(zip(grads, modelo.trainable_variables))
    m_loss.update_state(perdida)
    m_acc.update_state(y, logits)

@tf.function
def paso_validacion(x, y):
    logits = modelo(x, training=False)                       # training=False apaga Dropout
    v_loss.update_state(perdida_fn(y, logits))
    v_acc.update_state(y, logits)

for epoca in range(1, 9):
    for m in (m_loss, m_acc, v_loss, v_acc):
        m.reset_state()
    for x, y_ in ds_ent:
        paso_entrenamiento(x, y_)
    for x, y_ in ds_val:
        paso_validacion(x, y_)
    print(f"época {epoca}: loss={m_loss.result():.3f} acc={m_acc.result():.3f} | val_loss={v_loss.result():.3f} val_acc={v_acc.result():.3f} | lr={float(optimizador.learning_rate):.4f}")

print("lotes por época:", pasos_por_epoca, "| tamaño del último lote:", len(X_ent) % 64)
print("trazados: entrenamiento =", paso_entrenamiento.experimental_get_tracing_count(),
      "| validación =", paso_validacion.experimental_get_tracing_count(),
      "| pasos del optimizador:", int(optimizador.iterations.numpy()))

class ModeloConPasoPropio(keras.Model):
    def train_step(self, data):
        x, y = data
        with tf.GradientTape() as cinta:
            y_pred = self(x, training=True)
            perdida = self.compute_loss(x=x, y=y, y_pred=y_pred)
        grads = cinta.gradient(perdida, self.trainable_variables)
        self.optimizer.apply_gradients(zip(grads, self.trainable_variables))
        for m in self.metrics:
            if m.name == "loss":
                m.update_state(perdida)
            else:
                m.update_state(y, y_pred)
        return {m.name: m.result() for m in self.metrics}

def un_paso(**kw):
    w = keras.Variable([0.0, 0.0])
    keras.optimizers.SGD(learning_rate=1.0, **kw).apply_gradients([(tf.constant([3.0, 4.0]), w)])
