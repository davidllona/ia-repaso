La interfaz en cuatro verbos

import gymnasium as gym

env = gym.make("CartPole-v1")                    # 1. crear el entorno
obs, info = env.reset(seed=0)                    # 2. empezar un episodio
terminado = truncado = False
while not (terminado or truncado):
    accion = env.action_space.sample()           #    (aquí decidiría tu agente)
    obs, r, terminado, truncado, info = env.step(accion)   # 3. actuar
env.close()                                      # 4. cerrar

Los espacios: Discrete y Box

  • Discrete(n): un entero de 0 a \( n-1 \). FrozenLake tiene Discrete(16) estados y Discrete(4) acciones; CartPole, Discrete(2) acciones. Se lee el tamaño con .n.
  • Box(low, high, shape, dtype): un array de números reales con límites. El estado de CartPole es un Box de forma (4,) con tipo float32. Los límites de posición (±4,8) y ángulo (±0,419 rad ≈ ±24°) los da el entorno, pero el episodio termina antes (a ±2,4 y ±12°); las velocidades no tienen límite (inf).

Esto decide qué algoritmo vale: con estados Discrete pequeños sirve una tabla Q; con un Box de reales hace falta una red neuronal (DQN).

terminated frente a truncated (y por qué importa)

Un episodio puede acabar por dos motivos muy distintos, y Gymnasium los separa:

  • terminated: el entorno llegó a un estado final de verdad (el palo cayó, se llegó a la meta, se cayó en el agujero). Tras él no hay futuro.
  • truncated: se cortó por un límite externo, normalmente de tiempo (500 pasos en CartPole, 100 en FrozenLake). El agente no ha hecho nada mal: simplemente se acabó el tiempo. El futuro seguía existiendo.

Para decidir cuándo parar el bucle, basta terminated or truncated. Pero al calcular el objetivo de aprendizaje, el futuro solo se anula en terminated. Si trataras un corte por tiempo como un final, enseñarías al agente que «tras 500 pasos no hay nada», y los valores cerca del límite saldrían subestimados. Por eso los fragmentos 12 y 13 guardan float(terminated) en el buffer, no truncated.

Ojo: el código antiguo que ya no funciona

Un tutorial de antes de 2022 empieza con import gym, escribe obs = env.reset() y obs, r, done, info = env.step(a). Con Gymnasium:

  • import gym da ModuleNotFoundError si solo tienes gymnasium instalado. Corrección: import gymnasium as gym.
  • obs = env.reset() no falla, pero obs es ahora una tupla (observación, info), y todo lo que venga después se rompe de formas confusas. Corrección: obs, info = env.reset().
  • obs, r, done, info = env.step(a) lanza ValueError: too many values to unpack (expected 4). Corrección: cinco valores, obs, r, terminated, truncated, info, y done = terminated or truncated.

Lo ves reproducido, con la salida real, en el fragmento 2. Además, render_mode="human" abre una ventana y no funciona en un servidor sin pantalla; render_mode="rgb_array" devuelve imágenes como arrays.

13 · DQN completo en CartPole (Keras + Gymnasium)

Para qué sirve Entrenar de punta a punta un agente DQN pequeño: red Q, red objetivo, replay buffer, ε decreciente y un paso de entrenamiento compilado con tf.function. Termina evaluando al agente sin explorar. Es un entrenamiento muy pequeño (300 episodios, ≈ 1 minuto en CPU), así que no llega a resolver el problema del todo: se ve aprender, pero con altibajos.

import random
from collections import deque
import numpy as np
import tensorflow as tf
import keras
from keras import layers
import gymnasium as gym

tf.config.threading.set_intra_op_parallelism_threads(1)
tf.config.threading.set_inter_op_parallelism_threads(1)
SEMILLA = 0
keras.utils.set_random_seed(SEMILLA)
random.seed(SEMILLA)
rng = np.random.default_rng(SEMILLA)

env = gym.make("CartPole-v1")
gamma, tam_lote = 0.99, 64
episodios, pasos_eps, sync_cada, empezar_en = 300, 5000, 500, 1000

def crear_red():
    return keras.Sequential([keras.Input(shape=(4,)),
                             layers.Dense(64, activation="relu"),
                             layers.Dense(64, activation="relu"),
                             layers.Dense(2)])

q = crear_red()
q_obj = crear_red()
q_obj.set_weights(q.get_weights())
optimizador = keras.optimizers.Adam(1e-3)
huber = keras.losses.Huber()
buffer = deque(maxlen=10000)

def como_lote(lote):
    s, a, r, s2, f = zip(*lote)
    return (np.array(s, "float32"), np.array(a, "int32"), np.array(r, "float32"),
            np.array(s2, "float32"), np.array(f, "float32"))

@tf.function
def entrenar_lote(s, a, r, s2, f):
    y = r + gamma * tf.reduce_max(q_obj(s2), axis=1) * (1.0 - f)
    with tf.GradientTape() as cinta:
        q_sa = tf.reduce_sum(q(s) * tf.one_hot(a, 2), axis=1)
        perdida = huber(y, q_sa)
    grads = cinta.gradient(perdida, q.trainable_variables)
    optimizador.apply_gradients(zip(grads, q.trainable_variables))

@tf.function
def accion_greedy(estado):
    return tf.argmax(q(estado[None, :]), axis=1)[0]

retornos, pasos_totales = [], 0
for ep in range(episodios):
    obs, _ = env.reset(seed=SEMILLA if ep == 0 else None)
    total, fin = 0.0, False
    while not fin:
        eps = max(0.05, 1.0 - pasos_totales / pasos_eps)
        if rng.random() < eps:
            a = int(rng.integers(2))
        else:
            a = int(accion_greedy(tf.constant(obs)))
        obs2, r, terminated, truncated, _ = env.step(a)
        buffer.append((obs, a, r, obs2, float(terminated)))
        obs, total, fin = obs2, total + r, terminated or truncated
        pasos_totales += 1
        if len(buffer) >= empezar_en:
            lote = random.sample(buffer, tam_lote)
            entrenar_lote(*como_lote(lote))
        if pasos_totales % sync_cada == 0:
            q_obj.set_weights(q.get_weights())
    retornos.append(total)
    if (ep + 1) % 30 == 0:
        print(f"episodio {ep + 1:3d} | pasos {pasos_totales:5d} | epsilon {eps:.2f} | retorno medio (últimos 30) {np.mean(retornos[-30:]):6.1f}")

greedy = []
for i in range(10):
    obs, _ = env.reset(seed=1000 + i)
    total, fin = 0.0, False
    while not fin:
        obs, r, terminated, truncated, _ = env.step(int(accion_greedy(tf.constant(obs))))
        total, fin = total + r, terminated or truncated
    greedy.append(total)
print("10 episodios con la política greedy (sin explorar):", greedy)
print("media greedy:", np.mean(greedy), "| azar puro, para comparar: unos 22")
