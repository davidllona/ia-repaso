On-policy y off-policy: SARSA frente a Q-learning

En todo agente conviven dos políticas. La política de comportamiento es la que genera la experiencia (la ε-greedy, que a veces explora y recomienda al azar). La política objetivo es la que queremos evaluar y mejorar. Si son la misma, el algoritmo es on-policy («sobre la política»); si son distintas, es off-policy.

SARSA se llama así por la secuencia que necesita para cada actualización: \( (s,\, a,\, r,\, s',\, a') \): estado, acción, recompensa, estado siguiente y acción siguiente.

El entorno clásico para verlo: una cuadrícula de 4×12. Hay que ir de la salida (abajo a la izquierda) a la meta (abajo a la derecha). Cada paso cuesta −1. Entre las dos hay un acantilado: pisarlo cuesta −100 y devuelve al agente a la salida. El camino más corto bordea el acantilado; uno más largo da un rodeo por arriba. Para llevarlo a StreamFlix, piensa que el acantilado son los «botones de cancelar suscripción» (−100) y que un paso al azar junto a ellos es una recomendación arriesgada.

On-policy y off-policy: SARSA frente a Q-learning

Un recomendador de StreamFlix a veces explora y enseña una película al azar. Si es una película muy rara, el usuario puede enfadarse y cancelar (−100). ¿Valora sus estrategias suponiendo que nunca se equivocará al explorar, o contando con esos despistes?

En todo agente conviven dos políticas. La política de comportamiento es la que genera la experiencia (la ε-greedy, que a veces explora y recomienda al azar). La política objetivo es la que queremos evaluar y mejorar. Si son la misma, el algoritmo es on-policy («sobre la política»); si son distintas, es off-policy.

Dos algoritmos, una sola diferencia
Q-learning (off-policy)SARSA (on-policy)
Objetivo\( r + \gamma \max_{a'} Q(s',a') \)\( r + \gamma\, Q(s',a') \), con \( a' \) la acción que de verdad se hará después
Supone que luego…actuará de forma óptimaseguirá explorando como hasta ahora (con ε)
Aprendeel valor del mejor camino posibleel valor del camino que realmente recorre, con sus despistes

SARSA se llama así por la secuencia que necesita para cada actualización: \( (s,\, a,\, r,\, s',\, a') \): estado, acción, recompensa, estado siguiente y acción siguiente.

Ejemplo numérico: el mismo paso, dos objetivos

\( \alpha = 0{,}5 \), \( \gamma = 1 \), \( r = -1 \), \( Q(s,a) = 0 \). En el estado siguiente \( s' \), el recomendador puede enseñar una comedia o un thriller: \( Q(s', \text{comedia}) = 2 \) y \( Q(s', \text{thriller}) = 5 \). El agente va a explorar y elige \( a' = \) comedia (valor 2).

ObjetivoError TD\( Q(s,a) \) nuevo
Q-learning\( -1 + 1 \cdot \max(2,5) = 4 \)\( 4 - 0 = 4 \)\( 0 + 0{,}5 \cdot 4 = 2 \)
SARSA\( -1 + 1 \cdot 2 = 1 \)\( 1 - 0 = 1 \)\( 0 + 0{,}5 \cdot 1 = 0{,}5 \)

Q-learning se queda con el 5: «si desde aquí hago lo mejor, voy muy bien». SARSA dice: «voy a hacer una recomendación torpe de exploración, así que este paso vale menos». Si la exploración es peligrosa, SARSA lo «nota».

El acantilado

El entorno clásico para verlo: una cuadrícula de 4×12. Hay que ir de la salida (abajo a la izquierda) a la meta (abajo a la derecha). Cada paso cuesta −1. Entre las dos hay un acantilado: pisarlo cuesta −100 y devuelve al agente a la salida. El camino más corto bordea el acantilado; uno más largo da un rodeo por arriba. Para llevarlo a StreamFlix, piensa que el acantilado son los «botones de cancelar suscripción» (−100) y que un paso al azar junto a ellos es una recomendación arriesgada.

  • Q-learning aprende el camino óptimo: el que va pegado al borde (13 pasos), el de las recomendaciones más arriesgadas. Pero como entrena con ε = 0,1, cada diez pasos aproximadamente uno es al azar, y a esa distancia del borde un paso al azar es peligroso: cae al precipicio de vez en cuando (el usuario cancela).
  • SARSA tiene en cuenta que explorará: su objetivo usa la acción que de verdad elegirá, que a veces será un movimiento al azar. Los estados junto al acantilado salen peor valorados, así que aprende el rodeo de 17 pasos, más seguro.

El fragmento 10 lo mide con 5 semillas: durante el entrenamiento, SARSA gana de media −32,84 por episodio y Q-learning −51,25 (más negativo: se cae más). Pero sin explorar, el camino de Q-learning cuesta −13 y el de SARSA −17. Cada uno es mejor según con qué vara se mida.

Regla fácil

Q-learning aprende cómo jugar si fuera perfecto; SARSA aprende cómo jugar siendo como eres. Si más tarde vas a desplegar la política sin exploración (ε = 0), Q-learning es lo que quieres. Si lo que importa es lo que ganas mientras aprendes y explorar es peligroso (un robot real o un recomendador con usuarios reales que pueden cancelar), conviene SARSA, o hacer que ε baje a 0. Existe una variante, Expected SARSA, que en vez de la acción elegida usa el promedio de los valores según la política, con menos ruido.

Dos consecuencias para lo que viene: los algoritmos off-policy pueden reutilizar experiencia vieja (el replay buffer de DQN solo tiene sentido porque Q-learning es off-policy), mientras que los on-policy (SARSA, A2C, PPO) necesitan datos recién generados por la política actual.

7 · Una actualización de Q-learning (la regla TD), con las cuentas visibles

Para qué sirve Aplicar la regla \( Q(s,a) \leftarrow Q(s,a) + \alpha\,[\,r + \gamma \max_{a'} Q(s',a') - Q(s,a)\,] \) a mano y en código, incluyendo el caso de un paso terminal. Es el núcleo de cualquier algoritmo de Q-learning.

import numpy as np

alpha, gamma = 0.1, 0.9

Q = np.zeros((3, 2))
Q[0, 1] = 0.40
Q[1] = [0.2, 0.9]

def actualizar(Q, s, a, r, s_sig, terminado):
    objetivo = r + gamma * Q[s_sig].max() * (not terminado)
    error_td = objetivo - Q[s, a]
    Q[s, a] += alpha * error_td
    return objetivo, error_td

objetivo, error_td = actualizar(Q, s=0, a=1, r=0.0, s_sig=1, terminado=False)
print("objetivo  r + γ·max Q(s',·) =", round(objetivo, 4))
print("error TD  objetivo - Q(s,a) =", round(error_td, 4))
print("Q(0,1) nuevo =", round(Q[0, 1], 4))

objetivo, error_td = actualizar(Q, s=1, a=1, r=1.0, s_sig=2, terminado=True)
print("paso terminal: objetivo =", objetivo, "| Q(1,1) nuevo =", round(Q[1, 1], 4))

En el paso terminal el objetivo es exactamente la recompensa, 1,0, porque después de un estado final no hay futuro que descontar; el valor sube de 0,90 a 0,91. Olvidar ese (not terminado) es uno de los fallos más frecuentes: el agente creería que tras la meta sigue habiendo recompensas y los valores se inflan.

10 · SARSA frente a Q-learning en el acantilado (CliffWalking-v1)

Para qué sirve Entrenar los dos algoritmos con el mismo código, cambiando solo una línea (el objetivo), y comparar el camino que aprende cada uno y lo que gana mientras entrena. Es la prueba en código de la diferencia entre on-policy y off-policy.

import numpy as np
import gymnasium as gym

env = gym.make("CliffWalking-v1")
FILAS, COLS = 4, 12
alpha, gamma, epsilon = 0.5, 1.0, 0.1

def elegir(Q, s, rng):
    if rng.random() < epsilon:
        return int(rng.integers(4))
    return int(rng.choice(np.flatnonzero(Q[s] == Q[s].max())))

def entrenar(algoritmo, episodios=500, semilla=0):
    rng = np.random.default_rng(semilla)
    Q = np.zeros((48, 4))
    recompensas = []
    for ep in range(episodios):
        s, _ = env.reset(seed=semilla if ep == 0 else None)
        a = elegir(Q, s, rng)
        total, pasos, fin = 0.0, 0, False
        while not fin and pasos < 500:
            s2, r, terminado, truncado, _ = env.step(a)
            a2 = elegir(Q, s2, rng)
            if algoritmo == "sarsa":
                siguiente = Q[s2, a2]
            else:
                siguiente = Q[s2].max()
            Q[s, a] += alpha * (r + gamma * siguiente * (not terminado) - Q[s, a])
            s, a = s2, a2
            total += r
            pasos += 1
            fin = terminado or truncado
        recompensas.append(total)
    return Q, np.array(recompensas)

def camino_greedy(Q):
    s, _ = env.reset()
    ruta = [s]
    while s != 47 and len(ruta) < 50:
        s, _, _, _, _ = env.step(int(Q[s].argmax()))
        ruta.append(s)
    return ruta

def dibujar(ruta):
    tablero = [["."] * COLS for _ in range(FILAS)]
    for c in range(1, COLS - 1):
        tablero[3][c] = "C"
    for celda in ruta:
        tablero[celda // COLS][celda % COLS] = "*"
    tablero[3][0], tablero[3][11] = "S", "G"
    return ["".join(f) for f in tablero]

for alg in ["sarsa", "qlearning"]:
    medias = []
    for semilla in range(5):
        Q, rec = entrenar(alg, semilla=semilla)
        medias.append(rec[-100:].mean())
    Q, rec = entrenar(alg, semilla=0)
    ruta = camino_greedy(Q)
    print(f"{alg}: recompensa media por episodio (últimos 100, 5 semillas) = {np.mean(medias):.2f}")
    print(f"{alg}: camino greedy de {len(ruta) - 1} pasos")
    print("\n".join(dibujar(ruta)))
