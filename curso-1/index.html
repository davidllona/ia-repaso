Machine Learning con Python

Qué es aprender de datos y cómo se hace de verdad: preparar datos, regresión, clasificación, agrupación, evaluación honesta y un proyecto completo con scikit-learn.

Qué vas a entender

Qué significa que un ordenador aprenda, qué algoritmos existen y cuándo usar cada uno, cómo medir si un modelo funciona de verdad y cómo organizar un proyecto de principio a fin.

Lo que conviene saber antes

Ninguno. Si sabes qué es una variable y una tabla, ya puedes empezar. Python se explica cuando aparece.
