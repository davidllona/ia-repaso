¿Cuántos grupos? Tres métricas que no coinciden

Probamos K de 2 a 7 con n_init=10 (K-Means empieza desde posiciones al azar; con 10 intentos se queda con el mejor) y calculamos tres cosas:

  • Inercia: suma de las distancias² de cada usuario al centro de su grupo. Siempre baja al subir K (con K = 5000 sería cero), así que sola no sirve para elegir; se usa para ver el «codo».
  • Silhouette (más alto es mejor, entre −1 y +1): para cada usuario compara lo cerca que está de los suyos (a) con lo cerca que está del grupo vecino más próximo (b): \( s = (b - a)/\max(a, b) \).
  • Davies-Bouldin (más bajo es mejor): para cada grupo busca el grupo más «parecido» (dispersión de los dos entre la distancia entre sus centros) y promedia. Grupos compactos y bien separados dan valores bajos.
Ejemplo numérico: silhouette de un punto

Mide a cada usuario por las horas que ve a la semana. Grupo A (los ocasionales) = {1, 2, 3} horas y grupo B (los maratonianos) = {8, 9, 10} horas. Para el usuario que ve 2 horas:

  1. a = distancia media (en horas) a los demás de su grupo = (|2−1| + |2−3|) / 2 = 1.
  2. b = distancia media a los puntos del otro grupo = (6 + 7 + 8) / 3 = 7.
  3. s = (7 − 1) / max(1, 7) = 6 / 7 = 0,857: está muy bien asignado. Si fuera un usuario «a medio camino» entre los dos grupos (a = 4, b = 5), s = 1/5 = 0,2.

Qué enseña esta tabla, que es una de las más honestas del módulo:

  • La inercia baja siempre: no decide nada.
  • El Silhouette elige K = 4 (0,228) y el Davies-Bouldin elige K = 3 (1,559). No coinciden, y no pasa nada: son dos formas distintas de medir «grupos bien separados».
  • Todos los Silhouette son bajos (≈ 0,2). Valores por debajo de 0,25 indican estructura débil: los grupos se solapan. Esperable: los usuarios son un continuo de comportamientos, no cuatro bolas separadas.

Entonces, ¿cómo se decide? Con el sentido de negocio. Las métricas acotan el rango (entre 3 y 4), y se elige el K para el que puedes ponerle nombre y acción a cada grupo. Elijo K = 4 y compruebo si tiene sentido.

Ojo: K-Means tiene supuestos

K-Means busca grupos «redondos» y de tamaño parecido alrededor de un centro, y cada punto tiene que pertenecer a algún grupo (aunque sea un caso raro). Es sensible a la escala (por eso estandarizamos) y a los valores atípicos, que arrastran los centros. Si los grupos tuvieran formas raras o hubiera ruido, DBSCAN (siguiente sección) sería mejor candidato.

Para qué sirve Prepara las columnas de comportamiento (imputar y escalar), prueba K-Means con 2 a 7 grupos midiendo cada uno con dos métricas internas y, por último, ajusta K = 4 y describe los grupos por sus medias.

cluster_features = ['HorasMes', 'DiasDesdeUltimoUso', 'PeliculasVistas', 'SeriesVistas',
                    'ProblemasPago', 'ErroresApp', 'Dispositivos']
X_cluster = df[cluster_features].copy()

cluster_scaler = StandardScaler()
X_cluster_scaled = cluster_scaler.fit_transform(X_cluster_imputed)

for k in range(2, 8):
    model = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = model.fit_predict(X_cluster_scaled)
    silhouette = silhouette_score(X_cluster_scaled, labels)
    dbi = davies_bouldin_score(X_cluster_scaled, labels)

k_results_df = pd.DataFrame(k_results)
print(k_results_df)

kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
df['Cluster'] = kmeans.fit_predict(X_cluster_scaled)
print(df['Cluster'].value_counts())
cluster_summary = df.groupby('Cluster')[cluster_features].mean()
print(cluster_summary)
print(df.groupby('Cluster')[['Cancelado', 'HorasProximoMes']].mean())

33 · K-Means con K de 2 a 7: inercia, Silhouette y Davies-Bouldin

Para qué sirve Prepara los datos para agrupar (imputar y estandarizar las numéricas) y calcula, para cada número de grupos, tres medidas para decidir cuántos hay.

from sklearn.cluster import KMeans
from sklearn.metrics import davies_bouldin_score, silhouette_score

Z = pre_num.fit_transform(df[numericas])
print("matriz para agrupar:", Z.shape, "| media de cada columna ≈", Z.mean(axis=0).round(2)[:3], "| desviación ≈", Z.std(axis=0).round(2)[:3])

filas = []
for k in range(2, 8):
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(Z)
    filas.append({"K": k, "inercia": km.inertia_, "silhouette": silhouette_score(Z, km.labels_),
                  "davies_bouldin": davies_bouldin_score(Z, km.labels_)})
print(pd.DataFrame(filas).set_index("K").round(3))
