Antes de empezar: las piezas

Python es un lenguaje de programación: escribes órdenes, una por línea, y el ordenador las ejecuta de arriba abajo.

Python trae lo básico. Para tablas, cálculos o Machine Learning se usan librerías: código que otras personas ya escribieron y empaquetaron para que lo reutilices. Se instalan aparte (con pip install; en Google Colab ya vienen). Una librería grande se ordena en cajones, llamados módulos, y dentro de cada cajón están las piezas: funciones y clases (moldes para fabricar objetos, como un modelo).

  • LIBRERÍAsklearn
  • CAJÓN (MÓDULO)tree
  • PIEZADecisionTreeClassifier

import trae una librería a tu programa. Hasta que no la importas, Python no conoce sus piezas y da el error NameError. Hay tres formas:

  • import pandas as pd → trae la librería entera con un apodo. Luego se usa pd.DataFrame(…).
  • from sklearn.tree import DecisionTreeClassifier → trae solo una pieza de un cajón. Luego se usa sin prefijo: DecisionTreeClassifier(…).
  • import re → la librería entera, sin apodo: re.findall(…).
Analogía

Una librería es una caja de herramientas. import pandas as pd es traerte la caja entera y ponerle una etiqueta corta. from … import … es abrir un cajón y sacar solo el martillo.

Reglas a mano frente a un modelo que aprende la regla

Para qué sirve Comparar las dos formas de la lección 1. En la de arriba, el 20 lo pone una persona a ojo. En la de abajo nadie escribe el 18,5: lo encuentra fit.

from sklearn.tree import DecisionTreeClassifier

# --- Programación tradicional: las reglas las escribimos nosotros ---
def cancela_por_reglas(dias_sin_entrar):
    if dias_sin_entrar > 20:
        return 1
    return 0

# --- Machine Learning: damos ejemplos y el algoritmo encuentra la regla ---
X = [[2], [5], [8], [12], [25], [31], [40], [55]]   # días sin entrar
y = [0, 0, 0, 0, 1, 1, 1, 1]                        # 0 = se queda, 1 = cancela

modelo = DecisionTreeClassifier(max_depth=1, random_state=42)
modelo.fit(X, y)

print("Umbral aprendido:", modelo.tree_.threshold[0])
print("Predicciones:", modelo.predict([[10], [28]]))

Fragmento 8 · Ver el sobreajuste con números

Para qué sirve Comprobar que al subir la complejidad el error en train baja siempre, pero el de test, a partir de cierto punto, se dispara. Es el porqué del max_depth=1 del paso 6.

import numpy as np

rng = np.random.default_rng(42)

def verdad(x):
    return 0.8 * np.sin(2.4 * x) + 0.25 * x

# 20 puntos para entrenar y 200 para probar, con ruido
x_train = rng.uniform(-1, 1, 20)
y_train = verdad(x_train) + rng.normal(0, 0.2, 20)
x_test = rng.uniform(-1, 1, 200)
y_test = verdad(x_test) + rng.normal(0, 0.2, 200)

for grado in (1, 3, 12):
    coef = np.polyfit(x_train, y_train, grado)
    error_train = np.mean((np.polyval(coef, x_train) - y_train) ** 2)
    error_test = np.mean((np.polyval(coef, x_test) - y_test) ** 2)
    print(f"grado {grado:2d} | error train = {error_train:.3f} | error test = {error_test:.3f}")

import numpy as np
import pandas as pd

peliculas = ["Matrix", "E.T.", "Indiana Jones", "Iron Man", "Thor", "Shrek"]
usuarios = ["David", "B", "C", "D"]

# Matriz usuario x película: 1 = la ha visto
vistas = pd.DataFrame(
    [[1, 1, 1, 0, 0, 0],      # David
     [1, 1, 1, 0, 1, 0],      # B: lo mismo que David y además Thor
     [0, 0, 0, 0, 0, 1],      # C: solo Shrek
     [1, 1, 0, 1, 0, 0]],     # D: Matrix, E.T. e Iron Man
    index=usuarios, columns=peliculas)

# Características de cada película: [Acción, Ciencia ficción, Aventura, Superhéroes, Comedia]
rasgos = pd.DataFrame(
    [[1, 1, 0, 0, 0],   # Matrix
     [0, 1, 0, 0, 0],   # E.T.
     [1, 0, 1, 0, 0],   # Indiana Jones
     [1, 1, 0, 1, 0],   # Iron Man
     [1, 1, 0, 1, 0],   # Thor
     [0, 0, 0, 0, 1]],  # Shrek
    index=peliculas, columns=["Acción", "Ciencia ficción", "Aventura", "Superhéroes", "Comedia"])

def coseno(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

# --- Content-based: "te gusta X -> cosas parecidas a X" ---
perfil = rasgos.loc[vistas.loc["David"] == 1].mean()      # gustos medios de David
content = rasgos.apply(lambda fila: coseno(perfil.values, fila.values), axis=1)

# --- Collaborative: "personas parecidas a ti también vieron..." ---
yo = vistas.loc["David"].values
parecido = vistas.apply(lambda fila: coseno(yo, fila.values), axis=1).drop("David")
collab = (vistas.drop("David").T * parecido).T.sum()

nuevas = vistas.loc["David"] == 0                          # solo lo que aún no ha visto
print("Parecido de David con los demás:", parecido.round(2).to_dict())
tabla = pd.DataFrame({"content": content[nuevas], "collab": collab[nuevas]}).round(2)
tabla["collab_norm"] = (tabla["collab"] / tabla["collab"].max()).round(2)
tabla["hibrido"] = (0.5 * tabla["content"] + 0.5 * tabla["collab_norm"]).round(2)
print(tabla.sort_values("hibrido", ascending=False))

import numpy as np
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(7)

def clientes_del_mes(umbral_real, n=400):
    """Días sin entrar de n clientes y si cancelaron. Cancelar = pasar del umbral (con un 5 % de ruido)."""
    dias = rng.uniform(0, 60, n)
    cancela = (dias > umbral_real).astype(int)
    ruido = rng.random(n) < 0.05
    return dias.reshape(-1, 1), np.where(ruido, 1 - cancela, cancela)

# Los hábitos cambian: cada mes la gente cancela con menos días sin entrar
umbrales = [20, 20, 18, 15, 12, 10]
meses = [clientes_del_mes(u) for u in umbrales]

# Mes 0: entrenamos y lo ponemos en producción
modelo = DecisionTreeClassifier(max_depth=1, random_state=0).fit(*meses[0])
print(f"Entrenado en el mes 0: umbral aprendido = {modelo.tree_.threshold[0]:.1f} días")

# Monitorización: con el modelo congelado, ¿cuánto acierta cada mes?
for mes, (X, y) in enumerate(meses):
    print(f"mes {mes}: accuracy = {modelo.score(X, y):.3f}")

# Reentrenamiento con los datos recientes (meses 4 y 5)
X_rec = np.vstack([meses[4][0], meses[5][0]])
y_rec = np.concatenate([meses[4][1], meses[5][1]])
nuevo = DecisionTreeClassifier(max_depth=1, random_state=0).fit(X_rec, y_rec)
X6, y6 = clientes_del_mes(10)
print(f"Reentrenado: umbral = {nuevo.tree_.threshold[0]:.1f} días")
print(f"mes 6, modelo viejo = {modelo.score(X6, y6):.3f} | modelo nuevo = {nuevo.score(X6, y6):.3f}")

Fragmento 17 · Tokenización, sentimiento y entidades a mano

Para qué sirve Lo que hacen las librerías de lenguaje, escrito desde cero: trocear un texto en tokens, puntuar el sentimiento de una reseña de cine con un diccionario y reconocer entidades.

De la lección 6. 

import re

def tokenizar(texto):
    """Trocea un texto en palabras (tokens), quitando la puntuación."""
    return re.findall(r"\w+", texto)

print(tokenizar("Me encanta Toy Story"))
print(tokenizar("¡La película ha sido increíble, repetiría!"))

# --- Análisis de sentimiento "de diccionario" ---
POSITIVAS = {"increíble", "espectacular", "genial", "bueno", "rápido"}
NEGATIVAS = {"horrible", "lento", "malo", "decepcionante", "aburrido"}

def sentimiento(texto):
    palabras = [p.lower() for p in tokenizar(texto)]
    puntos = sum(p in POSITIVAS for p in palabras) - sum(p in NEGATIVAS for p in palabras)
    return "POSITIVO" if puntos > 0 else "NEGATIVO" if puntos < 0 else "NEUTRO"

for frase in ["La película ha sido increíble",
              "Este final es espectacular",
              "El guion es lento y el final es horrible",
              "No es nada bueno"]:
    print(f"{sentimiento(frase):9s} <- {frase}")

# --- Reconocimiento de entidades (NER) con un diccionario ---
ENTIDADES = {"Netflix": "ORGANIZACIÓN", "Corea": "LUGAR", "Madrid": "LUGAR"}
for palabra in tokenizar("Netflix grabó una serie nueva en Corea"):
    if palabra in ENTIDADES:
        print(f"{palabra} -> {ENTIDADES[palabra]}")
