X es lo que el modelo sabe; y, lo que debe adivinar

Tres círculos (IA, Machine Learning, Deep Learning) y cinco palabras que saldrán en todos los módulos: features, target, modelo, parámetro e hiperparámetro.

Índice del módulo

Netflix tiene una tabla con Edad, Plan, HorasMes y Canceló. Quiere predecir quién cancelará. ¿Cuántas columnas le enseña al modelo para que aprenda: las 4 o solo 3?

Solo 3. «Canceló» es la respuesta, lo que queremos que adivine: se usa para corregirle, no como información. Si se la damos como una columna más, el modelo «acierta» copiando la respuesta y no aprende nada útil para clientes nuevos.

Tres círculos, uno dentro de otro

Este curso trabaja sobre todo con ML clásico (regresión, árboles, KNN, K-Means…). El Deep Learning (redes neuronales) domina imágenes, voz y lenguaje, y llega en los cursos 2 y 3.

Las piezas: una tabla, dos papeles

Todo problema de ML empieza en una tabla (el dataset): cada fila es un ejemplo (un cliente) y cada columna, una variable.

Las columnas juegan dos papeles. Las features (características) son lo que el modelo conoce: Edad, Plan, HorasMes. El target (objetivo) es lo que debe predecir: Canceló. En el código, las features se llaman X y el target y.

Regla fácil

X = lo que el modelo sabe. y = lo que queremos que aprenda a predecir. El algoritmo es la receta; el modelo, el plato ya cocinado con tus datos.

Con números: parámetros e hiperparámetros

Ejemplo numérico

Un modelo sencillo estima la nota de una película con cuatro números aprendidos (sus parámetros): 0,43 · −1,72 · 0,08 · 3,51. Para una película de 2 horas, que es secuela (1), con 5 actores famosos y final feliz (1):

  1. 0,43 · 2 − 1,72 · 1 + 0,08 · 5 + 3,51 · 1
  2. = 0,86 − 1,72 + 0,40 + 3,51 = 3,05 (cifras inventadas).

Esos cuatro números los aprendió el modelo con los datos, como el umbral 18,5 de la lección 1. En cambio, «cuántos árboles tiene el Random Forest» o «la K de KNN» los eliges tú antes de entrenar: son hiperparámetros, y cambian cómo aprende.

Analogía

Aprender guitarra: lo que aprenden tus dedos (los acordes) son los parámetros. Cuántas horas practicas y con qué método son los hiperparámetros: los decides desde fuera.

Cambias el número de árboles de un Random Forest de 100 a 500. ¿Has tocado un parámetro o un hiperparámetro? ¿Hace falta volver a entrenar?

Un hiperparámetro: lo configuras tú desde fuera. Y sí, hay que reentrenar: los parámetros (lo que cada árbol aprende: sus umbrales) se vuelven a calcular con la nueva configuración. Regla: hiperparámetro = lo configuras; parámetro = lo aprende.

En tres líneas

  • IA ⊃ Machine Learning ⊃ Deep Learning. Este curso: ML clásico.
  • Features (X) = lo que el modelo conoce; target (y) = lo que debe predecir. Nunca metas el target en X.
  • Parámetros los aprende el modelo; hiperparámetros los eliges tú antes de entrenar.

IA, Machine Learning y Deep Learning

Estas tres palabras se usan a veces como si fueran lo mismo. No lo son: son tres círculos, uno dentro de otro.

Inteligencia Artificial (IA)

El campo más amplio: construir sistemas que realicen tareas que asociamos con inteligencia (reconocer una cara, entender una pregunta, detectar fraude, traducir, conducir, generar una imagen…).

No toda IA usa Machine Learning: un programa de ajedrez con reglas escritas a mano también es IA.

Machine Learning (ML)

La parte de la IA que aprende de datos en vez de seguir reglas escritas por una persona. Regresión, árboles, KNN, SVM, Random Forest, K-Means… En este curso trabajamos sobre todo con ML clásico.

Deep Learning (DL)

Una rama del ML basada en redes neuronales profundas. Domina imágenes, voz, lenguaje y modelos generativos. Es el tema de los Cursos 2 y 3.

Error típico

Dejar el target dentro de X. Si en las features incluyes «FechaDeCancelación», el modelo tendrá prácticamente la respuesta y sacará resultados espectaculares… que desaparecerán en la vida real, porque esa fecha todavía no existe cuando quieres predecir. Se llama data leakage y lo estudiaremos con calma en el módulo 5.

Algoritmo, modelo, entrenamiento y predicción

Analogía

El algoritmo es la receta. Los datos son los ingredientes. El entrenamiento es cocinar. El modelo es el plato terminado. La predicción es servir ese plato a un cliente nuevo.

  • Algoritmo: el método para aprender (Regresión Lineal, KNN, Random Forest…). No existe uno «mejor» para todo: depende del problema, del tamaño de los datos, del coste de equivocarse…
  • Modelo: lo que sale después de entrenar el algoritmo con tus datos. «Random Forest» es un algoritmo; «el Random Forest entrenado con mis 5.000 clientes» es un modelo.
  • Entrenamiento: el proceso por el que el modelo ajusta sus números internos.
  • Predicción: usar el modelo entrenado con datos nuevos.

Así entrena un modelo, en el fondo, siempre:

  • Predice
  • Compara con la realidad
  • Mide el error
  • Ajusta sus parámetros
  • Repite

Parámetros e hiperparámetros

Son dos cosas distintas que se confunden mucho:

Parámetro

Un número que aprende el propio modelo durante el entrenamiento.

Ejemplo: en el umbral de antes, el 18,5. En una recta, la pendiente y el intercepto.

Hiperparámetro

Un ajuste que eliges tú antes de entrenar: configura cómo aprende.

Ejemplos: el número de árboles de un Random Forest, la K de KNN, la fuerza de la regularización (alpha).

Analogía

Aprender guitarra. Lo que tus dedos aprenden (los acordes) son los parámetros. Cuántas horas practicas al día o qué método sigues son los hiperparámetros: los decides tú desde fuera, y cambian lo bien que aprendes.

20 · Crear no es entrenar: hiperparámetros, parámetros y predict_proba

Para qué sirve Ver con código la diferencia entre lo que configuras tú (hiperparámetros), lo que aprende el modelo (parámetros), qué pasa si llamas a predict antes de fit, y que cambiar de algoritmo solo cambia una línea. Reutiliza el reparto del fragmento 19.

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.linear_model import LogisticRegression
from sklearn.exceptions import NotFittedError

datos = load_breast_cancer()
X_train, X_test, y_train, y_test = train_test_split(
    datos.data, datos.target, test_size=0.3, stratify=datos.target, random_state=42)
escalador = StandardScaler().fit(X_train)
X_train_e, X_test_e = escalador.transform(X_train), escalador.transform(X_test)

# CREAR un modelo no es ENTRENARLO
clf = SVC(C=1.0, gamma="scale")
print("hiperparámetros (los eliges tú):", {k: clf.get_params()[k] for k in ("C", "kernel", "gamma")})
try:
    clf.predict(X_test_e[:1])
except NotFittedError:
    print("predict antes de fit -> NotFittedError")

clf.fit(X_train_e, y_train)
print("parámetros aprendidos: vectores de soporte =", clf.support_vectors_.shape[0],
      "| intercepto =", clf.intercept_.round(3))

# predict da la clase; el resto de métodos dan más información
paciente = X_test_e[:1]
print("SVC predict:", clf.predict(paciente), "(0 = maligno, 1 = benigno)")

# Otro algoritmo, la MISMA interfaz: solo cambia la línea que crea el modelo
logistica = LogisticRegression(max_iter=1000).fit(X_train_e, y_train)
print("Logística predict      :", logistica.predict(paciente))
print("Logística predict_proba:", logistica.predict_proba(paciente).round(3), "[P(maligno), P(benigno)]")
