Analogía

Cinco amigos tienen que decidir si merece la pena ver la película que se estrena esta noche.

  • La estadística cuenta: «de las películas con este tráiler y este reparto, el 75 % acabó gustando». Decide con probabilidades.
  • La cotilla pregunta a los amigos que tienen los gustos más parecidos a los tuyos: «a vosotros, que veis lo mismo que él, ¿os gustó?». Decide con vecinos.
  • La cartógrafa dibuja un mapa de películas (más acción hacia un lado, más humor hacia el otro) y traza una línea que separa «las que te gustan» de «las que no». Decide con fronteras.
  • El interrogador juega a las veinte preguntas: «¿es de comedia? ¿dura menos de dos horas?…». Decide con árboles.
  • El comité reúne a muchos de los anteriores y se queda con la opinión mayoritaria. Decide con ensembles.

1 · Gini, entropía y ganancia de información calculadas a mano (y comprobadas con scikit-learn)

Para qué sirve Reproducir con código las cuentas del apartado de árboles: cuánto «desorden» tiene un grupo de clientes y cuánto desorden quita cada pregunta posible. Al final comprobamos que un árbol de scikit-learn elige la misma pregunta que nosotros.

import numpy as np
from sklearn.tree import DecisionTreeClassifier

# 10 clientes: días sin entrar, horas de uso al mes, ¿canceló? (1 = sí)
dias  = [3, 6, 9, 14, 17, 21, 26, 33, 41, 52]
horas = [30, 25, 8, 20, 5, 12, 6, 4, 10, 2]
y = np.array([0, 0, 1, 0, 1, 0, 1, 1, 1, 1])

def gini(etiquetas):
    p = np.bincount(etiquetas, minlength=2) / len(etiquetas)
    return 1 - np.sum(p ** 2)

def entropia(etiquetas):
    p = np.bincount(etiquetas, minlength=2) / len(etiquetas)
    p = p[p > 0]
    return -np.sum(p * np.log2(p))

def ganancia(medida, variable, umbral):
    variable = np.array(variable)
    izq, der = y[variable <= umbral], y[variable > umbral]
    ponderada = (len(izq) * medida(izq) + len(der) * medida(der)) / len(y)
    return medida(y) - ponderada

print("Nodo raíz: Gini =", round(gini(y), 4), "| entropía =", round(entropia(y), 4))
print("dias  <= 23.5 -> ganancia Gini =", round(ganancia(gini, dias, 23.5), 4))
print("horas <= 11  -> ganancia Gini =", round(ganancia(gini, horas, 11), 4))
print("dias  <= 23.5 -> ganancia entropía =", round(ganancia(entropia, dias, 23.5), 4))
print("horas <= 11  -> ganancia entropía =", round(ganancia(entropia, horas, 11), 4))

X = np.column_stack([dias, horas])
arbol = DecisionTreeClassifier(max_depth=1, random_state=0).fit(X, y)
print("sklearn pregunta:", ["dias", "horas"][arbol.tree_.feature[0]], "<=", arbol.tree_.threshold[0])
print("sklearn impureza del nodo raíz:", arbol.tree_.impurity[0])

Las dos medidas coinciden en cuál es la mejor pregunta, y scikit-learn pregunta justo por horas <= 11.0 y confirma el Gini de 0,48 en la raíz.

2 · DecisionTreeClassifier: criterion, max_depth, export_text y feature_importances_

Para qué sirve Entrenar un árbol de verdad con las flores de iris, leer sus preguntas como si fueran un if anidado y ver qué variables han pesado más en las decisiones.

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, stratify=iris.target, random_state=42
)

for criterio in ("gini", "entropy"):
    arbol = DecisionTreeClassifier(criterion=criterio, max_depth=3, random_state=42)
    arbol.fit(X_train, y_train)
    print(f"{criterio:8s} | train = {arbol.score(X_train, y_train):.3f} | test = {arbol.score(X_test, y_test):.3f}")

arbol = DecisionTreeClassifier(criterion="gini", max_depth=3, random_state=42).fit(X_train, y_train)
print(export_text(arbol, feature_names=list(iris.feature_names)))

for nombre, imp in zip(iris.feature_names, arbol.feature_importances_):
    print(f"{nombre:20s} {imp:.3f}")
print("hojas:", arbol.get_n_leaves(), "| profundidad:", arbol.get_depth())

4 · DecisionTreeRegressor: predecir un número con un árbol

Para qué sirve Comprobar con código el árbol de regresión del apartado: umbral, valor de cada hoja, predicciones en forma de escalón y qué pasa cuando se le deja memorizar.

import numpy as np
from sklearn.tree import DecisionTreeRegressor, export_text

# El ejemplo de la teoría: 6 puntos con un salto claro entre x = 3 y x = 4
x = np.array([[1], [2], [3], [4], [5], [6]])
y = np.array([10, 12, 11, 30, 32, 31])

arbol = DecisionTreeRegressor(max_depth=1, random_state=0).fit(x, y)
print("umbral:", arbol.tree_.threshold[0])
print("valor de cada nodo (raíz, hoja izq., hoja dcha.):", arbol.tree_.value.ravel())
print("predicciones para x = 2, 3.4, 3.6, 5.5:", arbol.predict([[2], [3.4], [3.6], [5.5]]))
print(export_text(arbol, feature_names=["x"]))

# Más profundidad = más escalones: con un dato por hoja, memoriza
profundo = DecisionTreeRegressor(random_state=0).fit(x, y)
print("sin límite de profundidad, hojas:", profundo.get_n_leaves(), "| predicciones =", profundo.predict(x))

5 · KNN paso a paso: distancias, vecinos y votos (a mano y con scikit-learn)

Para qué sirve Calcular a mano la distancia de un cliente nuevo a todos los demás, ordenarlos, votar con distintos valores de K y comprobar que KNeighborsClassifier hace exactamente lo mismo.

import numpy as np
from sklearn.neighbors import KNeighborsClassifier

# columnas: horas de uso al mes, días sin entrar | etiqueta: 0 = se queda, 1 = cancela
X = np.array([[30, 3], [25, 8], [20, 5], [6, 25], [10, 18], [12, 30], [16, 12], [22, 14]])
y = np.array([0, 0, 0, 1, 1, 1, 1, 0])
nuevo = np.array([[14, 14]])

# A mano: distancia euclídea del cliente nuevo a cada cliente
distancias = np.sqrt(((X - nuevo) ** 2).sum(axis=1))
orden = np.argsort(distancias)
print("distancias:", distancias.round(2))
print("orden de cercanía (posiciones):", orden)

for k in (1, 3, 5):
    votos = y[orden[:k]]
    print(f"K={k}: etiquetas de los vecinos {votos} -> gana", np.bincount(votos).argmax())

# Con scikit-learn
knn = KNeighborsClassifier(n_neighbors=3).fit(X, y)
dist, idx = knn.kneighbors(nuevo)
print("kneighbors -> distancias:", dist.round(2), "posiciones:", idx)
print("predict:", knn.predict(nuevo), "| predict_proba:", knn.predict_proba(nuevo))

6 · KNeighborsRegressor: predecir un número promediando vecinos

Para qué sirve Usar KNN para predecir un valor numérico (la media de los vecinos) y ver el efecto de K y de ponderar los vecinos según su cercanía.

import numpy as np
from sklearn.neighbors import KNeighborsRegressor

x = np.array([[1], [2], [3], [4], [5], [6]])
y = np.array([10, 12, 11, 30, 32, 31])

for k in (1, 2, 3):
    knn = KNeighborsRegressor(n_neighbors=k).fit(x, y)
    print(f"K={k}: predicción para x=3.6 ->", knn.predict([[3.6]]))

ponderado = KNeighborsRegressor(n_neighbors=3, weights="distance").fit(x, y)
print("K=3 con weights='distance' ->", ponderado.predict([[3.6]]).round(3))
