Antes de empezar: las piezas

Python es el lenguaje en el que está escrito todo: se lee casi como inglés y se ejecuta línea a línea, de arriba abajo.

Una librería es código que otra gente ya escribió para que tú no tengas que hacerlo. import es la orden que la trae a tu programa. Aquí usamos cuatro: NumPy (cuentas con tablas de números), pandas (tablas con nombres), scikit-learn (los algoritmos) y SciPy (el árbol jerárquico).

scikit-learn (sklearn): los algoritmos ya hechos

Se instala como scikit-learn y se importa como sklearn (el nombre corto). Está ordenada en cajones, uno por tipo de tarea. Todos sus modelos se usan igual: se crean, se les hace fit y se les pide algo.

fit
«Aprende de estos datos». En no supervisado solo recibe X, sin respuesta.
transform, fit_transform, inverse_transform
transform: aplica lo aprendido (escalar, proyectar…). fit_transform: aprende y aplica de una vez. inverse_transform: deshace el cambio.
predict y fit_predict
predict: la respuesta del modelo para filas nuevas (un grupo, normal o raro). fit_predict: aprende y responde de una vez.
Nombres con guion bajo final
labels_, cluster_centers_, inertia_, n_iter_, components_…: lo que el modelo deja apuntado tras el fit.
random_state
La semilla del azar del modelo. Fíjala (random_state=42) para que te salga lo mismo que aquí.
sklearn.datasets
Datos que vienen dentro de la librería: load_wine (178 vinos), load_digits (1.797 dígitos de 8 × 8 píxeles), make_blobs (inventa nubes redondas) y make_moons (inventa dos lunas).
StandardScaler
Cajón preprocessing. Escala: a cada columna le resta su media y la divide entre su desviación.
FunctionTransformer
Cajón preprocessing. Sin argumentos, deja pasar los datos tal cual. Sirve para conservar las columnas originales dentro de una tubería.
make_pipeline y make_union
Cajón pipeline. make_pipeline: encadena pasos en orden (escalar, luego agrupar). make_union: pone lado a lado lo que sale de varios pasos.
NearestNeighbors
Cajón neighbors. Un buscador de vecinos: fit guarda la tabla y kneighbors devuelve las distancias y las posiciones de los K más cercanos.
KNeighborsClassifier
Cajón neighbors. El KNN del módulo 3: clasifica con el voto de los vecinos. Aquí se usa para medir lo útil que es un mapa.
KMeans
Cajón cluster. Agrupa con centroides: asignar, mover a la media, repetir. n_clusters = K; n_init = cuántos comienzos prueba; init = cómo elige el primero.
AgglomerativeClustering
Cajón cluster. El jerárquico: junta de dos en dos. linkage = el enlace (ward, complete, average, single).
DBSCAN y HDBSCAN
Cajón cluster. Agrupan por densidad. DBSCAN pide eps (radio) y min_samples (mínimo); HDBSCAN, solo min_cluster_size. El ruido sale con −1.
silhouette_score y silhouette_samples
Cajón metrics. El silhouette medio, o el de cada punto (de −1 a +1, alto es mejor).
davies_bouldin_score
Cajón metrics. Cuánto se pisan los grupos. Bajo es mejor.
adjusted_rand_score (ARI)
Cajón metrics. Compara dos repartos en grupos: 1 = iguales, 0 = como al azar.
IsolationForest
Cajón ensemble. Aísla a los raros con cortes al azar: a quien se queda solo pronto, lo marca. contamination = qué parte esperas que sea rara.
LocalOutlierFactor (LOF)
Cajón neighbors. Compara la densidad de cada punto con la de sus vecinos: si vive en una zona más vacía que ellos, es raro.
PCA
Cajón decomposition. Resume muchas columnas en pocas, quedándose con las direcciones de más varianza. n_components = cuántas.
TSNE y trustworthiness
Cajón manifold (formas curvas). t-SNE dibuja un mapa que conserva a los vecinos; trustworthiness mide qué parte de los vecinos del mapa lo eran de verdad.
train_test_split y cross_val_score
Cajón model_selection (módulo 5). Separar datos para entrenar y para examinar; y repetir el examen varias veces y hacer la media.
LogisticRegression
Cajón linear_model. La regresión logística del módulo 2: separa clases con una frontera recta.

Paso 2 · Escalar y medir distancias

Para qué sirve Medir la distancia entre una familia y un fan de la acción, antes y después de escalar, y ver qué parte de esa distancia pone la columna de los minutos.

from sklearn.preprocessing import StandardScaler

def distancia(p, q):
    return np.sqrt(((p - q) ** 2).sum())

a, b = usuarios.iloc[0], usuarios.iloc[90]          # una familia y un fan de la acción
print("Sin escalar: distancia =", round(distancia(a, b), 1))
print("  parte que pone min_sesion:", round((a["min_sesion"] - b["min_sesion"]) ** 2 / distancia(a, b) ** 2 * 100), "%")

escalador = StandardScaler()
X = escalador.fit_transform(usuarios)
print("Escalado:    distancia =", round(distancia(X[0], X[90]), 2))
print("  parte que pone min_sesion:", round((X[0, 6] - X[90, 6]) ** 2 / distancia(X[0], X[90]) ** 2 * 100), "%")
print("Media y desviación de cada columna escalada:", X.mean(axis=0).round(2) + 0.0, X.std(axis=0).round(2))

# ===== Paso 1 · Inventar los usuarios de Netflix =====
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
columnas = ["accion", "comedia", "drama", "terror", "docu", "anime", "min_sesion"]

# Cuatro tipos de espectador escondidos: horas al mes de cada género y minutos por sesión
tipos = {
    "familias":     [2, 12, 3, 1, 2, 20, 40],
    "accion":       [22, 4, 3, 8, 1, 1, 110],
    "dramas":       [3, 8, 20, 2, 3, 1, 70],
    "documentales": [2, 2, 5, 1, 15, 1, 50],
}
cuantos = [90, 80, 70, 60]
bloques = [rng.normal(medias, [3, 3, 3, 3, 3, 3, 15], size=(n, 7))
           for medias, n in zip(tipos.values(), cuantos)]

# Cinco cuentas raras que no siguen a nadie
raras = np.array([[18, 18, 18, 18, 18, 18, 160],
                  [0, 0, 0, 25, 0, 25, 30],
                  [20, 0, 20, 0, 20, 0, 130],
                  [12, 12, 12, 0, 0, 0, 200],
                  [1, 1, 1, 1, 1, 1, 5]])

usuarios = pd.DataFrame(np.vstack(bloques + [raras]).clip(0).round(1), columns=columnas)
tipo_real = np.repeat(list(tipos) + ["rara"], cuantos + [5])   # solo para comprobar al final

print("Tabla:", usuarios.shape[0], "usuarios x", usuarios.shape[1], "columnas")
print(usuarios.head(3))
print(usuarios.agg(["min", "mean", "max"]).round(1))

# ===== Paso 2 · Escalar y medir distancias =====
from sklearn.preprocessing import StandardScaler

def distancia(p, q):
    return np.sqrt(((p - q) ** 2).sum())

a, b = usuarios.iloc[0], usuarios.iloc[90]          # una familia y un fan de la acción
print("Sin escalar: distancia =", round(distancia(a, b), 1))
print("  parte que pone min_sesion:", round((a["min_sesion"] - b["min_sesion"]) ** 2 / distancia(a, b) ** 2 * 100), "%")

escalador = StandardScaler()
X = escalador.fit_transform(usuarios)
print("Escalado:    distancia =", round(distancia(X[0], X[90]), 2))
print("  parte que pone min_sesion:", round((X[0, 6] - X[90, 6]) ** 2 / distancia(X[0], X[90]) ** 2 * 100), "%")
print("Media y desviación de cada columna escalada:", X.mean(axis=0).round(2) + 0.0, X.std(axis=0).round(2))

# ===== Paso 3 · Qué géneros van juntos: reglas de asociación =====
fan = usuarios[columnas[:6]] >= 10                 # True si ve 10 horas o más de ese género
soporte = fan.mean()

reglas = []
for g1 in fan.columns:
    for g2 in fan.columns:
        if g1 != g2:
            s_12 = (fan[g1] & fan[g2]).mean()
            if s_12 >= 0.05:
                confianza = s_12 / soporte[g1]
                reglas.append({"regla": f"{g1} -> {g2}", "soporte": round(s_12, 3),
                               "confianza": round(confianza, 2), "lift": round(confianza / soporte[g2], 2)})

print(pd.DataFrame(reglas).sort_values("lift", ascending=False).to_string(index=False))

print("Grupo de los 8 primeros:", km.labels_[:8])

# ===== Paso 6 · ¿Era 4 una buena K? =====
from sklearn.metrics import silhouette_score, davies_bouldin_score

print(" K | inercia | silhouette | davies-bouldin")
for k in range(2, 8):
    prueba = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X)

13 · HDBSCAN frente a DBSCAN con densidades distintas

Para qué sirve Ver con números por qué un solo eps no puede con grupos de densidades distintas y cómo HDBSCAN lo resuelve sin fijar eps.

import numpy as np
from sklearn.cluster import DBSCAN, HDBSCAN

# Tres grupos de densidades muy distintas (dos densos y pegados, uno disperso) + ruido
rng = np.random.default_rng(5)
A = rng.normal([3.0, 3.4], 0.2, (55, 2))
B = rng.normal([4.8, 3.4], 0.2, (55, 2))
C = rng.normal([11.5, 6.4], 1.5, (60, 2))
ruido = np.c_[rng.uniform(0.3, 15.7, 16), rng.uniform(0.3, 9.7, 16)]
X = np.vstack([A, B, C, ruido])
y = np.r_[np.zeros(55), np.ones(55), 2 * np.ones(60), 3 * np.ones(16)]

def etiqueta_dominante(lab):
    """Etiqueta más frecuente dentro de cada grupo real (A, B, C): -1 significa «ruido»."""
    return [int(np.bincount(lab[y == g] + 1).argmax()) - 1 for g in range(3)]

print("DBSCAN con distintos eps (min_samples=5):")
for eps in (0.3, 0.5, 1.0, 1.5):
    lab = DBSCAN(eps=eps, min_samples=5).fit_predict(X)
    print(f"  eps={eps}: {lab.max() + 1} grupos, {(lab == -1).sum():3d} de ruido, etiqueta de A, B, C = {etiqueta_dominante(lab)}")

hdb = HDBSCAN(min_cluster_size=15, copy=True).fit(X)
lab = hdb.labels_
print("HDBSCAN (sin eps):", lab.max() + 1, "grupos,", (lab == -1).sum(), "de ruido, etiqueta de A, B, C =", etiqueta_dominante(lab))
print("Tamaño de cada grupo:", np.bincount(lab[lab >= 0]))
print("Confianza (probabilities_), mínimo / media:", hdb.probabilities_.min().round(2), hdb.probabilities_.mean().round(2))

22 · K-Means como ingeniería de variables dentro de un Pipeline
