La idea y el ejemplo

PyTorch usa capas como nn.Conv2d, nn.ReLU, nn.MaxPool2d y nn.Linear. Aquí nn.Sequential también sirve para apilar operaciones sin crear una clase.

La diferencia que más errores causa es la forma: Keras suele usar NHWC y PyTorch NCHW. El otro detalle importante es que nn.CrossEntropyLoss espera logits (sin softmax) y etiquetas enteras de tipo long.

Con números

(16,3,32,32) → Conv2d(3,8) → (16,8,32,32) → Pool → (16,8,16,16) → Flatten → (16,2048) → Linear(2048,2).

import torch.nn as nn
modelo = nn.Sequential(
    nn.Conv2d(3, 8, kernel_size=3, padding=1),
    nn.ReLU(), nn.MaxPool2d(2),
    nn.Flatten(), nn.Linear(8 * 16 * 16, 2)
)
perdida = nn.CrossEntropyLoss()
