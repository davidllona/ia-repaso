Sin posición, «título arriba» y «título abajo» son el mismo póster

Antes de entrar en los bloques, el ViT añade dos cosas a los parches: un token extra, el CLS, que acabará resumiendo el póster, y a cada token un vector que dice dónde está.

Índice del módulo

Barajas los 16 parches de una miniatura y se los das a un Transformer que no sabe nada de posiciones. ¿Cambia su respuesta?

No. La atención compara contenidos, no lugares: si barajas la entrada, la salida sale barajada igual y el resumen final es el mismo. Para ese modelo el póster es una bolsa de parches, como ya viste con «Woody salva a Buzz».

Un token que resume y un vector que dice «dónde»

La posición. A cada token se le suma un vector de \(d\) números que depende de su lugar en la rejilla. En el ViT no se usan senos y cosenos: es una tabla que se aprende, una fila por posición. Al entrenar, la tabla acaba codificando «fila 1, columna 3» por sí sola.

El token CLS. Es un vector aprendido que no viene de ningún parche y se pone el primero de la fila. En cada bloque pregunta a todos los parches como uno más. Al final, la cabeza clasificadora lee solo su vector: es el crítico que no tiene asiento propio, pero escucha a toda la sala antes de dar la nota.

  • 196 parches(196, d)
  • + CLS delante(197, d)
  • + posicióntabla (197, d)
  • Bloquesla cabeza lee el CLS

Con números: lo que cuestan y lo que aportan

Ejemplo numérico
  1. ViT-B/16: el CLS son 768 parámetros; la tabla de posiciones, \(197 \cdot 768 =\) 151.296.
  2. Nuestra miniatura (16 parches, \(d = 64\)): \(64 + 17 \cdot 64 = 1.152\) parámetros.
  3. Experimento real del código: miniaturas con «título arriba» o «título abajo», ViT diminuto de 2 bloques.

Entrenas con pósters de 224 y quieres afinar con 384 para ver más detalle. ¿Te vale la tabla de posiciones tal cual?

No: con 384 salen 24×24 = 576 parches y la tabla solo tiene 14×14 = 196 filas (más el CLS). Se interpola: se ve la tabla como una imagen de 14×14 y se estira a 24×24. Las librerías lo hacen por ti.

En tres líneas

  • Sin posición, el Transformer ve una bolsa de parches: el orden no le importa.
  • El ViT suma a cada token una posición aprendida (tabla de 197 × d).
  • El token CLS va delante, escucha a todos y es lo único que lee la cabeza.
Profundizar: CLS o media, posiciones 1D o 2D y errores típicosPor qué la tabla es aprendida, qué alternativas hay al CLS, cómo se interpola y qué falla al guardar una capa propia en Keras.

Aprendida y no sinusoidal

En el Curso 3 viste la codificación con senos y cosenos del Transformer de texto. El ViT original probó varias opciones (ninguna, 1D aprendida, 2D aprendida, relativa) y vio que cualquier posición ayuda muchísimo frente a ninguna, pero que entre ellas apenas hay diferencia. Se quedó con la más sencilla: una tabla 1D aprendida de 197 filas. Si dibujas la similitud entre filas de la tabla ya entrenada, aparecen solas la estructura de filas y columnas de la rejilla: el modelo aprende que el parche 15 está debajo del 1.

CLS frente a media de parches

El CLS viene de BERT. La alternativa es la media de todos los tokens de salida (global average pooling, como en muchas CNN). Las dos funcionan; el CLS permite ver a quién atiende el resumen (lo harás en la lección 3), y la media es algo más estable con pocos datos. En Keras la media es layers.GlobalAveragePooling1D(); en PyTorch, t.mean(dim=1).

Orden de las operaciones

Primero se concatena el CLS y luego se suma la posición: por eso la tabla tiene \(n + 1\) filas y el CLS también recibe su propia posición (la 0). Se suma y no se concatena para que el token conserve \(d\) números y todas las capas siguientes funcionen igual.

Interpolar para otra resolución

Al afinar a más resolución, se separa la fila del CLS, se reorganizan las 196 filas restantes como una imagen 14×14×d, se redimensiona a 24×24 con interpolación bicúbica y se vuelve a aplanar. timm y Hugging Face lo hacen solas; en torchvision, vit_b_16 tiene un tamaño fijo y hay que hacerlo a mano.

Ojo: capas propias en Keras

Una capa como ClsYPos se entrena sin problema, pero si guardas el modelo con model.save("vit.keras") y lo cargas después, Keras necesita saber que existe: decora la clase con @keras.saving.register_keras_serializable() o pásala en custom_objects al cargar. Si la capa recibe argumentos en __init__, añade también get_config. Es un error clásico al pasar del cuaderno al proyecto final.

Ojo: parámetros en PyTorch

En PyTorch el CLS y la tabla tienen que ser nn.Parameter. Si los creas como tensores normales (torch.zeros(…)), no aparecen en model.parameters(), el optimizador no los toca y se quedan en cero o al azar para siempre.

3 · Keras: una capa que pone el CLS delante y suma la posición

Para qué sirve Escribir la capa ClsYPos que usarán el ViT y el híbrido de las lecciones 3, 4 y 5, y comprobar formas y parámetros con 2 pósters de 16 tokens.

import numpy as np, keras
from keras import layers, ops

class ClsYPos(layers.Layer):
    """Pone el token CLS delante y suma una posición aprendida a cada token."""
    def build(self, forma):                              # forma = (lote, n_tokens, d)
        n, d = forma[1], forma[2]
        self.cls = self.add_weight(shape=(1, 1, d), initializer="zeros", name="cls")
        self.pos = self.add_weight(shape=(1, n + 1, d), name="pos",
                                   initializer=keras.initializers.RandomNormal(stddev=0.02))
    def call(self, t):
        cls = ops.repeat(self.cls, ops.shape(t)[0], axis=0)   # un CLS por póster del lote
        return ops.concatenate([cls, t], axis=1) + self.pos

tokens = np.random.default_rng(0).normal(size=(2, 16, 64)).astype("float32")
capa = ClsYPos()
salida = ops.convert_to_numpy(capa(tokens))
print("entra:", tokens.shape, "-> sale:", salida.shape)
print("pesos: cls", tuple(capa.cls.shape), "+ pos", tuple(capa.pos.shape), "=", capa.count_params())
print("¿el CLS sale igual en los dos pósters?", np.allclose(salida[0, 0], salida[1, 0]))

4 · PyTorch: el mismo ViT diminuto con y sin posición

Para qué sirve Medir de verdad lo que aporta la posición. Genera miniaturas 32×32 con el título arriba o abajo, define ViTMini (que reutilizan las lecciones 5 y 6) y lo entrena dos veces.

import numpy as np, torch, torch.nn as nn
torch.manual_seed(0)

def posters(n, seed=0):                                   # 1 = título arriba, 0 = título abajo
    rng = np.random.default_rng(seed)
    X = rng.uniform(0, 0.3, (n, 32, 32, 3)).astype("float32")
    y = rng.integers(0, 2, n)
    for i in range(n):
        f = rng.integers(1, 5) + (0 if y[i] else 24)       # fila donde empieza la banda del título
        X[i, f:f+3, 4:28] += 0.6
        cy, cx = rng.integers(12, 21, 2)                   # «personaje» en el centro
        X[i, cy-3:cy+3, cx-3:cx+3, rng.integers(0, 3)] += 0.6
    return torch.tensor(X).permute(0, 3, 1, 2), torch.tensor(y)

class ViTMini(nn.Module):
    def __init__(s, posicion=True, d=32):
        super().__init__()
        s.parches = nn.Conv2d(3, d, kernel_size=8, stride=8)
        s.cls = nn.Parameter(torch.zeros(1, 1, d))
        s.pos = nn.Parameter(torch.randn(1, 17, d) * 0.02) if posicion else None
        capa = nn.TransformerEncoderLayer(d, 2, 64, dropout=0.0, batch_first=True, norm_first=True)
        s.bloques = nn.TransformerEncoder(capa, 2, enable_nested_tensor=False)
        s.cabeza = nn.Linear(d, 2)
    def forward(s, x):
        t = s.parches(x).flatten(2).transpose(1, 2)
        t = torch.cat([s.cls.expand(len(x), -1, -1), t], dim=1)
        if s.pos is not None: t = t + s.pos
        return s.cabeza(s.bloques(t)[:, 0])

Xtr, ytr = posters(800, seed=1); Xte, yte = posters(400, seed=2)
for con_pos in [False, True]:
    torch.manual_seed(0)
    m = ViTMini(posicion=con_pos)
    opt = torch.optim.Adam(m.parameters(), lr=1e-3)
    for epoca in range(10):
        for i in range(0, 800, 32):
            loss = nn.functional.cross_entropy(m(Xtr[i:i+32]), ytr[i:i+32])
            opt.zero_grad(); loss.backward(); opt.step()
    with torch.no_grad(): acc = (m(Xte).argmax(1) == yte).float().mean().item()
    print(f"posición={con_pos!s:5}  parámetros={sum(p.numel() for p in m.parameters()):,}  acierto test={acc:.3f}")
