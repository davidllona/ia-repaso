La idea y el ejemplo

PyTorch es un framework de aprendizaje profundo con control explícito sobre el entrenamiento. Su Dataset define cómo obtener una muestra (imagen, etiqueta). DataLoader organiza esas muestras en lotes y puede barajarlas.

torchvision incluye utilidades para imágenes: ImageFolder aprovecha carpetas por clase; transforms.ToTensor() convierte una imagen PIL de 0–255 a un tensor de forma (C, H, W) en escala 0–1.

Con números

Si hay 100 fotos y usas batch_size=32, obtendrás cuatro batches: 32, 32, 32 y 4 fotos (salvo que descartes el último).

PyTorch separa Dataset y DataLoader

Para qué sirve Dataset sabe buscar una imagen; DataLoader sabe agruparlas y entregarlas.

from torchvision import datasets, transforms
from torch.utils.data import DataLoader
prep = transforms.Compose([transforms.Resize((224, 224)), transforms.ToTensor()])
datos = datasets.ImageFolder("datos/train", transform=prep)
loader = DataLoader(datos, batch_size=32, shuffle=True)
