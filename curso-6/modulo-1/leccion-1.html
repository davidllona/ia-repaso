Cada carpeta es una clase: el nombre de la carpeta es la etiqueta

El proyecto final clasifica imágenes en dos clases. Antes de cualquier red, las imágenes se ordenan en carpetas, y esas carpetas ya son las etiquetas.

Índice del módulo

Tienes las carpetas animacion/ y accion/ con 100 pósters cada una, y nadie ha escrito ni una etiqueta. ¿De dónde sacará Keras que un póster es 0 o 1?

Del nombre de la carpeta en la que está. Keras y PyTorch ordenan los nombres alfabéticamente y los numeran: accion = 0, animacion = 1. No hace falta ningún CSV de etiquetas: las carpetas ya lo son.

Ordenar en carpetas ya es etiquetar

El proyecto final de Coursera clasifica fotos de satélite: ¿este trozo de terreno es agrícola o no agrícola? Aquí usamos pósters de películas («animación» frente a «acción») porque la técnica es idéntica: dos carpetas, una imagen por archivo y una red que aprende a separarlas. Lo harás dos veces, con Keras y con PyTorch, y al final compararás los dos.

Todo empieza en el disco. La convención que entienden los dos frameworks es una subcarpeta por clase:

posters/
├── accion/      000.png … 099.png   → etiqueta 0
└── animacion/   000.png … 099.png   → etiqueta 1

La etiqueta no se escribe en ningún sitio: sale del nombre de la carpeta, y el número, del orden alfabético de esos nombres. Lo hacen igual image_dataset_from_directory en Keras y ImageFolder en PyTorch, y es la misma idea que ya usaste con flow_from_directory en el proyecto de los aviones.

Cada imagen sigue siendo una pila de tablas de números: un póster de 32 × 32 en color son 32 · 32 · 3 = 3.072 números entre 0 y 255.

Con números: 1.000 pósters

Ejemplo numérico
  1. 2 carpetas × 500 pósters = 1.000 imágenes.
  2. Reservas un 20 % para validación: 0,2 · 1.000 = 200. Quedan 800 para entrenar.
  3. Lotes de 32: 800 / 32 = 25 pasos por época. Validación: 200 / 32 = 6,25 → 7 lotes (el último, de 8).
  4. Cada póster son 3.072 números; los 1.000, 3.072.000. Eso es lo que hay que mover del disco a la red.
Añades una carpeta amor/ junto a accion/ y animacion/. ¿Qué etiqueta tiene ahora animacion?

2. Por orden alfabético: accion = 0, amor = 1, animacion = 2. Un modelo entrenado antes creía que 1 era animación. Por eso se guardan los nombres de las clases (class_names) junto al modelo.

En tres líneas

  • El proyecto: clasificar imágenes en dos clases (satélite en Coursera, pósters aquí), con Keras y con PyTorch.
  • Una subcarpeta por clase: la etiqueta es el nombre de la carpeta, numerado por orden alfabético.
  • Antes de tocar la red, cuenta: cuántas imágenes, cuántas para validación y cuántos lotes por época.

Por eso este módulo importa más de lo que parece: si los datos llegan mal (etiquetas cruzadas, validación contaminada, píxeles sin escalar), todo lo que venga después dará números que no significan nada, y ningún framework te avisará.

Por qué orden alfabético y no el orden del disco

El sistema operativo no garantiza en qué orden lista las carpetas: os.listdir puede devolverlas en un orden en tu portátil y en otro en Colab. Si las etiquetas dependieran de ese orden, el mismo código daría etiquetas distintas en cada máquina. Ordenar alfabéticamente lo hace reproducible. Si quieres otro orden, en Keras puedes pasar class_names=["no_agricola", "agricola"]; en PyTorch, ImageFolder guarda el diccionario en class_to_idx y puedes consultarlo, pero no se cambia con un parámetro. Un truco común es poner prefijos: 0_no_agricola/, 1_agricola/.

Una carpeta o dos

Hay dos formas de organizar el proyecto. Con una sola carpeta (la de arriba), la validación se separa en el código (lección 3). Con carpetas train/, val/ y test/, cada una con sus subcarpetas por clase, el reparto queda fijado en el disco, como en el proyecto de los aviones. La segunda es más segura para el test, que se mira una sola vez: nadie lo mezcla por accidente.

Ojo · la clase fantasma

En Jupyter y Colab aparece a veces una carpeta oculta .ipynb_checkpoints dentro de tu carpeta de datos. Para ImageFolder es una subcarpeta más, así que la trata como una clase y, como no tiene imágenes, falla al crear el dataset con FileNotFoundError: Found no valid file for the classes .ipynb_checkpoints. Bórrala o mueve los datos fuera de la carpeta del cuaderno. Antes de entrenar, imprime siempre la lista de clases y cuántas imágenes tiene cada una.

Mira el equilibrio antes de entrenar

Cuenta las imágenes de cada carpeta. Con 500 y 500, un modelo que dice siempre «animación» acierta el 50 %: ese es el listón mínimo. Con 900 y 100, ese mismo modelo tonto acierta el 90 %, y el accuracy engaña. Saber el reparto te dice qué número es bueno de verdad.

Un detalle para el cuestionario: la forma de cada imagen es (alto, ancho, canales) al leerla con PIL o NumPy, y los valores son enteros uint8 de 0 a 255. Cómo la reordena y la escala cada framework lo verás en las lecciones 3, 5 y 6.

Código

1 · Fabricar la carpeta de pósters sintéticos

Para qué sirve Crear, sin internet, la estructura que espera el proyecto: posters/accion/ y posters/animacion/ con 100 imágenes PNG de 32 × 32 cada una. Los fragmentos de las lecciones siguientes leen esta carpeta.

import os
import numpy as np
from PIL import Image

rng = np.random.default_rng(0)
yy, xx = np.mgrid[0:32, 0:32]

def poster(clase):
    if clase == "animacion":                       # fondo claro + un círculo de color
        img = np.full((32, 32, 3), 220.0)
        cy, cx = rng.integers(10, 22, size=2)
        r = rng.integers(5, 9)
        img[(yy - cy) ** 2 + (xx - cx) ** 2 < r ** 2] = rng.uniform(0, 255, size=3)
    else:                                          # fondo oscuro + rayas diagonales
        img = np.full((32, 32, 3), 40.0)
        img[(xx + yy + rng.integers(0, 8)) % 8 < 3] = [200, 60, 30]
    img += rng.normal(0, 10, size=img.shape)       # un poco de ruido
    return np.clip(img, 0, 255).astype(np.uint8)

for clase in ["animacion", "accion"]:
    os.makedirs(f"posters/{clase}", exist_ok=True)
    for i in range(100):
        Image.fromarray(poster(clase)).save(f"posters/{clase}/{i:03d}.png")

for clase in sorted(os.listdir("posters")):
    archivos = sorted(os.listdir(f"posters/{clase}"))
    img = np.array(Image.open(f"posters/{clase}/{archivos[0]}"))
    print(f"{clase:10s} {len(archivos)} archivos  primero={archivos[0]}  forma={img.shape}  {img.dtype}  brillo medio={img.mean():.1f}")
