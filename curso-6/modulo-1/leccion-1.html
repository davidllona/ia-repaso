La idea y el ejemplo

Una imagen RGB es una cuadrícula: alto × ancho × tres intensidades (rojo, verde y azul). Una etiqueta indica la respuesta correcta, por ejemplo gato=0 y perro=1. Una carpeta puede servir como etiqueta si contiene fotos de una sola clase.

El proyecto necesita tres conjuntos independientes: TRAIN para aprender, VALIDATION para elegir ajustes y TEST para medir el resultado al final. No uses la misma foto en dos conjuntos: si el modelo la memoriza, la evaluación deja de ser honesta.

Con números

Con 1.000 imágenes, un reparto posible es 700 para entrenamiento, 150 para validación y 150 para prueba. No es una norma universal: importa conservar clases y evitar duplicados.
