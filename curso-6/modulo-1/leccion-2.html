La idea y el ejemplo

Keras es una API de alto nivel que facilita crear redes neuronales; normalmente usa TensorFlow como motor. La función image_dataset_from_directory recorre carpetas con nombres de clases y produce lotes de imágenes y etiquetas.

Un batch es un grupo, por ejemplo de 32 imágenes. En cada paso el modelo ve un batch. prefetch prepara el siguiente lote mientras la GPU trabaja con el actual: evita muchos tiempos muertos de lectura.

Con números

1.024 fotos / 32 por lote = 32 batches por época. La red no aprende solo de 32 fotos: acaba recorriendo las 1.024 a lo largo de esa época.

Para qué sirve En un dataset grande, lo importante es cargar y procesar solo el siguiente grupo de imágenes.

import tensorflow as tf
from tensorflow import keras
train = keras.utils.image_dataset_from_directory("datos/train", image_size=(224, 224), batch_size=32)
train = train.prefetch(tf.data.AUTOTUNE)
