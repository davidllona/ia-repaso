Checklist antes de entrenar
  1. Imprime x.shape, y.shape y model(x).shape: ¿yhat e y tienen la misma forma?
  2. ¿Los datos son float32? (x.dtype)
  3. ¿Las variables están estandarizadas?
  4. ¿El bucle tiene zero_grad, backward y step, en este orden?
  5. Prueba con un lr pequeño y mira que el coste baje en las primeras épocas; si baja, sube el lr.
  6. Fija una semilla (torch.manual_seed) para poder repetir el experimento.

Para qué sirve Provocar a propósito siete errores típicos de la regresión con PyTorch y leer el mensaje que da cada uno (o, en el último, el síntoma silencioso).

import warnings
import torch
from torch import nn

def intentar(titulo, f):
    try:
        f()
    except Exception as e:
        print(f"{titulo}\n   {type(e).__name__}: {str(e).splitlines()[0]}")

lineal = nn.Linear(1, 1)

intentar("1. entrada float64 en un modelo float32",
         lambda: lineal(torch.tensor([[1.0], [2.0]], dtype=torch.float64)))
intentar("2. entrada con forma (3,) en lugar de (3, 1)",
         lambda: lineal(torch.tensor([1.0, 2.0, 3.0])))
intentar("3. backward() sin requires_grad",
         lambda: (torch.tensor(2.0) * 3).backward())

w = torch.tensor(1.0, requires_grad=True)
def en_sitio():
    w.sub_(0.1)                                        # w -= 0.1 en sitio
intentar("4. actualizar un parámetro en sitio sin torch.no_grad()", en_sitio)

class Mala(nn.Module):
    def __init__(self):
        self.linear = nn.Linear(1, 1)                  # se nos olvidó super().__init__()
intentar("5. clase nn.Module sin super().__init__()", Mala)

w = torch.tensor(1.0, requires_grad=True)
loss = (w * 2 - 5) ** 2
loss.backward()
w = w - 0.1 * w.grad                                   # crea un tensor NUEVO, no actualiza el parámetro
print("6. w = w - lr * w.grad  ->  w.is_leaf =", w.is_leaf, " requires_grad =", w.requires_grad, " w.grad =", end=" ")
with warnings.catch_warnings():
    warnings.simplefilter("ignore")
    print(w.grad)

x = torch.tensor([[1.0], [2.0], [3.0]])
y = torch.tensor([2.0, 5.0, 8.0])                      # forma (3,) en lugar de (3, 1)
torch.manual_seed(1)
modelo = nn.Linear(1, 1)
opt = torch.optim.SGD(modelo.parameters(), lr=0.05)
crit = nn.MSELoss()
with warnings.catch_warnings():
    warnings.simplefilter("ignore")
    for _ in range(500):
        loss = crit(modelo(x), y)
        opt.zero_grad(); loss.backward(); opt.step()
print("7. y de forma (3,) frente a yhat de forma (3, 1): w =", round(modelo.weight.item(), 3),
      " b =", round(modelo.bias.item(), 3), " loss =", round(loss.item(), 3))

Cada error da el mensaje que verás en tu terminal: «mat1 and mat2 must have the same dtype, but got Double and Float»; «mat1 and mat2 shapes cannot be multiplied (1x3 and 1x1)»; «element 0 of tensors does not require grad and does not have a grad_fn»; «a leaf Variable that requires grad is being used in an in-place operation»; y «cannot assign module before Module.__init__() call». En el 6, w deja de ser una hoja (is_leaf = False) y su .grad es None. Y el 7 es el silencioso: no da error, pero el modelo aprende w ≈ 0.005 y b ≈ 4.989 con coste 6.0, es decir, predice siempre la media de y (5) porque compara cada predicción con todos los objetivos.
