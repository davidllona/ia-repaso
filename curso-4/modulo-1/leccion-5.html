from_numpy comparte memoria; torch.tensor copia

Tus datos llegan en NumPy o en una tabla de Pandas, y para dibujarlos vuelves a NumPy. Al cruzar ese puente hay dos preguntas: ¿se comparten los números o se copian? ¿Y en qué tipo llegan?

Índice del módulo

Conviertes np.array([1.0, 2.0]) con torch.from_numpy. ¿El tensor sale en float32, como esperan las capas de PyTorch?

No: sale en float64, el tipo por defecto de NumPy, y el tensor lo hereda. Si después lo pasas por una capa con pesos float32, error de tipo. Haz torch.tensor(arr, dtype=torch.float32) o .float().

Compartir la lista o copiarla

Piensa en una lista de reproducción de Netflix. torch.from_numpy(arr) es compartir la misma lista con otra persona: si ella cambia una película, tú lo ves al instante. torch.tensor(arr) es hacer una copia: dos listas independientes.

Escribes¿Comparte?
torch.from_numpy(arr)Sí
torch.tensor(arr)No, copia
t.numpy()Sí
t.detach().cpu().numpy()Sí, si ya está en CPU

Compartir es eficiente (no se copian millones de números), pero si modificas uno, cambia el otro.

Una tabla de Pandas pasa por su array: las columnas de entrada a torch.tensor(df[cols].values, dtype=torch.float32), forma (muestras, características); la etiqueta a int64 si es una clase. Las columnas de texto no se convierten: hay que quitarlas o codificarlas antes.

Para dibujar con Matplotlib: puntos con linspace, función sobre todos y plt.plot(x, y). Si el tensor viene de algo con gradientes, primero .detach().

Con números: el mismo cambio, dos resultados

Ejemplo numérico

arr = np.array([1., 2., 3.]) (minutos vistos de tres capítulos), a = torch.from_numpy(arr), b = torch.tensor(arr). Después, arr[1] = 99.

  1. a = [1., 99., 3.]: comparte la memoria con arr.
  2. b = [1., 2., 3.]: es una copia hecha antes del cambio.
  3. Los dos son float64: 3 · 8 = 24 bytes. En float32 serían 12.

Con una tabla de 5 usuarios (capítulos vistos, fracción del último): X mide (5, 2) en float32 e y («terminó la serie») mide (5,) en int64.

Dibujas las notas que predice tu modelo con plt.plot(x, y_pred) y salta un error. ¿Qué tiene y_pred que no tenía x?

Gradientes. y_pred sale de un cálculo con parámetros requires_grad=True, y PyTorch no deja convertirlo a NumPy: «Can't call numpy() on Tensor that requires grad». La solución es plt.plot(x, y_pred.detach()) (y .cpu() si está en GPU).

En tres líneas

  • from_numpy y .numpy() comparten memoria; torch.tensor copia.
  • NumPy da float64: pasa a float32 antes de entrenar; las etiquetas de clase, int64.
  • Pandas → torch.tensor(df[cols].values, dtype=torch.float32); para dibujar, .detach().

NumPy, Pandas y PyTorch: pasar de uno a otro

Tus datos (por ejemplo, el historial de lo que ha visto cada usuario) llegan en una tabla de Pandas o en un array de NumPy. ¿Cómo los conviertes en tensores, cómo vuelves a NumPy para dibujar o guardar, y qué pasa con la memoria al hacerlo?

Analogía

Una lista de reproducción de Netflix. torch.from_numpy(arr) no crea una lista nueva: es como compartir la misma lista con otra persona. Si ella añade o quita una película, tú lo ves al instante, porque es la misma lista. torch.tensor(arr), en cambio, hace una copia de la lista: es otra lista con sus propias películas, y los cambios en una no afectan a la otra.

Que se comparta memoria es muy eficiente (no se copian millones de números), pero tiene una consecuencia que hay que tener presente: si modificas uno, cambia el otro. Pruébalo en este experimento:

Experimento de arriba: «Quién comparte memoria con quién», con todo detalle

Haz esto. Con torch.from_numpy(arr) pulsa «arr[1] = 99» y luego «t[2] = -5». Cambia a torch.tensor(arr) y repite. Prueba también t.numpy() y la conversión con astype(float32).

Fíjate en. Con from_numpy y con .numpy() hay un solo bloque de memoria y los dos nombres lo ven. Con torch.tensor y con astype se copia: dos bloques independientes. Fíjate en el dtype del cuadro de lectura: NumPy mete float64 y el tensor lo hereda.

Ojo · NumPy usa float64 y PyTorch espera float32

np.array([1.0, 2.0]) es float64, así que torch.from_numpy te da un tensor float64. Cuando más adelante lo pases por una capa nn.Linear (que guarda sus pesos en float32), recibirás un error de tipo («mat1 and mat2 must have the same dtype»). Haz siempre torch.tensor(arr, dtype=torch.float32) o .float(). El fragmento 12 muestra los tres casos (comparten, copian, cambian de tipo).

De Pandas a tensor

Un DataFrame de Pandas no se convierte directamente: se pasa por su array de NumPy. El patrón para un problema de aprendizaje supervisado es: las columnas de entrada a un tensor float32 de forma (muestras, características) y la columna de etiquetas a otro tensor (int64 si son clases, float32 si es un valor numérico a predecir):

X = torch.tensor(df[["capitulos", "fraccion_ultimo"]].values, dtype=torch.float32)   # (5, 2)
y = torch.tensor(df["termino_serie"].values)                                      # (5,)  int64

Las columnas de texto no se pueden convertir (un array con texto tiene tipo object): hay que quitarlas o codificarlas como números antes (por ejemplo con las técnicas del Curso 1). El fragmento 13 hace la conversión con una tabla de 5 usuarios (capítulos que han visto de una serie, fracción del último capítulo y si terminaron la serie) y provoca el error con una columna de nombres.

Ojo · Pandas 3 y los arrays de solo lectura

Con Pandas 3, df['col'].to_numpy() devuelve a veces un array de solo lectura. Si lo pasas a torch.from_numpy (que comparte memoria), PyTorch emite un UserWarning: The given NumPy array is not writable…: escribir en ese tensor podría estropear la tabla. Para evitarlo, usa torch.tensor(…), que copia, como hace el fragmento 13.

Dibujar tensores con Matplotlib

¿Cómo ves una función, unos datos o cómo baja el error mientras la red aprende, si lo que tienes son tensores?

Se usa Matplotlib, la librería de gráficos que ya conoces de los cursos anteriores. El patrón para dibujar una función es siempre el mismo: (1) crear los puntos con torch.linspace, (2) calcular la función sobre todos a la vez, (3) llamar a plt.plot(x, y). Matplotlib acepta tensores directamente siempre que no tengan gradientes.

Ojo · «Can't call numpy() on Tensor that requires grad»

Si el tensor viene de un cálculo con parámetros que requieren gradientes (por ejemplo la salida de un modelo), Matplotlib intenta convertirlo a NumPy y PyTorch lo prohíbe. La solución es siempre .detach() (y, si está en GPU, .cpu()): plt.plot(x, y.detach()). El fragmento 14 provoca el error y lo corrige. Verás este mensaje muchas veces cuando dibujes la pérdida o las predicciones de un modelo.

Las gráficas interactivas de esta página (la pendiente de una curva, el mapa del gradiente…) son justo eso: una rejilla de puntos, una función evaluada sobre ellos y su dibujo. En un cuaderno de Jupyter terminarías con plt.show(); en un script sin pantalla se guarda con plt.savefig("figura.png") (hay que elegir antes el backend Agg, como hace el fragmento).

12 · NumPy ↔ PyTorch: qué comparte memoria y qué se copia

Para qué sirve Pasar de un array de NumPy a un tensor y viceversa, comprobar quién comparte memoria con quién y ver el detalle del float64 que NumPy mete por defecto.

import numpy as np
import torch

arr = np.array([1.0, 2.0, 3.0])
t = torch.from_numpy(arr)
c = torch.tensor(arr)
print(t, t.dtype)

t[0] = 100.0
print("arr tras tocar t:", arr)
print("c   (copia)     :", c)
back = t.numpy()
arr[1] = -5.0
print("back:", back, "| t:", t)

enteros = np.array([1, 2, 3])
print(enteros.dtype, torch.from_numpy(enteros).dtype)
t32 = torch.tensor(arr, dtype=torch.float32)
print(t32.dtype, torch.from_numpy(arr.astype(np.float32)).dtype)
print(torch.tensor([1.0, 2.0]).dtype, torch.tensor(np.array([1.0, 2.0])).dtype)

13 · De una tabla de Pandas a tensores

Para qué sirve Convertir las columnas de un DataFrame en un tensor de características X (decimales) y otro de etiquetas y (enteros), y ver qué pasa si hay una columna de texto.

import pandas as pd
import torch

df = pd.DataFrame({
    "capitulos":       [1, 2, 3, 4, 5],
    "fraccion_ultimo": [0.0, 0.5, 0.5, 1.0, 1.0],
    "termino_serie":   [0, 0, 1, 1, 1],
})
print(df.dtypes.to_dict())

X = torch.tensor(df[["capitulos", "fraccion_ultimo"]].values, dtype=torch.float32)
y = torch.tensor(df["termino_serie"].values)
print(X)
print(X.shape, X.dtype)
print(y, y.dtype)

capitulos = torch.tensor(df["capitulos"].to_numpy())
print(capitulos, capitulos.dtype)

df["nombre"] = ["ana", "luis", "eva", "pau", "ivo"]
try:
    torch.tensor(df.values)
except (TypeError, ValueError) as err:
    print(type(err).__name__, err)
