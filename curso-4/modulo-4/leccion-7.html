Recuerda

En el módulo 5 del Curso 1 viste la matriz de confusión (aciertos y errores contados por tipo), la accuracy, la precisión y la exhaustividad y el efecto del umbral. Aquí las calculamos con tensores de PyTorch. Y recuerda también que evaluar con los mismos datos con los que se entrena da una nota inflada: hace falta un conjunto de validación que el modelo no haya visto.

De probabilidad a clase: el umbral

El modelo no dice «cancelará», dice «cancelará con probabilidad 0.57». Para decidir hay que fijar un umbral (threshold): si \( p \ge \text{umbral} \), clase 1; si no, clase 0. Lo habitual es 0.5, pero no es obligatorio. En PyTorch es una comparación que devuelve booleanos, que se convierten a números para comparar con las etiquetas:

pred = (p >= 0.5).float()                  # tensor de 0. y 1.
acierto = (pred == y).float()              # 1. donde coincide, 0. donde no
accuracy = acierto.mean()                  # fracción de aciertos

La accuracy es simplemente la fracción de aciertos: \( \text{accuracy} = \dfrac{\text{aciertos}}{N} \). Ya la usamos arriba (12 aciertos de 14 = 0.857).

Ojo · compara clases, no probabilidades

El error más frecuente es escribir (p == y).float().mean(): compara la probabilidad (0.57) con la etiqueta (1.0) y casi nunca coinciden, así que la «accuracy» sale 0. Primero hay que convertir \( p \) en clase con el umbral, y luego comparar. Y si el modelo devuelve logits, la clase es logits > 0, sin sigmoide.

La matriz de confusión

La accuracy esconde el tipo de error. Hay dos errores distintos: dar la alarma «cancela» a alguien que se queda (falso positivo, FP: le ofreces un descuento sin necesidad) y decir «se queda» a alguien que cancela (falso negativo, FN: se te escapa sin avisar). Se cuentan los cuatro casos:

Predice 1 (cancela)Predice 0 (se queda)
Realidad 1 (canceló)TP: verdadero positivoFN: falso negativo
Realidad 0 (se quedó)FP: falso positivoTN: verdadero negativo

De ahí salen: \( \text{accuracy} = \dfrac{TP+TN}{N} \), \( \text{precisión} = \dfrac{TP}{TP+FP} \) («de los que dije que cancelarían, ¿cuántos cancelaron?») y \( \text{exhaustividad} = \dfrac{TP}{TP+FN} \) («de los que cancelaron, ¿a cuántos detecté?»; recall).

Entrenamiento y validación, con números

El fragmento 14 genera 200 usuarios sintéticos (con una «verdad oculta» \( w = 1.2,\ b = -5.4 \) y azar), separa 150 para entrenar y 50 para validar, entrena el modelo con BCEWithLogitsLoss y evalúa con el modelo en modo evaluación:

modelo.eval()                    # modo evaluación (no cambia nada en una capa lineal, pero es la costumbre)
with torch.no_grad():            # no se guardan gradientes: ahorra memoria y tiempo
    p_va = torch.sigmoid(modelo(X_va))

Resultados reales: el modelo aprende \( w = 1.085,\ b = -5.029 \) (cerca de la verdad oculta, 1.2 y −5.4; no es exacto porque hay azar y solo 150 muestras). Pérdida de entrenamiento 0.3151 y de validación 0.3133: son parecidas, así que no hay sobreajuste (un modelo de dos parámetros apenas puede memorizar). Un usuario con 3.5 días sin abrir la app tiene \( p = 0.226 \).

Un umbral bajo es «alarmista»: da la alarma de cancelación a más gente, atrapa casi a todos los que cancelaron (FN = 2) pero salta la alarma en falso más veces (FP = 5). Regla fácil

Entrena con la pérdida (BCE), que es suave y se puede derivar; evalúa con la accuracy y la matriz de confusión, que es lo que de verdad te importa. La accuracy es un conteo (no se puede derivar), por eso no se usa para entrenar. Y siempre sobre datos de validación.

13 · Datos perfectamente separables: w crece sin parar (y weight_decay lo frena)

Para qué sirve Entrenar con unos datos que una recta separa sin ningún error y comprobar que la pérdida baja hacia 0 mientras \(w\) crece indefinidamente; después, frenarlo con regularización L2 (weight_decay).

separable = (dias >= 3.25).float()

def entrenar_separable(epocas, weight_decay=0.0):
    torch.manual_seed(0)
    m = nn.Linear(1, 1)
    opt = torch.optim.SGD(m.parameters(), lr=0.5, weight_decay=weight_decay)
    for e in range(epocas):
        loss = nn.BCEWithLogitsLoss()(m(dias), separable)
        opt.zero_grad(); loss.backward(); opt.step()
    acc = ((m(dias) > 0).float() == separable).float().mean().item()
    return loss.item(), m.weight.item(), m.bias.item(), acc

print("Sin regularización:")
for epocas in (100, 1000, 10000):
    loss, w, b, acc = entrenar_separable(epocas)
    print(f"  {epocas:5d} épocas: pérdida {loss:.5f}  w = {w:6.2f}  b = {b:7.2f}  accuracy {acc:.2f}")
print("Con weight_decay = 0.003:")
for epocas in (100, 1000, 10000):
    loss, w, b, acc = entrenar_separable(epocas, weight_decay=0.003)
    print(f"  {epocas:5d} épocas: pérdida {loss:.5f}  w = {w:6.2f}  b = {b:7.2f}  accuracy {acc:.2f}")

14 · Evaluar: entrenamiento y validación, accuracy y umbrales

Para qué sirve Fabricar 200 usuarios con una probabilidad «verdadera» conocida, separar entrenamiento y validación, entrenar, evaluar con accuracy y ver cómo cambia la matriz de confusión al mover el umbral.

g = torch.Generator().manual_seed(7)
N = 200
dias_all = torch.rand(N, 1, generator=g) * 10
prob_real = torch.sigmoid(1.2 * (dias_all - 4.5))
cancela_all = (torch.rand(N, 1, generator=g) < prob_real).float()

X_tr, y_tr = dias_all[:150], cancela_all[:150]
X_va, y_va = dias_all[150:], cancela_all[150:]
print("entrenamiento:", tuple(X_tr.shape), " validación:", tuple(X_va.shape))
print("cancelan en train:", int(y_tr.sum().item()), "de 150; en validación:", int(y_va.sum().item()), "de 50")

torch.manual_seed(0)
modelo = nn.Linear(1, 1)
criterio = nn.BCEWithLogitsLoss()
opt = torch.optim.SGD(modelo.parameters(), lr=0.1)
for epoca in range(3000):
    loss = criterio(modelo(X_tr), y_tr)
    opt.zero_grad(); loss.backward(); opt.step()
print(f"w = {modelo.weight.item():.3f}  b = {modelo.bias.item():.3f}  (la verdad oculta era w = 1.2, b = -5.4)")

modelo.eval()
with torch.no_grad():
    p_va = torch.sigmoid(modelo(X_va))
    loss_va = criterio(modelo(X_va), y_va).item()
print(f"pérdida de entrenamiento {loss.item():.4f}   pérdida de validación {loss_va:.4f}")

for umbral in (0.3, 0.5, 0.7):
    pred = (p_va >= umbral).float()
    acc = (pred == y_va).float().mean().item()
    tp = int(((pred == 1) & (y_va == 1)).sum()); fp = int(((pred == 1) & (y_va == 0)).sum())
    fn = int(((pred == 0) & (y_va == 1)).sum()); tn = int(((pred == 0) & (y_va == 0)).sum())
    print(f"umbral {umbral}: accuracy {acc:.2f}   TP={tp} FP={fp} FN={fn} TN={tn}")

with torch.no_grad():
    print("usuario con 3.5 días -> p =", round(torch.sigmoid(modelo(torch.tensor([[3.5]]))).item(), 3))
