Softmax o sigmoide: multiclase frente a multi-etiqueta

La softmax obliga a elegir: sus probabilidades suman 1, así que si una sube, las otras bajan. Es lo correcto cuando cada muestra tiene exactamente una clase (un dígito es un 3 y solo un 3): clasificación multiclase. Pero hay problemas donde cada muestra puede tener varias etiquetas a la vez (Titanic es «drama» y «romance» a la vez; una serie puede ser «comedia» y «thriller»): clasificación multi-etiqueta. Ahí cada etiqueta es una pregunta de sí/no independiente y lo natural es una sigmoide por salida, con su propia probabilidad entre 0 y 1, sin que sumen nada.

Ejemplo numérico · los mismos logits, dos lecturas (fragmento 19)

Logits de Titanic (cifras inventadas) para «drama», «comedia» y «romance»: \( \mathbf{z} = (2;\ -1;\ 0{,}5) \).

  • Softmax: \( (0{,}7856;\ 0{,}0391;\ 0{,}1753) \), suma 1: «lo más probable es que sea un drama».
  • Sigmoide por etiqueta: \( \sigma(2) = 0{,}8808 \), \( \sigma(-1) = 0{,}2689 \), \( \sigma(0{,}5) = 0{,}6225 \): suman 1,7722, y con umbral 0,5 la predicción es \( [1, 0, 1] \): «drama y romance».
  • Pérdida con etiquetas reales \( (1, 0, 1) \): BCEWithLogitsLoss = media de tres entropías cruzadas binarias \( = \) 0,3048, y coincide con la cuenta a mano.
Ojo

No mezcles: con varias etiquetas a la vez y CrossEntropyLoss, el modelo aprende a repartir el 100 % entre las etiquetas verdaderas (la mejor probabilidad posible para dos etiquetas sería 0,5 y 0,5) en lugar de dar un «sí» claro a cada una. Y con una sola clase por muestra, BCEWithLogitsLoss funciona pero no obliga a que las probabilidades sumen 1 y se aprende peor que con softmax.

2 · Softmax a mano frente a torch.softmax

Para qué sirve Calcula la softmax paso a paso (exponencial, suma, división) y comprueba que coincide con torch.softmax y con la capa nn.Softmax. Muestra también que el argmax no cambia.

import torch
from torch import nn

z = torch.tensor([3.0, 1.0, -1.0])

e = torch.exp(z)
suma = e.sum()
p_mano = e / suma
print("e^z       :", e)
print("suma      :", suma)
print("p a mano  :", p_mano)

p_torch = torch.softmax(z, dim=0)
print("p torch   :", p_torch)
print("¿iguales? :", torch.allclose(p_mano, p_torch))
print("suman     :", p_torch.sum())

capa = nn.Softmax(dim=0)
print("nn.Softmax:", capa(z))

print("clase predicha (argmax de p)     :", torch.argmax(p_torch).item())
print("clase predicha (argmax de logits):", torch.argmax(z).item())

3 · Softmax con un lote: dim=1 frente a dim=0

Para qué sirve Con una matriz de logits (muestras, clases) enseña por qué la softmax va sobre dim=1: con dim=0 no da ningún error, pero normaliza lo que no toca.

import torch

Z = torch.tensor([[ 3.0,  1.0, -1.0,  0.0],
                  [ 0.5,  0.5,  0.5,  0.5],
                  [-2.0,  4.0,  1.0,  1.0]])
print("forma de Z:", tuple(Z.shape), "= (muestras, clases)")

P1 = torch.softmax(Z, dim=1)
P0 = torch.softmax(Z, dim=0)

print("softmax con dim=1:")
print(P1)
print("suma de cada fila   :", P1.sum(dim=1))
print("softmax con dim=0 (mal):")
print(P0)
print("suma de cada fila   :", P0.sum(dim=1))
print("suma de cada columna:", P0.sum(dim=0))

confianza, clase = torch.max(P1, dim=1)
print("clase predicha de cada muestra:", clase)
print("confianza de cada muestra     :", confianza)

19 · Softmax o sigmoide con los mismos logits

Para qué sirve Compara las dos lecturas de los mismos logits, la multiclase (suma 1) y la multi-etiqueta (cada una por separado), y comprueba que BCEWithLogitsLoss es la media de entropías cruzadas binarias.

import torch
from torch import nn

logits = torch.tensor([[2.0, -1.0, 0.5]])

p_soft = torch.softmax(logits, dim=1)
p_sig = torch.sigmoid(logits)
print("softmax (una sola etiqueta):", p_soft.numpy().round(4), "suma =", round(p_soft.sum().item(), 4))
print("sigmoide (varias etiquetas):", p_sig.numpy().round(4), "suma =", round(p_sig.sum().item(), 4))

etiquetas = torch.tensor([[1.0, 0.0, 1.0]])
perdida = nn.BCEWithLogitsLoss()(logits, etiquetas)
print("BCEWithLogitsLoss:", round(perdida.item(), 4))
a_mano = -(etiquetas * torch.log(p_sig) + (1 - etiquetas) * torch.log(1 - p_sig)).mean()
print("a mano           :", round(a_mano.item(), 4))
print("predicción por umbral 0.5:", (p_sig > 0.5).int().tolist())
