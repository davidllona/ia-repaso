El modelo: una sola capa nn.Linear(64, 10) y lo que aprende

Si el modelo es solo una capa lineal con una neurona por dígito, ¿qué contiene exactamente cada neurona después de entrenar, y se puede «ver»?

La regresión softmax (también llamada regresión logística multinomial) es la capa lineal de la primera sección con la pérdida de la sección anterior. Escrita como nn.Module, igual que la regresión lineal y la logística de los módulos 3 y 4:

class RegresionSoftmax(nn.Module):
    def __init__(self, n_entradas, n_clases):
        super().__init__()
        self.lineal = nn.Linear(n_entradas, n_clases)

    def forward(self, x):
        return self.lineal(x)          # logits, SIN softmax

El forward devuelve logits: la softmax la pone la pérdida (al entrenar) o tú, aparte, cuando quieras ver probabilidades. El fragmento 11 crea RegresionSoftmax(64, 10) y comprueba:

  • lineal.weight tiene forma (10, 64) (una fila de 64 pesos por clase) y lineal.bias forma (10,).
  • 650 parámetros \( = 64\cdot 10 + 10 \). Con MNIST (784 entradas) serían 7.850.
  • La salida de un lote de 3 imágenes tiene forma (3, 10), y X @ W.T + b coincide con modelo(X): es literalmente la fórmula \( Z = X W^{\top} + \mathbf{b} \) de la primera sección.

Es equivalente (y más corto) escribirlo con nn.Sequential: nn.Sequential(nn.Linear(64, 10)); con imágenes 2D sin aplanar, nn.Sequential(nn.Flatten(), nn.Linear(784, 10)).

Cada fila de W es una plantilla

La puntuación de la clase \( k \) es \( z_k = \sum_{i} w_{k,i}\,x_i + b_k \): un producto escalar entre la imagen y una fila de pesos. Esa fila de 64 pesos se puede dibujar como una imagen 8×8, una plantilla de la clase. Un peso positivo en un píxel dice «si hay tinta aquí, suma a favor de esta clase» y un peso negativo dice «si hay tinta aquí, resta».

Ejemplo numérico · una plantilla de 4 píxeles

Carátulas diminutas de \( 2\times 2 \) píxeles (1 = píxel oscuro, 0 = claro; aplanadas: \( x_1, x_2, x_3, x_4 \)) y un crítico que busca carátulas con una franja «diagonal»: \( \mathbf{w} = (+1, -1, -1, +1) \), \( b = 0 \).

Imagen\( \mathbf{x} \)\( z = \mathbf{w}\cdot\mathbf{x} \)Lectura
carátula con la diagonal principal oscura(1, 0, 0, 1)1 + 1 = 2encaja con la plantilla: puntuación alta
carátula con la otra diagonal oscura(0, 1, 1, 0)−1 − 1 = −2justo lo contrario: puntuación baja
carátula toda clara(0, 0, 0, 0)0sin píxeles oscuros no hay evidencia (solo cuenta el sesgo)

La puntuación mide cuánto se parece la imagen a la plantilla, con signo. Con 10 plantillas hay 10 puntuaciones, y la softmax las convierte en un reparto.

Las plantillas reales del modelo entrenado se pueden ver. El fragmento 16 dibuja dos en texto: la de la clase 0 tiene pesos positivos formando un anillo (donde un 0 suele tener tinta) y pesos negativos en el centro (un 0 tiene el centro vacío, y tinta ahí le resta puntos). La de la clase 1 es menos legible: un trazo vertical positivo en el centro y negativos a los lados. No esperes plantillas bonitas: se entrenan para separar las clases entre sí, no para parecerse a un dígito, así que contienen también correcciones («esto no es un 8, porque…»).

Ojo

Softmax siempre elige algo. Si le das un garabato que no es ningún dígito, el modelo reparte un 100 % entre los diez dígitos igualmente; la probabilidad más alta no significa «seguro de que es un 3», sino «el 3 es lo menos malo». Para detectar entradas que no son de ninguna clase se necesitan otras técnicas (una clase «ninguna», umbrales de confianza, modelos de detección de anomalías).

11 · El modelo: RegresionSoftmax como nn.Module

Para qué sirve Define el modelo de softmax como una clase de PyTorch, cuenta sus parámetros, comprueba que \( XW^T + b \) coincide con la salida de nn.Linear y provoca tres errores de entrada típicos.

import torch
from torch import nn

class RegresionSoftmax(nn.Module):
    def __init__(self, n_entradas, n_clases):
        super().__init__()
        self.lineal = nn.Linear(n_entradas, n_clases)

    def forward(self, x):
        return self.lineal(x)

torch.manual_seed(42)
modelo = RegresionSoftmax(64, 10)
print(modelo)
for nombre, parametro in modelo.named_parameters():
    print(nombre, tuple(parametro.shape))
total = sum(p.numel() for p in modelo.parameters())
print("parámetros:", total, "= 64*10 + 10 =", 64 * 10 + 10)
print("con 784 entradas (MNIST):", sum(p.numel() for p in nn.Linear(784, 10).parameters()))
