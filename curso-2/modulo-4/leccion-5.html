Posición: cómo sabe un Transformer el orden

La RNN conocía el orden gratis: lo recibía paso a paso. Un Transformer procesa el conjunto de tokens en paralelo y su operación central (la atención) es indiferente al orden: si intercambias dos tokens, los resultados se intercambian igual, pero cada token recibe la misma información. El fragmento 10 lo demuestra con números: con la atención «pelada», el token «persigue» recibe exactamente lo mismo en las dos frases anteriores. Sin posición, para la red son la misma frase.

La solución: sumar a cada embedding un vector que codifique su posición. Si «detective» está en la posición 1 («El detective persigue al ladrón»), su vector de entrada es \(x_1 = \text{embedding}(\text{detective}) + \text{PE}(1)\); si está en la posición 4 («El ladrón persigue al detective»), \(x_4 = \text{embedding}(\text{detective}) + \text{PE}(4)\). Mismo token, entrada distinta según el lugar (como un capítulo que, según el orden en que lo veas, es una sorpresa o un spoiler). En las notas del curso lo resumen así: embedding + posición.

Posición: cómo sabe un Transformer el orden

«El detective persigue al ladrón» ≠ «El ladrón persigue al detective». Un Transformer (lo verás en la sección siguiente) mira todas las palabras a la vez, como si te dieran todos los capítulos de la serie de golpe, sin verlos uno detrás de otro. Entonces, ¿cómo sabe cuál va primero?

Codificación posicional sinusoidal

El Transformer original (2017) construye \(\text{PE}\) con senos y cosenos de distintas frecuencias:

\[ \text{PE}(pos,\,2i) = \sin\!\Big(\frac{pos}{10000^{2i/d}}\Big), \qquad \text{PE}(pos,\,2i+1) = \cos\!\Big(\frac{pos}{10000^{2i/d}}\Big) \]
  • \(pos\): la posición del token (0, 1, 2…).
  • \(d\): el tamaño del vector (\(d_{model}\), el mismo que el del embedding, para poder sumarlos).
  • \(i\): el número de pareja de dimensiones (0, 1, …, \(d/2 - 1\)). Las dimensiones pares (\(2i\)) usan seno y las impares (\(2i+1\)), coseno de el mismo ángulo.
  • \(10000^{2i/d}\): el divisor. Para \(i = 0\) vale 1 (frecuencia alta: el ángulo es la posición misma); a medida que \(i\) crece, el divisor se hace enorme y la onda se hace muy lenta.
Analogía

Un reloj: la manecilla de los segundos da la vuelta cada minuto, la de los minutos cada hora, la de las horas cada 12 horas. Con las tres posiciones puedes decir qué hora es sin ambigüedad, aunque cada manecilla por separado se repite. La codificación posicional hace lo mismo: cada pareja (seno, coseno) es una «manecilla» con su propio ritmo, y el conjunto identifica de forma única cada posición.

Ejemplo numérico

Cada token recibe un «sello de posición», como el número de capítulo en tu maratón (capítulo 0, 1, 2, 3). Veamos cómo se calcula con \(d = 4\): hay dos parejas. Pareja 0 (\(i=0\)): divisor \(10000^{0} = 1\). Pareja 1 (\(i=1\)): divisor \(10000^{2/4} = 100\).

  1. pos = 0: \((\sin 0,\; \cos 0,\; \sin 0,\; \cos 0) = (0,\; 1,\; 0,\; 1)\).
  2. pos = 1: pareja 0 con ángulo \(1/1 = 1\): \(\sin 1 = 0{,}8415\), \(\cos 1 = 0{,}5403\). Pareja 1 con ángulo \(1/100 = 0{,}01\): \(\sin 0{,}01 = 0{,}0100\), \(\cos 0{,}01 = 1{,}0000\).
  3. pos = 2: ángulos 2 y 0,02 → \((0{,}9093,\; -0{,}4161,\; 0{,}0200,\; 0{,}9998)\).
  4. pos = 3: ángulos 3 y 0,03 → \((0{,}1411,\; -0{,}9900,\; 0{,}0300,\; 0{,}9996)\).

Las dos primeras columnas cambian mucho de una posición a la siguiente (distinguen posiciones vecinas); las dos últimas cambian lentamente (distinguen zonas amplias de la frase). Cada fila es distinta: cada posición tiene su «huella».

Por qué senos y cosenos

  • Acotados entre −1 y 1: tienen una escala parecida a la del embedding, así que la suma no lo aplasta (en el artículo original, además, se multiplica el embedding por \(\sqrt{d_{model}}\)).
  • Sin parámetros que aprender y válidos para cualquier longitud, incluso mayor que las vistas en el entrenamiento.
  • La similitud entre dos posiciones es una suma de cosenos que solo depende de su diferencia (\(\cos(a-b) = \cos a \cos b + \sin a \sin b\)): lo vimos en la demo. Así, «el token anterior» o «dos tokens más allá» son relaciones fáciles de aprender para la red.

La alternativa: posiciones aprendidas

Otra opción es tratar la posición como si fuera una palabra más: una segunda tabla Embedding(maxlen, d) cuyas filas se aprenden durante el entrenamiento. Es lo que hace la clase TokenAndPositionEmbedding del fragmento 12 (token + posición, sumados) y lo que usan modelos como BERT y GPT-2. Es sencillo y funciona muy bien, pero tiene un límite fijo (maxlen): no sabe qué hacer con posiciones que nunca vio. Los modelos recientes usan variantes que codifican la posición relativa (por ejemplo, RoPE, que gira las consultas y claves un ángulo que depende de la posición), pero la idea de fondo es la misma: el orden no viene gratis, hay que inyectarlo.

Ojo

La posición se suma al embedding (no se concatena). Por eso los dos tienen que tener el mismo tamaño \(d_{model}\). Y se suma una vez, a la entrada: a partir de ahí, las capas del Transformer se ocupan de mezclar información.

2 · La misma RNN con Keras: SimpleRNN y sus parámetros

Para qué sirve Comprobar que la capa SimpleRNN de Keras hace exactamente la cuenta del fragmento 1, y que su número de parámetros sale de la fórmula \(n_h(n_{in}+n_h+1)\).

import numpy as np
from tensorflow import keras
from tensorflow.keras import layers

W_x = np.array([[1.0], [-1.0]])
W_h = np.array([[0.5, 0.5], [-0.5, 0.5]])
b = np.zeros(2)

capa = layers.SimpleRNN(2, activation="tanh", return_sequences=True)
modelo = keras.Sequential([keras.Input(shape=(3, 1)), capa])
capa.set_weights([W_x.T, W_h.T, b])           # Keras guarda las matrices "traspuestas"

x = np.array([[[1.0], [2.0], [0.0]]], dtype="float32")   # (lote=1, pasos=3, variables=1)
print(modelo.predict(x, verbose=0)[0].round(4))
modelo.summary()

ultima = layers.SimpleRNN(2, return_sequences=False)     # muchos-a-uno: solo el último h
ultima(x)
ultima.set_weights([W_x.T, W_h.T, b])
print("solo el último:", ultima(x).numpy()[0].round(4))

n_in, n_h = 1, 2
print("parámetros (fórmula):", n_h * (n_in + n_h + 1), "| Keras:", capa.count_params())

10 · Codificación posicional sinusoidal y el problema del orden

Para qué sirve Calcular la codificación posicional del Transformer, comprobar que la similitud entre dos posiciones solo depende de su distancia, y demostrar que la atención sin posición no distingue «el detective persigue al ladrón» de «el ladrón persigue al detective».

import numpy as np

def codificacion_posicional(n_pos, d_modelo):
    pos = np.arange(n_pos)[:, None]                   # (n_pos, 1): 0, 1, 2, ...
    i = np.arange(d_modelo // 2)[None, :]             # (1, d/2): una frecuencia por pareja
    angulos = pos / (10000 ** (2 * i / d_modelo))     # (n_pos, d/2)
    pe = np.zeros((n_pos, d_modelo))
    pe[:, 0::2] = np.sin(angulos)                     # dimensiones pares: seno
    pe[:, 1::2] = np.cos(angulos)                     # dimensiones impares: coseno
    return pe

print(codificacion_posicional(4, 4).round(4))
print("a mano, pos=1:", np.round([np.sin(1), np.cos(1), np.sin(0.01), np.cos(0.01)], 4))

# La similitud entre dos posiciones depende solo de la DISTANCIA entre ellas
pe = codificacion_posicional(50, 16)
sim = lambda a, b: pe[a] @ pe[b] / (16 / 2)           # 8 = valor máximo (una posición consigo misma)
print("distancia 1:", round(sim(3, 4), 3), round(sim(20, 21), 3), "| distancia 10:", round(sim(3, 13), 3), round(sim(30, 40), 3))

# ¿Por qué hace falta? Una atención SIN posición no distingue el orden
rng = np.random.default_rng(0)
d = 8
emb = {w: rng.normal(size=d) for w in ["el", "detective", "persigue", "al", "ladrón"]}
Wq, Wk, Wv = (rng.normal(size=(d, d)) for _ in range(3))

def atencion(X):
    Q, K, V = X @ Wq, X @ Wk, X @ Wv
    S = Q @ K.T / np.sqrt(d)
    A = np.exp(S - S.max(axis=1, keepdims=True))
    A /= A.sum(axis=1, keepdims=True)
    return A @ V

f1 = ["el", "detective", "persigue", "al", "ladrón"]
f2 = ["el", "ladrón", "persigue", "al", "detective"]   # misma frase con detective y ladrón intercambiados
X1 = np.array([emb[w] for w in f1])
X2 = np.array([emb[w] for w in f2])
print("sin posición, 'persigue' recibe lo mismo en ambas:", np.allclose(atencion(X1)[2], atencion(X2)[2]))
P = codificacion_posicional(5, d)
print("con posición, 'persigue' recibe lo mismo en ambas:", np.allclose(atencion(X1 + P)[2], atencion(X2 + P)[2]))
