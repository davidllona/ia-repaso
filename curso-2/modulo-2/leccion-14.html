Fallos que no dan ningún mensaje

Los peores son los que ejecutan sin quejarse y dan un modelo malo. Por eso conviene saber reconocer los síntomas:

SíntomaCausa probableQué hacer
La pérdida es nan desde la primera época (fragmento 15, con SGD(learning_rate=10): [nan, nan, nan]) learning_rate demasiado grande; entradas sin normalizar; o datos con valores raros. Baja el learning rate (prueba 0,001), normaliza las entradas y revisa los datos.
La pérdida baja muy despacio o se queda plana Entradas sin normalizar (17,1 frente a 7,0 en el fragmento 5), learning rate diminuto, pocas épocas, o capa final inadecuada (sigmoide en regresión). Normaliza, sube el learning rate, entrena más épocas, revisa la tabla pérdida / capa final.
Hay NaN en los datos y Keras no avisa En el fragmento 15, una sola fila con NaN no produjo ningún error ni una pérdida nan (salió 73,51), y aun así algún peso de la red quedó en NaN. Antes de entrenar, comprueba np.isnan(X).any() y trata los NaN como en el Curso 1 (imputar o eliminar).
«Entreno otra vez» y el modelo no empieza de cero (fragmento 15: la 1.ª llamada termina en 68,44 y la 2.ª empieza en 67,77) fit continúa con los pesos actuales. Para empezar de cero, vuelve a construir el modelo (y a llamar a compile).
Accuracy altísimo en entrenamiento y mediocre en validación/test Sobreajuste. Mira las curvas de History; usa EarlyStopping, una red menor o más datos.
Un resultado «demasiado bueno» Fuga de datos: normalizaste con todo el conjunto, o evaluaste con datos de entrenamiento, o elegiste hiperparámetros mirando el test. Separa train / validación / test antes de nada, y toca el test una sola vez.
Las predicciones del modelo cargado no coinciden con las de antes Falta el preprocesado (normalización) que se aplicó fuera del modelo, o se aplicó otro orden de columnas. Aplica exactamente el mismo preprocesado, o mejor mételo dentro del modelo.
Lista de comprobación antes de entrenar
  1. X.shape e y.shape: ¿cuadran con Input y con la última capa?
  2. ¿Hay NaN? ¿Están las entradas normalizadas?
  3. ¿La capa final, la pérdida y el formato de y son una pareja válida (tabla de compile)?
  4. ¿Es razonable la pérdida de la primera época? Con \( C \) clases debería rondar \( \ln C \).
  5. ¿Has guardado el test sin tocarlo?

14 · regression_demo y classification_demo: dos modelos completos de 8 entradas

Para qué sirve Reunir en dos funciones todo lo visto: una regresión 8 → 5 → 5 → 1 y una clasificación de 4 clases 8 → 5 → 5 → 4. Los datos son sintéticos y conocemos su regla, así que podemos saber si la red la aprende.

import numpy as np
import keras
from keras import layers
from keras.utils import to_categorical

def regression_demo(epochs=20):
    keras.utils.set_random_seed(42)
    X = np.random.normal(size=(1200, 8)).astype("float32")
    pesos = np.array([2.0, -1.5, 0.8, 3.0, -2.0, 1.2, 0.4, 2.5], dtype="float32")
    y = (X @ pesos + 5 + np.random.normal(0, 0.5, size=1200)).astype("float32")
    X_train, y_train, X_test, y_test = X[:1000], y[:1000], X[1000:], y[1000:]

    model = keras.Sequential([
        keras.Input(shape=(8,)),
        layers.Dense(5, activation="relu"),
        layers.Dense(5, activation="relu"),
        layers.Dense(1),
    ])
    model.compile(optimizer="adam", loss="mean_squared_error",
                  metrics=["mean_absolute_error"])
    history = model.fit(X_train, y_train, epochs=epochs, batch_size=32,
                        validation_split=0.2, verbose=0)
    mse, mae = model.evaluate(X_test, y_test, verbose=0)
    pred = model.predict(X_test[:1], verbose=0)[0, 0]
    return history, mse, mae, pred, y_test[0], float(X_test[0] @ pesos + 5)

def classification_demo(epochs=25):
    keras.utils.set_random_seed(42)
    X = np.random.normal(size=(1400, 8)).astype("float32")
    puntuaciones = np.column_stack([X[:, 0] + X[:, 1],
                                    X[:, 2] - X[:, 3],
                                    X[:, 4] + 0.5 * X[:, 5],
                                    X[:, 6] - X[:, 7]])
    etiquetas = np.argmax(puntuaciones, axis=1)
    Y = to_categorical(etiquetas, num_classes=4)
    X_train, Y_train, X_test = X[:1200], Y[:1200], X[1200:]
    et_test = etiquetas[1200:]

    model = keras.Sequential([
        keras.Input(shape=(8,)),
        layers.Dense(5, activation="relu"),
        layers.Dense(5, activation="relu"),
        layers.Dense(4, activation="softmax"),
    ])
    model.compile(optimizer="adam", loss="categorical_crossentropy",
                  metrics=["accuracy"])
    model.fit(X_train, Y_train, epochs=epochs, batch_size=32,
              validation_split=0.2, verbose=0)
    probs = model.predict(X_test, verbose=0)
    return model, probs, et_test, etiquetas[:1200]

def red(salidas=10, entrada=64, compilar=True):
    modelo = keras.Sequential([keras.Input(shape=(entrada,)),
                               layers.Dense(8, activation="relu"),
                               layers.Dense(salidas, activation="softmax")])
    if compilar:
        modelo.compile(optimizer="adam", loss="sparse_categorical_crossentropy")
    return modelo

def provoca(titulo, accion, clave):
    try:
        accion()
        print(f"{titulo:24s}-> sin error")
    except Exception as error:
        texto = re.sub(r"\x1b\[[0-9;]*m", "", str(error))
        texto = " ".join(texto.split())
        frase = re.split(r"\. | Arguments", texto[texto.find(clave):])[0]
        print(f"{titulo:24s}-> {type(error).__name__}: ...{frase}")
