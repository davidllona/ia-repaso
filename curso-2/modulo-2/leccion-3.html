Una capa Dense es una tabla de pesos más un bias, y se cuenta a mano

Antes de entrenar ya puedes saber cuántos números aprenderá tu red: entradas × neuronas + neuronas, capa a capa.

Índice del módulo

Una red recibe 4 rasgos de una película y su primera capa es Dense(8). ¿Cuántos números aprende esa capa: 8, 32 o 40?

40. Cada una de las 8 neuronas tiene un peso por cada una de las 4 entradas (4 × 8 = 32) y además su propio bias (8). Los bias son lo que más se olvida al contar.

Una cadena de capas, y dentro de cada una, una matriz

keras.Sequential([...]) es una lista de capas que los datos atraviesan en orden: la salida de una es la entrada de la siguiente. La primera pieza, keras.Input(shape=(4,)), no calcula nada: solo dice cuántas features tiene una muestra, para que Keras pueda crear ya los pesos.

  • Input4 rasgos
  • Dense 8relu
  • Dense 8relu
  • Dense 3softmax: 3 géneros

En una capa Dense cada neurona está conectada con todas las entradas. Por dentro guarda dos cosas: una matriz de pesos \( W \) de forma (n_in, n_out), donde cada columna son los pesos de una neurona, y un vector de bias \( \mathbf{b} \), uno por neurona. Todas calculan a la vez:

\[ \mathbf{z} = \mathbf{x}\,W + \mathbf{b} \qquad \mathbf{a} = f(\mathbf{z}) \qquad \text{parámetros} = n_{in}\cdot n_{out} + n_{out} \]

Es la neurona del módulo 1 repetida \( n_{out} \) veces. Input y las activaciones no añaden parámetros, y la capa final no se elige libremente: 1 neurona para un número, una por clase para clasificar.

Con números: película → género

Ejemplo numérico: red 4 → 8 → 8 → 3

Cada película se describe con 4 rasgos (género, duración, año de estreno y nota de la crítica) y la red debe repartirla entre 3 géneros (acción, comedia, terror).

CapaCuentaParámetros
Dense(8) (recibe 4 features)4 · 8 + 8 = 32 + 840
Dense(8) (recibe 8)8 · 8 + 8 = 64 + 872
Dense(3) (recibe 8)8 · 3 + 3 = 24 + 327
Total40 + 72 + 27139

Observa que los pesos (los productos) dominan sobre los bias (los sumandos pequeños), y que crecen con el producto de neuronas de capas vecinas: duplicar el ancho de dos capas seguidas casi cuadruplica los pesos entre ellas. En una float32 cada parámetro ocupa 4 bytes: 139 parámetros = 556 bytes. Por eso summary() escribe «772.00 B» para los 193 parámetros de la red del fragmento 3.

Duplicas el ancho de las dos capas ocultas, de 8 y 8 a 16 y 16. ¿Los pesos entre esas dos capas se duplican o casi se cuadruplican?

Se cuadruplican: 8 · 8 = 64 pasa a 16 · 16 = 256. Los pesos crecen con el producto de neuronas de capas vecinas; por eso las redes anchas engordan tan deprisa. Compruébalo en el constructor.

En tres líneas

  • Sequential es una cadena de capas; Input declara cuántas features llegan y no tiene parámetros.
  • Dense(n_out) guarda una matriz (n_in, n_out) y n_out bias: \( \mathbf{z} = \mathbf{x}W + \mathbf{b} \).
  • Parámetros = n_in · n_out + n_out por capa: 4 → 8 → 8 → 3 suma 139.

Sequential, Input y Dense: construir la red

¿Qué hay realmente dentro de una «capa» de Keras? Y, antes de entrenar nada, ¿puedes saber cuántos números va a tener que aprender tu red solo mirando cómo la has definido?

Sequential: una cadena de capas

keras.Sequential([...]) es la forma más sencilla de construir una red: le das una lista de capas y los datos las atraviesan en ese orden, la salida de cada una es la entrada de la siguiente. Vale para el 90 % de las redes de este módulo (las que son una «línea recta» de capas). Más adelante, en el Curso 3, verás la API funcional para redes con ramas o varias entradas.

  • Input(n_features,)
  • Dense 16relu
  • Dense 8relu
  • Dense 1sin activación

Hay dos formas equivalentes de escribirlo. La primera pasa la lista de golpe; la segunda va añadiendo capas con .add():

model = keras.Sequential([keras.Input(shape=(2,)), layers.Dense(16, activation="relu"), layers.Dense(1)])

model = keras.Sequential()
model.add(keras.Input(shape=(2,)))
model.add(layers.Dense(16, activation="relu"))
model.add(layers.Dense(1))

Input: decirle a Keras qué forma tienen las muestras

keras.Input(shape=(2,)) no es una capa que calcule nada y no tiene parámetros: solo declara cuántas features tiene una muestra. Con esa información Keras sabe ya el tamaño de la matriz de pesos de la primera capa (necesita saber cuántas entradas llegan) y puede crear todos los pesos al momento. Si te lo saltas, la red queda «sin construir» hasta que le pasas datos por primera vez, y model.summary() no puede mostrar los parámetros todavía. (En código antiguo verás Dense(16, input_shape=(2,)): significa lo mismo, pero Keras 3 prefiere Input.)

Dense: la capa «totalmente conectada»

Una capa Dense es una fila de neuronas en la que cada neurona está conectada con todas las entradas (de ahí «densa» o fully connected). Su firma, con los argumentos que más vas a tocar:

layers.Dense(units, activation=None, use_bias=True,
             kernel_initializer="glorot_uniform", bias_initializer="zeros", name=None)
ArgumentoQué significa
unitsCuántas neuronas tiene la capa = cuántos números produce por muestra. Es lo único obligatorio.
activationLa función de activación que se aplica a la salida de cada neurona: "relu", "tanh", "sigmoid", "softmax"… Con None (por defecto) no se aplica ninguna: la capa es puramente lineal.
use_biasSi cada neurona suma su bias (el «umbral» que la desplaza). Casi siempre True.
kernel_initializerCon qué números aleatorios empiezan los pesos. Por defecto Glorot uniforme (explicado abajo). Con ReLU también se usa "he_normal".
bias_initializerCon qué empiezan los bias: ceros por defecto.
nameUn nombre legible ("oculta1") para reconocer la capa en summary().

Qué hay dentro: una matriz de pesos y un vector de bias

Todas las neuronas de una capa hacen la misma operación con pesos distintos, así que Keras las calcula todas a la vez con una multiplicación de matrices. Una capa Dense(n_out) que recibe vectores de \( n_{in} \) números guarda dos tensores:

  • La matriz de pesos kernel \( W \), de forma (n_in, n_out): cada columna son los pesos de una neurona.
  • El vector bias \( \mathbf{b} \), de forma (n_out,): un bias por neurona.
\[ \mathbf{z} = \mathbf{x}\,W + \mathbf{b} \qquad\qquad \mathbf{a} = f(\mathbf{z}) \]

\( \mathbf{x} \) es el vector de entrada (una muestra), \( W \) la matriz de pesos, \( \mathbf{b} \) el vector de bias, \( \mathbf{z} \) lo que sale antes de la activación y \( f \) la función de activación (activation=). El resultado \( \mathbf{a} \) es la salida de la capa. Es exactamente la neurona del módulo 1, repetida \( n_{out} \) veces en paralelo.

Ejemplo numérico: una red 2 → 3 → 1 resuelta a mano

Red con una capa oculta de 3 neuronas con ReLU y una salida lineal. Entrada \( \mathbf{x} = [1,\ 2] \): imagina que \( x_1 \) es cuántos actores favoritos salen en la película y \( x_2 \) su duración en horas, y que la salida es las horas que la verías (cifras inventadas; los pesos los hemos puesto a mano). Pesos y bias:

neurona 1neurona 2neurona 3
pesos de x₁ (fila 1 de W₁)0,5−1,00,0
pesos de x₂ (fila 2 de W₁)0,250,51,0
bias \( \mathbf{b}_1 \)0,10,0−3,0

La capa de salida tiene pesos \( W_2 = [1,\ 2,\ 3]^T \) y bias \( b_2 = 0{,}5 \).

  1. Capa oculta, antes de la activación \( \mathbf{z}_1 = \mathbf{x}W_1 + \mathbf{b}_1 \):
    neurona 1: 1·0,5 + 2·0,25 + 0,1 = 1,1
    neurona 2: 1·(−1,0) + 2·0,5 + 0,0 = 0
    neurona 3: 1·0,0 + 2·1,0 + (−3,0) = −1,0
  2. ReLU (deja pasar los positivos y pone 0 a los negativos): \( \mathbf{h} = [1{,}1,\ 0,\ 0] \).
  3. Capa de salida (sin activación): 1,1·1 + 0·2 + 0·3 + 0,5 = 1,6.

Mira las formas: x es (1, 2), W₁ es (2, 3) → z₁ es (1, 3); luego h (1, 3) por W₂ (3, 1) → salida (1, 1). Las columnas de una matriz se «comen» a las filas de la siguiente: por eso el número de neuronas de una capa tiene que coincidir con las filas de la siguiente matriz. El fragmento 4 repite esta cuenta con NumPy y con model.predict y da el mismo 1,6.

Contar los parámetros a mano

Un parámetro es un número que la red aprende: cada peso y cada bias. Como una Dense con \( n_{in} \) entradas y \( n_{out} \) neuronas tiene una matriz \( n_{in} \times n_{out} \) y \( n_{out} \) bias:

\[ \text{parámetros de una capa Dense} = n_{in}\cdot n_{out} + n_{out} \]

El total de la red es la suma de todas sus capas. Input y las activaciones no añaden ninguno.

Fíjate en: Los parámetros de cada capa dependen solo de las neuronas de esa capa y de la anterior (y de si hay bias). La capa final toma su tamaño de la tarea: 1 neurona en regresión y en binaria, tantas como clases en multiclase. Sin capas ocultas queda un modelo lineal (regresión lineal o logística): no puede aprender curvas.

¿Con qué números empiezan los pesos? Inicializadores

Antes de entrenar, los pesos no pueden ser todos iguales ni todos cero: si dos neuronas de una capa empiezan idénticas, reciben exactamente el mismo gradiente y se quedan idénticas para siempre (la simetría nunca se rompe), así que serían una sola neurona repetida. Por eso se inicializan con números aleatorios pequeños. Si fueran demasiado grandes, las salidas explotarían o saturarían las activaciones; si fueran minúsculos, las señales se apagarían capa a capa.

El inicializador por defecto de Dense es Glorot uniforme ("glorot_uniform"): cada peso se saca al azar del intervalo \( [-L,\ L] \) con

\[ L = \sqrt{\frac{6}{n_{in} + n_{out}}} \]

donde \( n_{in} \) y \( n_{out} \) son las neuronas de entrada y de salida de la capa: cuantas más conexiones, más pequeños los pesos, para que la señal mantenga una escala parecida de capa en capa. Para una capa 64 → 64 el límite es \( L = \sqrt{6/128} \approx 0{,}2165 \), y para una 64 → 10 es \( \sqrt{6/74} \approx 0{,}2847 \). (Al crear la capa de 64 → 64 del módulo, el peso más grande en valor absoluto es 0,2164: justo por debajo del límite.) Los bias empiezan en cero porque no hay simetría que romper en ellos.

Ojo: unidades de la última capa

El número de neuronas de la última capa no se elige libremente: lo dicta el problema. Una regresión de un solo valor → Dense(1); una clasificación de 10 clases → Dense(10, activation="softmax"). Si pones Dense(5) para 10 clases, no podrás representar la clase 7 y Keras dará un error de formas al calcular la pérdida.

Ojo: sin activación, apilar capas no sirve de nada

Dos capas lineales seguidas equivalen a una sola. Con \( W_1 = \begin{pmatrix}1&2\\3&4\end{pmatrix} \) y \( W_2 = \begin{pmatrix}1\\-1\end{pmatrix} \), la entrada \( [1,\ 1] \) da \( [4,\ 6] \) tras la primera capa y \( 4 - 6 = -2 \) tras la segunda; pero la multiplicación directa por \( W_1W_2 = \begin{pmatrix}-1\\-1\end{pmatrix} \) da también \( -2 \). Toda la gracia de una red profunda está en las activaciones no lineales de las capas ocultas (en el módulo 1 lo viste con el experimento «sin no linealidad»). En las ocultas se usa casi siempre "relu".

3 · model.summary() y contar los parámetros a mano

Para qué sirve Entender de dónde sale cada número de summary(): cada Dense guarda una matriz de pesos y un vector de bias, y sus parámetros se cuentan con una fórmula.

import keras
from keras import layers

model = keras.Sequential([
    keras.Input(shape=(2,)),
    layers.Dense(16, activation="relu", name="oculta1"),
    layers.Dense(8, activation="relu", name="oculta2"),
    layers.Dense(1, name="salida"),
], name="red_regresion")
model.summary()

for capa in model.layers:
    W, b = capa.get_weights()
    print(f"{capa.name:8s} W{W.shape}  b{b.shape}  ->  {W.size + b.size} parámetros")

a_mano = (2 * 16 + 16) + (16 * 8 + 8) + (8 * 1 + 1)
print("A mano:", a_mano, "| Keras:", model.count_params())

sin_bias = layers.Dense(16, use_bias=False)
sin_bias.build((None, 2))
print("Dense(16) sin bias:", sin_bias.count_params(), "parámetros")

4 · Una capa Dense a mano con NumPy y comparada con Keras

Para qué sirve Demostrar que predict no tiene magia: una red 2 → 3 → 1 es multiplicar matrices, sumar el bias y aplicar ReLU. Calculamos el resultado nosotros y vemos que Keras da lo mismo.

import numpy as np
import keras
from keras import layers

model = keras.Sequential([
    keras.Input(shape=(2,)),
    layers.Dense(3, activation="relu"),
    layers.Dense(1),
])

W1 = np.array([[0.5, -1.0, 0.0],
               [0.25, 0.5, 1.0]])
b1 = np.array([0.1, 0.0, -3.0])
W2 = np.array([[1.0], [2.0], [3.0]])
b2 = np.array([0.5])
model.layers[0].set_weights([W1, b1])
model.layers[1].set_weights([W2, b2])

x = np.array([[1.0, 2.0]])
z1 = x @ W1 + b1
h1 = np.maximum(0, z1)
y_mano = h1 @ W2 + b2

print("z1 (antes de ReLU):", z1)
print("h1 (después de ReLU):", h1)
print("salida a mano:", y_mano)
print("salida de Keras:", model.predict(x, verbose=0))
