La sintaxis de Python que vas a ver

Variable y el signo =
Un nombre que guarda un valor. b = 0.5 se lee «guarda 0,5 con el nombre b». Dos signos, ==, preguntan «¿es igual?».
print
Escribe algo en pantalla. Todo lo que ves en «Salida» sale de un print.
Comentario #
Lo que va detrás de # es una nota para humanos. Python lo ignora.
def y return
def escribe una receta con nombre (una función); return dice qué devuelve. La receta no hace nada hasta que la llamas: sigmoide(0.5).
Argumento con valor por defecto
En def leaky(z, alfa=0.1), si no dices nada, alfa vale 0,1. Al llamar puedes cambiarlo: leaky(z, alfa=0.3).
lambda
Una función de una línea sin nombre. lambda z: max(0, z) = «dame z y te devuelvo el mayor entre 0 y z».
Sangría
Los espacios a la izquierda dicen qué líneas van dentro de un def, for, if o with.
for … in …
Un bucle: repite las líneas sangradas una vez por cada elemento. for n in (1, 2, 4): da tres vueltas.
range
Cuenta números seguidos sin incluir el último. range(1, 4) da 1, 2 y 3.
enumerate, zip, reversed
Numerar los elementos; juntar dos listas por parejas; recorrer una lista al revés.
if, elif, else
«Si…», «si no, si…», «si no…». and es «y», or es «o», in es «¿está en…?».
break
Sale del bucle en ese momento, aunque queden vueltas.
Lista [ ] y tupla ( )
Varios valores en orden. [1, 2] se puede cambiar; (1, 2), no.
Diccionario { }
Parejas clave: valor. p["W1"] saca el valor guardado con la clave «W1».
Corchetes y cortes
Se cuenta desde 0. x[0]: el primero. x[-1]: el último. X[:40]: los 40 primeros. X[40:100]: del 40 al 99. [0, 0]: fila 0, columna 0.
Lista por comprensión
Una lista fabricada con un bucle dentro de los corchetes. [np.zeros_like(p) for p in P]: «un montón de ceros por cada p de P».
Varios nombres a la vez
z, a = neurona(…): la función devuelve dos cosas y Python las reparte en dos nombres, por orden.
-=
«Réstale y guárdalo en el mismo sitio». w -= 0.1 es lo mismo que w = w - 0.1.
** y %
x ** 2 es «x al cuadrado». epoca % 400 es el resto de dividir entre 400 (vale 0 en 0, 400, 800…).
True, False, None
Verdadero, falso y «nada». is not None pregunta «¿tiene algo?».
f-string
Un texto con f delante: lo que va entre llaves se sustituye por su valor. {w:.4f} = con 4 decimales; {n:3d} = entero en 3 huecos; {nombre:9s} = texto en 9 huecos; {g:.2e} = notación científica.

Abre un «bloque especial» que hace algo al entrar y al salir. Aquí: grabar las cuentas para derivarlas (paso 6).
**kw
Abre un diccionario como argumentos con nombre. f(**{"l2": 0.003}) es f(l2=0.003).

NumPy: las cuentas a mano

NumPy (np)
La librería de cuentas con listas enteras de números. El nombre viene de «Numerical Python»; todo el mundo la apoda np. Aquí hace TODAS las cuentas a mano: sumas ponderadas, activaciones, gradientes.
np.array
Convierte una lista en un array: una lista con la que se calcula de golpe. Con corchetes dobles es una tabla (matriz). 2 * x dobla los cuatro números a la vez.
Vector y matriz
Un vector es una fila de números (las entradas de una película). Una matriz es una tabla de números (los pesos de una capa: una fila por neurona).
np.dot y @
Producto punto: multiplica pareja a pareja y suma. W1 @ x lo hace con cada fila de la matriz: todas las sumas ponderadas de una capa de una vez.
np.exp, np.log, np.sqrt, np.tanh
«e elevado a», logaritmo natural, raíz cuadrada y tangente hiperbólica, de cada número.
np.maximum y np.where
np.maximum(0, z): el mayor entre 0 y cada z (la ReLU). np.where(cond, a, b): «a donde se cumple, b donde no».
np.mean y np.sum
Media y suma. Con axis=1 suman cada fila; con axis=0, cada columna.
np.round y round
Redondear. np.round sirve para listas enteras; round, para un número suelto.
np.outer
Multiplica cada número de una lista por cada uno de otra y forma una tabla. Delta de cada neurona × cada entrada.
np.zeros, zeros_like, ones_like
Listas llenas de ceros (o unos). _like = «con la misma forma que esta otra».
np.random.default_rng
Una máquina de números al azar con semilla: misma semilla, mismos números. Luego: .normal (campana alrededor de una media), .uniform (entre dos valores), .random (entre 0 y 1).
np.random.seed y rand
La forma antigua de fijar la semilla de NumPy y sacar números entre 0 y 1.
np.linspace y np.diff
n números igual de separados entre dos valores; restar cada número al siguiente.
reshape, ravel, .T
Recolocar los números: reshape(-1, 1) los pone en columna; ravel() los aplana en una fila; .T gira la tabla (filas por columnas).
.shape
La forma de un array: (filas, columnas). (1000, 2): 1.000 usuarios con 2 datos.
dtype y float32
El tipo de número guardado. float32 son decimales de 32 bits: menos precisos, pero ocupan la mitad. Es lo habitual en redes.
.astype y .copy
Cambiar de tipo (verdadero/falso a 1/0); hacer una copia independiente.
np.allclose, isclose, array_equal
«¿Son iguales salvo errores diminutos?» (para listas o un número) y «¿son exactamente iguales?».
np.linalg.norm
Resume una lista o una tabla en un solo número: su tamaño.
np.inf
Infinito. Sirve como «peor pérdida posible» para empezar a comparar.

TensorFlow y Keras: las redes ya montadas

TensorFlow (tf)
La librería de Google para redes neuronales. Hace las mismas cuentas que NumPy, pero además sabe derivar sola y usar la tarjeta gráfica. El nombre: los «tensores» fluyen (en inglés, «flow») por la red. Su apodo es tf.
Tensor
Así llama TensorFlow a sus arrays: listas o tablas de números. .numpy() convierte un tensor en un array de NumPy.
tf.Variable y tf.constant
Un número que se puede cambiar (y derivar), y otro fijo. Pesos = variables; entradas = constantes.
tf.GradientTape
Una «cinta» que graba las cuentas para después hacerlas hacia atrás. cinta.gradient(…) devuelve todas las derivadas: es backpropagation automática.
tf.sigmoid, tf.math.log, matvec, tensordot
Sigmoide, logaritmo, matriz por vector y producto punto, en versión TensorFlow (para que la cinta las grabe).
Keras (keras)
La parte de TensorFlow que monta redes con piezas: capas, pérdidas, optimizadores. Se importa con from tensorflow import keras. «Keras» es «cuerno» en griego: viene de un poema de la Odisea.
Capa (keras.layers)
Una columna de neuronas que calculan a la vez. keras.layers es el cajón donde están todos los tipos de capa.
keras.Sequential
Una red que es una pila de capas, una detrás de otra. Lo que sale de una entra en la siguiente.
Input(shape=(2,))
Declara cuántos números entran por ejemplo: aquí 2 (encaje del género y duración).
Dense
Capa densa: cada neurona conectada con todas las de antes. Dense(8, activation="relu") = 8 neuronas con ReLU.
Dropout
Capa que, al entrenar, apaga al azar una parte de las neuronas (el freno de la lección 8).
regularizers.l2
El «impuesto» a los pesos grandes. Se pone en una capa con kernel_regularizer=… (kernel = la tabla de pesos).
compile
Prepara el entrenamiento: qué optimizador mueve los pesos, qué pérdida se baja y qué métricas se enseñan. No entrena aún.
optimizers.SGD y optimizers.Adam
Dos formas de dar el paso cuesta abajo (lección 7). learning_rate es el tamaño del paso.
"binary_crossentropy"
La entropía cruzada binaria: la pérdida para preguntas de sí o no (lección 4).
fit
«Ajustar»: la orden de entrenar. Repite forward, pérdida, backward y actualización. epochs = cuántas pasadas por los datos; batch_size = ejemplos por actualización.
validation_split
Aparta una parte de los datos de entrenamiento para vigilar si la red memoriza. 0.2 = el 20 %.
callbacks.EarlyStopping
Un vigilante que para el entrenamiento cuando la validación deja de mejorar. patience = épocas de paciencia; restore_best_weights = volver a los mejores pesos.
predict y evaluate
Predecir con la red entrenada; y ponerle nota con datos que no vio (pérdida y acierto).
get_weights, set_weights, count_params
Leer los pesos, ponerlos a mano y contarlos.
keras.losses
El cajón de pérdidas ya programadas: MeanSquaredError, binary_crossentropy, categorical_crossentropy.
set_random_seed
keras.utils.set_random_seed(42) fija a la vez el azar de Python, NumPy y TensorFlow. tf.random.set_seed fija solo el de TensorFlow.
verbose=0
«No me escribas el progreso». Sin él, Keras pinta barras de carga en cada época.

Paso 1 · Una neurona en NumPy (fragmento 1)

Para qué sirve Escribir la neurona como una función: entradas por pesos, más bias, y después la activación. Luego se cambia solo la activación para ver que la suma no cambia.

import numpy as np

def sigmoide(z):
    return 1 / (1 + np.exp(-z))

def neurona(x, w, b, activacion):
    z = np.dot(w, x) + b      # suma ponderada: w1*x1 + w2*x2 + ... + b
    a = activacion(z)         # función de activación
    return z, a

x = np.array([0.9, 0.6])      # entradas
w = np.array([2.0, -3.0])     # pesos
b = 0.5                       # bias

z, a = neurona(x, w, b, sigmoide)
print("z =", round(z, 4))
print("a =", round(a, 4))
print("¿Decide «sí»?", a > 0.5)

# La misma suma ponderada con otras activaciones
print("ReLU:", round(neurona(x, w, b, lambda z: max(0, z))[1], 4))
print("tanh:", round(neurona(x, w, b, np.tanh)[1], 4))

# El otro ejemplo del módulo, con números enteros: x = (2, 3), w = (0.5, 1), b = 0.5
z2, a2 = neurona(np.array([2.0, 3.0]), np.array([0.5, 1.0]), 0.5, sigmoide)
print("z =", z2, "| sigmoide:", round(a2, 4), "| tanh:", round(float(np.tanh(z2)), 4))

Paso 2 · Activaciones, sus derivadas y softmax (fragmento 2)

Para qué sirve Ver en cinco valores de z dónde cada activación deja pasar pendiente y dónde se aplana (satura). Y repartir tres puntuaciones en probabilidades que suman 1.

import numpy as np

def sigmoide(z):    return 1 / (1 + np.exp(-z))
def tanh(z):        return np.tanh(z)
def relu(z):        return np.maximum(0, z)
def leaky(z, alfa=0.1):  return np.where(z > 0, z, alfa * z)

def d_sigmoide(z):
    s = sigmoide(z)
    return s * (1 - s)
def d_tanh(z):      return 1 - np.tanh(z) ** 2
def d_relu(z):      return (z > 0).astype(float)
def d_leaky(z, alfa=0.1):  return np.where(z > 0, 1.0, alfa)

z = np.array([-5.0, -2.0, 0.0, 2.0, 5.0])
print("z          ", z)
for nombre, f, df in [("sigmoide", sigmoide, d_sigmoide), ("tanh", tanh, d_tanh),
                      ("ReLU", relu, d_relu), ("LeakyReLU", leaky, d_leaky)]:
    print(f"{nombre:9s} f ", np.round(f(z), 4))
    print(f"{nombre:9s} f'", np.round(df(z), 4))

def softmax(z):
    e = np.exp(z - np.max(z))     # restar el máximo evita desbordamientos
    return e / e.sum()

p = softmax(np.array([2.0, 1.0, 0.1]))
print("softmax:", np.round(p, 4), "suma =", p.sum())

import numpy as np

def gradient_descent_demo():
    x = np.array([1.0, 2.0, 3.0, 4.0], dtype=np.float32)    # entradas
    y = 2 * x                                               # salidas correctas: y = 2x

    weight = np.float32(0.2)                                # peso inicial: lo único que hay que aprender
    lr = 0.01                                               # learning rate
    epochs = 200

    for epoch in range(1, epochs + 1):
        prediction = weight * x                             # 1) forward: predicción con el peso actual
        error = prediction - y                              # 2) error de cada ejemplo
        mse = np.mean(error ** 2)                           # 3) pérdida (error cuadrático medio)
        gradient = np.mean(2 * error * x)                   # 4) derivada del MSE respecto al peso
        if epoch == 1 or epoch % 40 == 0:
            print(f"Época {epoch:3d} | peso = {weight:.4f} | MSE = {mse:.6f}")
        weight -= lr * gradient                             # 5) actualizar: un paso cuesta abajo

    print("Peso aprendido:", round(float(weight), 4))
    print("Peso correcto: 2.0")

import numpy as np

def sigmoide(z):
    return 1 / (1 + np.exp(-z))

def adelante(x, p):
    h = sigmoide(p["W1"] @ x + p["b1"])
    y_hat = sigmoide(p["v"] @ h + p["c"])
    return h, y_hat

def perdida(y, y_hat):
    return -(y * np.log(y_hat) + (1 - y) * np.log(1 - y_hat))

    d_o = y_hat - y
    d_h = d_o * p["v"] * h * (1 - h)
    return {"W1": np.outer(d_h, x), "b1": d_h, "v": d_o * h, "c": d_o}

import numpy as np

    return 1 / (1 + np.exp(-z))

y = np.array([[0], [1], [1], [0]], dtype=float)           # XOR: 1 solo si las entradas son distintas

def entrenar_xor(semilla, eta=0.5, epocas=2000, verbose=False):
    rng = np.random.default_rng(semilla)
    W1 = rng.normal(0, 1, (2, 4)); b1 = np.zeros((1, 4))   # capa oculta: 4 neuronas
    W2 = rng.normal(0, 1, (4, 1)); b2 = np.zeros((1, 1))   # capa de salida: 1 neurona
    for epoca in range(epocas + 1):
        # --- forward ---
        h = np.tanh(X @ W1 + b1)
        y_hat = sigmoide(h @ W2 + b2)
        loss = -np.mean(y * np.log(y_hat) + (1 - y) * np.log(1 - y_hat))
        # --- backward ---
        d_o = (y_hat - y) / len(X)                        # dL/dz de la salida (media de 4 ejemplos)
        gW2 = h.T @ d_o
        gb2 = d_o.sum(axis=0, keepdims=True)
        d_h = (d_o @ W2.T) * (1 - h ** 2)                 # tanh'(z) = 1 - tanh(z)^2
        gW1 = X.T @ d_h
        gb1 = d_h.sum(axis=0, keepdims=True)
        # --- actualizar ---
        W1 -= eta * gW1; b1 -= eta * gb1
        W2 -= eta * gW2; b2 -= eta * gb2
        if verbose and epoca % 400 == 0:
            print(f"época {epoca:4d} | loss = {loss:.4f}")
    return y_hat

y_hat = entrenar_xor(semilla=1, verbose=True)

Paso 9 · Los cuatro optimizadores a mano (fragmento 10)

import numpy as np

def f(w):                                   # coste: valle largo en w1 y muy estrecho en w2
    return 0.5 * (0.25 * w[0] ** 2 + 40 * w[1] ** 2)

def grad(w):                                # gradiente de f (derivadas parciales)
    return np.array([0.25 * w[0], 40 * w[1]])

def optimizar(metodo, lr, pasos=100, beta=0.9, rho=0.9, beta1=0.9, beta2=0.999, eps=1e-7):
    w = np.array([-4.0, 0.8])               # punto de partida
    v = np.zeros(2)                         # "velocidad" (momentum)
    s = np.zeros(2)                         # media de g^2 (RMSprop y Adam)
    m = np.zeros(2)                         # media de g (Adam)
    historial = [f(w)]
    for t in range(1, pasos + 1):
        g = grad(w)
        if metodo == "sgd":
            w = w - lr * g
        elif metodo == "momentum":
            v = beta * v - lr * g
            w = w + v
        elif metodo == "rmsprop":
            s = rho * s + (1 - rho) * g ** 2
            w = w - lr * g / (np.sqrt(s) + eps)
        elif metodo == "adam":
            m = beta1 * m + (1 - beta1) * g
            s = beta2 * s + (1 - beta2) * g ** 2
            m_hat = m / (1 - beta1 ** t)    # corrección de arranque
            s_hat = s / (1 - beta2 ** t)
            w = w - lr * m_hat / (np.sqrt(s_hat) + eps)
        historial.append(f(w))
    return w, historial

print("coste f tras N pasos (lr = 0.04, partiendo de f = %.2f)" % f(np.array([-4.0, 0.8])))
print("método      N=10     N=25     N=50     N=100")
for metodo in ("sgd", "momentum", "rmsprop", "adam"):
    w, h = optimizar(metodo, lr=0.04)
    print(f"{metodo:9s} {h[10]:8.4f} {h[25]:8.4f} {h[50]:8.4f} {h[100]:8.4f}")

import numpy as np
from sklearn.datasets import make_moons

def sigmoide(z):
    return 1 / (1 + np.exp(-z))

def perdida(y, p):
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

def adelante(X, P, m1=1.0, m2=1.0):
    a1 = np.tanh(X @ P["W1"] + P["b1"])
    a2 = np.tanh((a1 * m1) @ P["W2"] + P["b2"])
    p = sigmoide((a2 * m2) @ P["W3"] + P["b3"])
    return a1, a2, p

def entrenar(Xtr, ytr, Xva, yva, l2=0.0, dropout=0.0, paciencia=None, epocas=3000, eta=0.1):
    rng = np.random.default_rng(0)
    H = 32                                                   # red grande para 40 datos: puede memorizar
    P = {"W1": rng.normal(0, np.sqrt(1 / 2), (2, H)),  "b1": np.zeros(H),
         "W2": rng.normal(0, np.sqrt(1 / H), (H, H)),  "b2": np.zeros(H),
         "W3": rng.normal(0, np.sqrt(1 / H), (H, 1)),  "b3": np.zeros(1)}
    ytr, yva = ytr.reshape(-1, 1), yva.reshape(-1, 1)
    mejor, mejor_loss, mejor_ep = None, np.inf, 0
    for ep in range(epocas):
        # dropout: apaga neuronas al azar y reescala las que quedan (solo en entrenamiento)
        m1 = (rng.random((len(Xtr), H)) >= dropout) / (1 - dropout)
        m2 = (rng.random((len(Xtr), H)) >= dropout) / (1 - dropout)
        a1, a2, p = adelante(Xtr, P, m1, m2)
        # backpropagation
        d3 = (p - ytr) / len(Xtr)
        dz2 = (d3 @ P["W3"].T) * m2 * (1 - a2 ** 2)
        dz1 = (dz2 @ P["W2"].T) * m1 * (1 - a1 ** 2)
        G = {"W3": (a2 * m2).T @ d3,  "b3": d3.sum(0),
             "W2": (a1 * m1).T @ dz2, "b2": dz2.sum(0),
             "W1": Xtr.T @ dz1,       "b1": dz1.sum(0)}
        for k in P:
            peso_l2 = 2 * l2 * P[k] if k.startswith("W") else 0   # regularización L2: gradiente de l2 * w^2
            P[k] = P[k] - eta * (G[k] + peso_l2)
        # early stopping: vigilamos la pérdida en validación
        loss_va = perdida(yva, adelante(Xva, P)[2])
        if loss_va < mejor_loss - 1e-4:
            mejor, mejor_loss, mejor_ep = {k: w.copy() for k, w in P.items()}, loss_va, ep
        elif paciencia is not None and ep - mejor_ep >= paciencia:
            break
    return (mejor if paciencia is not None else P), ep + 1

def adelante(x, p):

def f(w):                                   # coste: valle largo en w1 y muy estrecho en w2
    return 0.5 * (0.25 * w[0] ** 2 + 40 * w[1] ** 2)

def grad(w):                                # gradiente de f (derivadas parciales)
    return np.array([0.25 * w[0], 40 * w[1]])

def optimizar(metodo, lr, pasos=100, beta=0.9, rho=0.9, beta1=0.9, beta2=0.999, eps=1e-7):
    w = np.array([-4.0, 0.8])               # punto de partida
    v = np.zeros(2)                         # "velocidad" (momentum)
    s = np.zeros(2)                         # media de g^2 (RMSprop y Adam)
    m = np.zeros(2)                         # media de g (Adam)
    historial = [f(w)]
    for t in range(1, pasos + 1):
        g = grad(w)
        if metodo == "sgd":
            w = w - lr * g
        elif metodo == "momentum":
            v = beta * v - lr * g
            w = w + v
        elif metodo == "rmsprop":
            s = rho * s + (1 - rho) * g ** 2
            w = w - lr * g / (np.sqrt(s) + eps)
        elif metodo == "adam":
            m = beta1 * m + (1 - beta1) * g
            s = beta2 * s + (1 - beta2) * g ** 2
            m_hat = m / (1 - beta1 ** t)    # corrección de arranque
            s_hat = s / (1 - beta2 ** t)
            w = w - lr * m_hat / (np.sqrt(s_hat) + eps)
        historial.append(f(w))
    return w, historial

def sigmoide(z):
    return 1 / (1 + np.exp(-z))

def perdida(y, p):
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

def adelante(X, P, m1=1.0, m2=1.0):
    a1 = np.tanh(X @ P["W1"] + P["b1"])
    a2 = np.tanh((a1 * m1) @ P["W2"] + P["b2"])
    p = sigmoide((a2 * m2) @ P["W3"] + P["b3"])
    return a1, a2, p

def entrenar(Xtr, ytr, Xva, yva, l2=0.0, dropout=0.0, paciencia=None, epocas=3000, eta=0.1):
    rng = np.random.default_rng(0)
    H = 32                                                   # red grande para 40 datos: puede memorizar
    P = {"W1": rng.normal(0, np.sqrt(1 / 2), (2, H)),  "b1": np.zeros(H),
         "W2": rng.normal(0, np.sqrt(1 / H), (H, H)),  "b2": np.zeros(H),
         "W3": rng.normal(0, np.sqrt(1 / H), (H, 1)),  "b3": np.zeros(1)}
    ytr, yva = ytr.reshape(-1, 1), yva.reshape(-1, 1)
    mejor, mejor_loss, mejor_ep = None, np.inf, 0
    for ep in range(epocas):
        # dropout: apaga neuronas al azar y reescala las que quedan (solo en entrenamiento)
        m1 = (rng.random((len(Xtr), H)) >= dropout) / (1 - dropout)
        m2 = (rng.random((len(Xtr), H)) >= dropout) / (1 - dropout)
        a1, a2, p = adelante(Xtr, P, m1, m2)
        # backpropagation
        d3 = (p - ytr) / len(Xtr)
        dz2 = (d3 @ P["W3"].T) * m2 * (1 - a2 ** 2)
        dz1 = (dz2 @ P["W2"].T) * m1 * (1 - a1 ** 2)
        G = {"W3": (a2 * m2).T @ d3,  "b3": d3.sum(0),
             "W2": (a1 * m1).T @ dz2, "b2": dz2.sum(0),
             "W1": Xtr.T @ dz1,       "b1": dz1.sum(0)}
        for k in P:
            peso_l2 = 2 * l2 * P[k] if k.startswith("W") else 0   # regularización L2: gradiente de l2 * w^2
            P[k] = P[k] - eta * (G[k] + peso_l2)
        # early stopping: vigilamos la pérdida en validación
        loss_va = perdida(yva, adelante(Xva, P)[2])
        if loss_va < mejor_loss - 1e-4:
            mejor, mejor_loss, mejor_ep = {k: w.copy() for k, w in P.items()}, loss_va, ep
        elif paciencia is not None and ep - mejor_ep >= paciencia:
            break
    return (mejor if paciencia is not None else P), ep + 1

def gradientes_por_capa(activacion, init, capas=10, ancho=16, semilla=0):
    rng = np.random.default_rng(semilla)
    tam = [8] + [ancho] * capas + [1]
    Ws = []
    for n_in, n_out in zip(tam[:-1], tam[1:]):
        if init == "xavier":
            std = np.sqrt(2 / (n_in + n_out))
        elif init == "he":
            std = np.sqrt(2 / n_in)
        else:
            std = init                                   # un número fijo
        Ws.append(rng.normal(0, std, (n_in, n_out)))
    X = rng.normal(0, 1, (32, 8))
    t = rng.normal(0, 1, (32, 1))
    # forward (guardamos las activaciones y las derivadas de cada capa)
    a, derivadas, entradas = X, [], []
    for i, W in enumerate(Ws):
        entradas.append(a)
        z = a @ W
        if i == len(Ws) - 1:                             # última capa: lineal
            a = z; derivadas.append(np.ones_like(z))
        elif activacion == "sigmoide":
            a = sigmoide(z); derivadas.append(a * (1 - a))

    return normas

Fragmento 16 · Construir una curva con neuronas ReLU

Para qué sirve Calcular a mano, sin entrenar, los pesos de una red con n neuronas ReLU que une con rectas puntos de la curva sin(2x). Y medir cómo baja el error al añadir neuronas. Es la cuenta que hay detrás de la demo «Aproximar una curva con neuronas ReLU».

import numpy as np

def objetivo(x):
    return np.sin(2 * x)

def construir(n, a=-3.0, b=3.0):
    """Pesos de una red 1-n-1 con neuronas ReLU que une n+1 puntos de la curva con rectas."""
    t = np.linspace(a, b, n + 1)                  # n+1 puntos: sus n primeros son los «codos»
    pendiente = np.diff(objetivo(t)) / np.diff(t) # pendiente de cada trozo recto
    c = np.diff(pendiente, prepend=0.0)           # cada neurona CAMBIA la pendiente respecto al trozo anterior
    return t[:-1], c, objetivo(a)                 # codos, pesos de salida, bias de salida

def red(x, codos, c, b):
    # capa oculta: ReLU(1·x - codo) para cada neurona; salida: suma ponderada + bias
    ocultas = np.maximum(0, x.reshape(-1, 1) - codos.reshape(1, -1))
    return ocultas @ c + b

x = np.linspace(-3, 3, 601)
for n in (1, 2, 4, 8, 12, 20):
    codos, c, b = construir(n)
    error = red(x, codos, c, b) - objetivo(x)
    print(f"n = {n:2d} neuronas | parámetros = {3 * n + 1:2d} | error máx = {np.abs(error).max():.3f} | MSE = {np.mean(error ** 2):.2e}")

Fragmento 15 · ¿Cuántas neuronas? Entrenar redes de distinto ancho

Para qué sirve Ahora sí entrenando (con Adam): redes de 1 a 32 neuronas ocultas aprenden sin(6πx), tres ondas, y se mide el error en puntos que no vieron. Muestra qué pasa con muy pocas neuronas, con las justas y con muchas.

import numpy as np

x = np.linspace(0, 1, 80).reshape(-1, 1)                  # 80 puntos para entrenar
y = np.sin(6 * np.pi * x)                                 # curva objetivo: 3 ondas completas
x_test = np.linspace(0.005, 0.995, 100).reshape(-1, 1)    # puntos intermedios que no ha visto
y_test = np.sin(6 * np.pi * x_test)

def entrenar(ancho, pasos=4000, lr=0.02):
    rng = np.random.default_rng(0)
    P = [rng.normal(0, 2, (1, ancho)), rng.normal(0, 1, (1, ancho)),          # W1, b1
         rng.normal(0, 1 / np.sqrt(ancho), (ancho, 1)), np.zeros((1, 1))]     # W2, b2
    m = [np.zeros_like(p) for p in P]                     # memorias de Adam (media de g)
    s = [np.zeros_like(p) for p in P]                     # memorias de Adam (media de g^2)
    for t in range(1, pasos + 1):
        a = np.tanh(x @ P[0] + P[1])                      # capa oculta con `ancho` neuronas tanh
        salida = a @ P[2] + P[3]                          # salida lineal (es regresión)
        d = 2 * (salida - y) / len(x)                     # derivada del MSE respecto a la salida
        da = (d @ P[2].T) * (1 - a ** 2)                  # se propaga hacia atrás por la tanh
        G = [x.T @ da, da.sum(0, keepdims=True), a.T @ d, d.sum(0, keepdims=True)]
        for i in range(4):                                # paso de Adam para cada parámetro
            m[i] = 0.9 * m[i] + 0.1 * G[i]
            s[i] = 0.999 * s[i] + 0.001 * G[i] ** 2
            P[i] = P[i] - lr * (m[i] / (1 - 0.9 ** t)) / (np.sqrt(s[i] / (1 - 0.999 ** t)) + 1e-8)
    pred = np.tanh(x_test @ P[0] + P[1]) @ P[2] + P[3]
    return np.mean((pred - y_test) ** 2)

for ancho in (1, 2, 4, 6, 8, 16, 32):
    print(f"{ancho:2d} neuronas ocultas -> MSE en test = {entrenar(ancho):.5f}")

  • Una red es la cuenta de una neurona (suma ponderada + activación) repetida capa a capa.

  • Keras hace lo mismo que nuestras cuentas a mano: Sequential, compile, fit, evaluate y predict.
