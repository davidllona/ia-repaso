El modelo: VGG16 congelada y una cabeza nueva

Ya tenemos los datos en lotes. ¿Cómo se construye, paso a paso, el modelo que decide «abolladura o grieta»?

Tarea 3: la base

  1. base_model = VGG16(weights='imagenet', include_top=False, input_shape=(img_rows, img_cols, 3)): la parte convolucional, con 7×7×512 de salida (sección «VGG16 por dentro»).
  2. output = base_model.layers[-1].output: coge la salida de la última capa de la base (el tensor 7×7×512).
  3. output = keras.layers.Flatten()(output): le añade un Flatten que aplana esos 7·7·512 en 25.088 valores por imagen. Flatten no aprende: solo reordena.
  4. base_model = Model(base_model.input, output): construye un modelo nuevo que va desde la entrada de VGG16 hasta ese Flatten. A partir de aquí la «base» ya incluye el aplanado.
  5. for layer in base_model.layers: layer.trainable = False: congela todas las capas. Sin esto, el entrenamiento reescribiría los 14,7 millones de pesos con tus pocas fotos.

La cabeza nueva

model = Sequential()
model.add(base_model)                        # VGG16 + Flatten → 25.088 valores
model.add(Dense(512, activation='relu'))
model.add(Dropout(0.3))
model.add(Dense(512, activation='relu'))
model.add(Dropout(0.3))
model.add(Dense(1, activation='sigmoid'))    # una probabilidad
  • Dense(512, relu) dos veces: capas ocultas que aprenden a combinar las 25.088 características de VGG16 en patrones «de daño». Que sean 512 es una decisión de diseño (un hiperparámetro), no una ley.
  • Dropout(0.3): en cada paso de entrenamiento, apaga al azar el 30 % de las unidades de esa capa (no borra neuronas para siempre: en el paso siguiente se sortean otras). Obliga a la red a no depender de unas pocas neuronas, lo que reduce el sobreajuste. En predicción no apaga nada.
  • Dense(1, sigmoid): una sola neurona de salida. La sigmoide convierte cualquier número \( z \) en una probabilidad entre 0 y 1: \( \sigma(z) = 1/(1+e^{-z}) \).

Si la neurona final saca \( z = 2 \), la red dice «88 % de probabilidad de clase 1 (dent)». Con \( z = -2 \), «12 %», es decir, 88 % de que sea crack. Se decide con un umbral: normalmente 0,5. Es lo mismo que cuando Netflix te dice «88 % de coincidencia» con una película: solo te la propone si pasa de cierto umbral.

Dropout, con números

Imagina un panel de 12 críticos que puntúan una película. Cada día faltan algunos al azar; para que la nota total del panel no baje, los que sí vienen opinan con más fuerza. Con números: si se apaga el 30 % de las unidades, las que quedan encendidas deben compensarlo, o la suma total de la capa bajaría en cada paso de entrenamiento y la capa siguiente se encontraría «datos más pequeños» de lo que verá en predicción. Keras las reescala por \( 1/(1-p) \). Con \( p = 0{,}3 \): \( 1/0{,}7 = 1{,}4286 \). Es el «Dropout invertido». El fragmento 12 lo muestra: con diez unidades que valen 1, en training=True salen 8 valores de 1,429 y 2 ceros (suma 11,43), y en training=False los diez unos sin cambiar. Con 100.000 unidades se apaga el 30,0 % y la media de salida sigue siendo 0,999 (≈ 1).

12 · Sigmoide, entropía cruzada binaria y Dropout con números

Para qué sirve Comprobar con código las cuentas a mano de la cabeza del clasificador: la sigmoide (0,12 / 0,50 / 0,73 / 0,88), la pérdida binary_crossentropy (0,128 y 2,120) y el comportamiento de Dropout(0.3) en entrenamiento y en predicción. Independiente de los demás.

import numpy as np
import keras

# Sigmoide: cualquier número z se convierte en una probabilidad
z = np.array([-2.0, 0.0, 1.0, 2.0])
p = 1 / (1 + np.exp(-z))
print("z        :", z)
print("sigmoide :", p.round(2))

# Binary crossentropy: -[ y·log(p) + (1-y)·log(1-p) ]
def bce(y, p):
    return -(y * np.log(p) + (1 - y) * np.log(1 - p))

print("y=1, p=0.88 -> a mano %.3f | Keras %.3f" % (bce(1, 0.88), float(keras.losses.binary_crossentropy([1.0], [0.88]))))
print("y=1, p=0.12 -> a mano %.3f" % bce(1, 0.12))
print("y=0, p=0.12 -> a mano %.3f" % bce(0, 0.12))

# Dropout(0.3): en entrenamiento apaga ~30 % al azar y reescala; en inferencia no hace nada
capa = keras.layers.Dropout(0.3, seed=1)
x = np.ones((1, 10), dtype="float32")
print("training=True :", np.array(capa(x, training=True))[0].round(3))
print("training=False:", np.array(capa(x, training=False))[0])
grande = np.array(capa(np.ones((1, 100000), dtype="float32"), training=True))
print("con 100000 unidades: apagadas %.3f, media de la salida %.3f" % (np.mean(grande == 0), grande.mean()))

15 · El import que falla, el aumento de datos y preprocess_input

Para qué sirve Ver con código cuatro cosas: (1) el ImportError de Keras 3, (2) el aumento de datos con ImageDataGenerator, (3) la alternativa moderna image_dataset_from_directory con capas de aumento y (4) la diferencia entre rescale y preprocess_input de VGG16. Necesita las carpetas del fragmento 13.

import numpy as np
import keras

# 1) El import de los tutoriales antiguos ya no existe en Keras 3
try:
    from keras.preprocessing.image import ImageDataGenerator
except ImportError as error:
    print("ImportError:", str(error).split(" (")[0])

# 2) Lo que sí funciona: la versión heredada, con aumento de datos
from tensorflow.keras.preprocessing.image import ImageDataGenerator
aumento = ImageDataGenerator(rescale=1./255, rotation_range=20, width_shift_range=0.1,
                             horizontal_flip=True, brightness_range=(0.8, 1.2))

def primera_imagen():
    flujo = aumento.flow_from_directory("aviones_sinteticos/train", target_size=(64, 64), batch_size=4,
                                        class_mode="binary", shuffle=False, interpolation="bilinear")
    return next(flujo)[0][0]

pasada1, pasada2 = primera_imagen(), primera_imagen()
print("la imagen 0, en dos pasadas distintas, ¿es igual?", np.allclose(pasada1, pasada2))

# 3) La alternativa moderna: image_dataset_from_directory + capas de aumento
dataset = keras.utils.image_dataset_from_directory(
    "aviones_sinteticos/train", image_size=(64, 64), batch_size=32, label_mode="binary", seed=42)
print("class_names:", dataset.class_names)
capas_aumento = keras.Sequential([keras.layers.Rescaling(1./255), keras.layers.RandomFlip("horizontal"),
                                  keras.layers.RandomRotation(0.05)])
for lote, etiquetas in dataset.take(1):
    aumentado = capas_aumento(lote, training=True).numpy()
    print("lote:", lote.shape, etiquetas.shape, "| tras Rescaling+aumento: %.2f a %.2f" % (aumentado.min(), aumentado.max()))

# 4) Preprocesado propio de VGG16 frente a rescale
from keras.applications.vgg16 import preprocess_input
pixel = np.array([[[[255., 128., 0.]]]])             # un píxel RGB
print("rescale 1/255         :", (pixel / 255).ravel().round(3))
print("vgg16.preprocess_input:", preprocess_input(pixel.copy()).ravel().round(3))
