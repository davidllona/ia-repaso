El autoencoder convolucional de las notas, capa a capa

Hasta ahora usamos capas Dense. Pero son imágenes: ¿no era mejor usar las convoluciones del módulo anterior? ¿Y cómo se «agranda» una imagen para reconstruirla, si MaxPooling2D solo sabe achicar?

Los datos: rectángulos sintéticos

Las notas generan sus propias imágenes con create_rectangle_images(number_samples=500, image_size=28): 500 imágenes negras de 28×28 con un rectángulo blanco en posición y tamaño aleatorios (imagínalas como 500 carátulas de juguete: fondo negro y un único recuadro blanco). Paso a paso:

  1. np.zeros((500, 28, 28, 1), dtype="float32") crea 500 imágenes negras: 500 es el lote, 28×28 el tamaño y el último 1 el canal (gris). float32 es el tipo con el que trabaja Keras.
  2. Para cada imagen, x1, y1 = np.random.randint(2, 14, size=2) sortea la esquina superior izquierda del rectángulo (un entero entre 2 y 13, incluidos) y x2, y2 = np.random.randint(14, 26, size=2) la inferior derecha (entre 14 y 25).
  3. images[i, y1:y2, x1:x2, 0] = 1 pinta de blanco las filas de y1 a y2-1 y las columnas de x1 a x2-1. (En NumPy, a:b excluye el b; y el orden es filas primero, por eso y va antes que x.)

Con np.random.seed(42), la imagen 0 tiene el rectángulo en las filas 5 a 20 y las columnas 8 a 23: 16×16 = 256 de los 784 píxeles encendidos (fragmento 1, que dibuja la imagen en texto). Lado mínimo: 14 − 13 = 1 píxel, máximo 25 − 2 = 23.

La arquitectura

El encoder alterna convolución (que detecta patrones) con MaxPooling2D (que reduce a la mitad el alto y el ancho). El decoder hace lo contrario: convoluciones y UpSampling2D, que duplica el alto y el ancho. La última capa es una convolución de 1 filtro con sigmoide, que deja cada píxel entre 0 y 1, igual que la imagen original.

Esas cifras salen idénticas del summary() real del fragmento 3. Observa que el modelo entero tiene solo 3.217 parámetros: las convoluciones comparten pesos (módulo 3), así que un autoencoder convolucional es mucho más pequeño que el denso de 209.968 de antes.

Ojo: el cuello de botella 7×7×8 son 392 números, no 8

El «cuello» aquí no es un vector corto: es un mapa de 7×7×8 = 392 valores. La compresión es de 784 / 392 = 2 veces, mucho menos agresiva que el 24,5 del ejemplo denso. En un autoencoder convolucional la compresión es «espacial» (se conserva la forma de la imagen en pequeño) y se regula con el número de filtros y de pooling. Además, la ReLU deja muchos ceros: en el fragmento 5, un 30 % de esos 392 valores vale exactamente 0.

MaxPooling2D baja, UpSampling2D sube (pero no devuelve el detalle)

MaxPooling2D(2) toma bloques de 2×2 y se queda con el máximo: 4 valores pasan a 1. UpSampling2D(2) hace el proceso opuesto en tamaño: repite cada valor en un bloque de 2×2, sin inventar nada. No puede recuperar los tres valores que el pooling tiró; por eso, después de agrandar, hace falta una convolución que suavice y «rellene» con lo aprendido.

Ejemplo numérico: subir un bloque

Bloque 2×2 original \( \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} \). Max pooling → \( 1 \). UpSampling → \( \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix} \). Se recuperó el tamaño pero no el detalle: ahora hay tres 1 donde antes había dos 0 y un 1 en otra posición. Si en cambio el bloque original ya era uniforme (todo 1), la reconstrucción es exacta. Es lo que ocurre al agrandar una miniatura de Netflix: recuperas el tamaño, pero la imagen sale más «a cuadritos» que la original.

¿Qué hace padding="same" aquí?

En todas las convoluciones (y en los MaxPooling2D de las notas) aparece padding="same". Con same, Keras añade ceros alrededor para que, con stride 1, la convolución conserve el alto y el ancho; y en el pooling, para que un tamaño impar no pierda la última fila. Es lo que mantiene las cuentas limpias: 28 → 14 → 7 al bajar y 7 → 14 → 28 al subir. Con padding="valid" cada convolución 3×3 pierde 2 píxeles y las cuentas dejan de cuadrar con el tamaño original.

3 · El autoencoder convolucional (arquitectura de las notas)

Para qué sirve Construir el autoencoder de las notas con la API funcional de Keras: encoder de dos bloques Conv+MaxPool, cuello de botella «bottleneck» de 7×7×8 y decoder con UpSampling, y comprobar formas y parámetros con summary().

import keras
from keras import layers

keras.utils.set_random_seed(42)      # pesos iniciales reproducibles

inputs = keras.Input(shape=(28, 28, 1))

# Encoder: comprime
x = layers.Conv2D(16, 3, activation="relu", padding="same")(inputs)
x = layers.MaxPooling2D(2, padding="same")(x)
x = layers.Conv2D(8, 3, activation="relu", padding="same")(x)
bottleneck = layers.MaxPooling2D(2, padding="same", name="bottleneck")(x)

# Decoder: reconstruye
x = layers.Conv2D(8, 3, activation="relu", padding="same")(bottleneck)
x = layers.UpSampling2D(2)(x)
x = layers.Conv2D(16, 3, activation="relu", padding="same")(x)
x = layers.UpSampling2D(2)(x)
outputs = layers.Conv2D(1, 3, activation="sigmoid", padding="same")(x)

autoencoder = keras.Model(inputs, outputs)
autoencoder.summary()

11 · La función transfer_learning_demo de las notas

Para qué sirve Ejecutar la estructura de transfer_learning_demo de las notas: base congelada, modelo con preprocess_input y GlobalAveragePooling2D, y fine-tuning de las últimas cuatro capas con Adam(1e-5). Con weights=None (sin internet); con weights="imagenet" tendría el conocimiento de ImageNet. Es independiente de los fragmentos anteriores.

import numpy as np
import keras
from keras import layers
from keras.applications import VGG16
from keras.applications.vgg16 import preprocess_input
from keras.optimizers import Adam

def contar(modelo):
    entrenables = sum(int(np.prod(w.shape)) for w in modelo.trainable_weights)
    congelados = sum(int(np.prod(w.shape)) for w in modelo.non_trainable_weights)
    return entrenables, congelados

def transfer_learning_demo(weights=None):
    keras.utils.set_random_seed(42)
    base_model = VGG16(weights=weights, include_top=False, input_shape=(224, 224, 3))
    base_model.trainable = False

    imagenes = np.random.default_rng(0).uniform(0, 255, size=(2, 224, 224, 3)).astype("float32")
    features = base_model.predict(preprocess_input(imagenes.copy()), verbose=0)
    print("feature maps de 2 imágenes:", features.shape)

    entrada = keras.Input(shape=(224, 224, 3))
    x = preprocess_input(entrada)
    x = base_model(x, training=False)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dense(256, activation="relu")(x)
    salida = layers.Dense(1, activation="sigmoid")(x)
    model = keras.Model(entrada, salida)
    model.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
    print("transfer learning  (entrenables, congelados):", contar(model))

    base_model.trainable = True
    for layer in base_model.layers[:-4]:
        layer.trainable = False
    model.compile(optimizer=Adam(1e-5), loss="binary_crossentropy", metrics=["accuracy"])
    print("fine-tuning        (entrenables, congelados):", contar(model))
    print("capas de la base entrenables:", [l.name for l in base_model.layers if l.trainable])
    return model

modelo_demo = transfer_learning_demo(weights=None)
