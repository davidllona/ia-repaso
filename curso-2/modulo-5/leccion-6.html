Compilar y entrenar: compile, fit y el error a mano

¿Cómo se le dice a Keras «aprende a quitar ruido»? ¿Y cómo sabemos que de verdad ha aprendido, sin fiarnos solo de lo que imprime?

  1. autoencoder.compile(optimizer="adam", loss="mean_squared_error"). compile no entrena nada: define cómo medir el error (MSE, que compara cada píxel de la salida con el de la imagen limpia) y cómo corregir los pesos (Adam, el optimizador del módulo anterior).
  2. autoencoder.fit(noisy, clean, epochs=8, batch_size=32, validation_split=0.2). Entrada: las imágenes ruidosas; objetivo: las limpias. epochs=8 son 8 pasadas completas. batch_size=32 actualiza los pesos cada 32 imágenes. validation_split=0.2 aparta el último 20 % (las imágenes 400 a 499) y no entrena con ellas: sirven para medir cómo funciona con imágenes que la red no ha visto.
  3. reconstructed = autoencoder.predict(noisy[:1]). Pasa la primera imagen ruidosa por la red y devuelve la imagen reconstruida (forma (1, 28, 28, 1)).
  4. Error a mano: np.mean((reconstructed[0] - clean[0]) ** 2). Resta pixel a pixel, eleva al cuadrado y hace la media: eso es el MSE que Keras calcula por dentro.
Ejemplo numérico: el MSE de una imagen minúscula

Carátula limpia de 4 píxeles \( (0,\ 0,\ 1,\ 1) \) y reconstrucción \( (0{,}1,\ 0,\ 0{,}8,\ 1) \). Diferencias: \( (0{,}1,\ 0,\ -0{,}2,\ 0) \). Al cuadrado: \( (0{,}01,\ 0,\ 0{,}04,\ 0) \). Media: \( 0{,}05/4 = \) 0,0125. El MSE de las 784 posiciones se calcula igual.

Separar el encoder y el decoder

Si ya entrenamos el modelo entero, ¿se pueden usar las dos mitades por separado? ¿Para qué querríamos solo el código comprimido?

Sí. Un autoencoder entrenado son dos redes en una, y Keras permite sacarlas. Como a la capa del cuello de botella le pusimos name="bottleneck", podemos pedirla por nombre:

  • Encoder: keras.Model(inputs, autoencoder.get_layer("bottleneck").output). Entrada: imagen; salida: el código (7, 7, 8). Sirve para comprimir, para visualizar, para hacer clustering o para alimentar otro modelo con una versión más corta de los datos.
  • Decoder: las capas posteriores al cuello, encadenadas desde una entrada nueva keras.Input(shape=(7, 7, 8)). Sirve para reconstruir a partir de un código (y, con ideas más avanzadas, para generar imágenes nuevas).

4 · Compilar, entrenar y medir el error a mano

Para qué sirve Entrenar el autoencoder para quitar ruido (fit(noisy, clean)), medir el error de una imagen a mano como en las notas y comprobar con las imágenes de validación que la red de verdad limpia. Continúa los fragmentos 1-3.

autoencoder.compile(optimizer="adam", loss="mean_squared_error")

history = autoencoder.fit(
    noisy, clean,
    epochs=8, batch_size=32, validation_split=0.2, verbose=0,
)
print("loss (train):", np.round(history.history["loss"], 4))
print("loss (val)  :", np.round(history.history["val_loss"], 4))

reconstructed = autoencoder.predict(noisy[:1], verbose=0)
print("MSE manual, imagen 0:", np.mean((reconstructed[0] - clean[0]) ** 2).round(4))

val_noisy, val_clean = noisy[400:], clean[400:]       # el 20 % que fit no usó para entrenar
val_rec = autoencoder.predict(val_noisy, verbose=0)
print("validación, imagen ruidosa  -> limpia: %.4f" % np.mean((val_noisy - val_clean) ** 2))
print("validación, imagen limpiada -> limpia: %.4f" % np.mean((val_rec - val_clean) ** 2))

# 8 épocas es poco: seguimos entrenando 40 más
history2 = autoencoder.fit(noisy, clean, epochs=40, batch_size=32, validation_split=0.2, verbose=0)
val_rec = autoencoder.predict(val_noisy, verbose=0)
print("tras 48 épocas, val_loss =", round(history2.history["val_loss"][-1], 4))
print("validación, imagen limpiada -> limpia: %.4f" % np.mean((val_rec - val_clean) ** 2))

5 · Separar el encoder y el decoder

Para qué sirve Sacar del autoencoder entrenado el encoder (imagen → código) y el decoder (código → imagen) y comprobar que juntos hacen lo mismo que el modelo completo. Continúa los fragmentos 1-4.

encoder = keras.Model(inputs, autoencoder.get_layer("bottleneck").output)
codigo = encoder.predict(noisy[:5], verbose=0)
print("código de 5 imágenes:", codigo.shape, "-> valores por imagen:", codigo[0].size, "(antes 784)")
print("compresión: %.1f veces" % (784 / codigo[0].size))
print("valores del código que son exactamente 0: %.0f %%" % (100 * np.mean(codigo == 0)), "| máximo: %.2f" % codigo.max())

# Decoder: las capas que van después del cuello de botella
entrada_codigo = keras.Input(shape=(7, 7, 8))
y = entrada_codigo
for capa in autoencoder.layers[autoencoder.layers.index(autoencoder.get_layer("bottleneck")) + 1:]:
    y = capa(y)
decoder = keras.Model(entrada_codigo, y)

via_dos_pasos = decoder.predict(codigo, verbose=0)
directo = autoencoder.predict(noisy[:5], verbose=0)
print("decoder(encoder(x)) == autoencoder(x):", np.allclose(via_dos_pasos, directo, atol=1e-5))
