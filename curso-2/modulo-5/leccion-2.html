Para quitar ruido basta con cambiar el objetivo: entra la imagen sucia y se pide la limpia

Si el cuello de botella solo guarda lo que se repite, el grano de una carátula fotografiada con el móvil se queda fuera. Basta con pedirle a la red la imagen limpia.

Índice del módulo

Fotografías la carátula de Matrix con el móvil y sale con grano. El grano es distinto en cada foto; el recuadro del título es igual en todas. ¿Cuál de los dos cabe mejor en un cuello de botella estrecho?

El recuadro del título. El cuello guarda la estructura que se repite en todas las imágenes; el ruido no sigue ninguna regla, así que no cabe y se queda fuera. Esa «pérdida» es justo lo que queremos.

Un solo cambio en el entrenamiento

El denoising autoencoder (autoencoder para quitar ruido) es el mismo de la lección 1 con un único cambio: la entrada es la imagen con ruido y el objetivo es la limpia.

  • Imagen limpiaes el objetivo
  • + ruido«nieve» de TV, a mano
  • Imagen ruidosaes la entrada
  • Autoencodercomprime y reconstruye
  • Salidase compara con la limpia

El ruido se fabrica así: a cada píxel se le suma un número sorteado de una normal (la campana de Gauss) con media 0 y desviación típica 0,25, y después np.clip recorta el resultado a [0, 1], porque un píxel no puede valer menos de 0 ni más de 1.

Regla fácil

Autoencoder normal: fit(X, X). Quitar ruido: fit(X_ruidoso, X_limpio).

En B y C el clip deshace el ruido. Por eso el fondo negro deja de valer 0 de media: el ruido negativo se recorta y el positivo se queda. La media sube a \( 0{,}25/\sqrt{2\pi} \approx \) 0,0997, y el error de la imagen ruidosa es \( 0{,}25^2/2 = \) 0,03125. Con 500 imágenes reales sale 0,100 y 0,0312.

Entrenaste el denoiser con ruido gaussiano de 0,25. Ahora le das una carátula con un rayón o una mancha de café. ¿La limpia?

Probablemente no. Un denoiser es específico del ruido que vio: no sabe quitar manchas, rayones ni ruido de otra intensidad. Y funciona porque todas las imágenes comparten estructura; con carátulas reales habría que entrenarlo con carátulas reales.

En tres líneas

  • Denoising = la misma red, con entrada ruidosa y objetivo limpio.
  • El ruido no se repite entre imágenes, así que no cabe en el cuello y se queda fuera.
  • Ruido = normal(0; 0,25) + np.clip; solo sabe quitar el tipo de ruido con el que se entrenó.

Autoencoder con ruido: quitar el ruido de las imágenes

Si un autoencoder solo puede conservar lo «importante», ¿qué pasa con lo que no es importante, como el grano de una carátula fotografiada con el móvil o una película con la señal de TV llena de interferencias? ¿Se puede usar esa pérdida a nuestro favor?

Sí, y es una de las aplicaciones más famosas: el denoising autoencoder (autoencoder para quitar ruido). El truco consiste en cambiar una sola cosa del entrenamiento: la entrada es la imagen con ruido y el objetivo es la imagen limpia.

  • Imagen limpiaes el objetivo
  • + ruido«nieve» de TV, a mano
  • Imagen ruidosaes la entrada
  • Autoencodercomprime y reconstruye
  • Salidase compara con la limpia

Como el cuello de botella no puede guardar cada píxel, solo conserva la estructura que se repite en todas las imágenes (aquí: «hay un rectángulo»). El ruido es distinto en cada imagen, no sigue ninguna regla, así que no cabe en el pasillo: se queda fuera. Y como el objetivo es la imagen limpia, la red aprende a producirla.

Cómo se fabrica el ruido, paso a paso

Partimos de las imágenes limpias clean (valores 0 y 1). Se crea una matriz de ruido noise con la misma forma, donde cada número se sortea de una distribución normal (la campana de Gauss) con media 0 y desviación típica 0,25. Se suman y, como una imagen no puede valer menos de 0 ni más de 1, se «recorta» con np.clip:

\[ \text{noisy} = \operatorname{clip}\big(\text{clean} + \text{noise},\ 0,\ 1\big) \qquad \text{noise} \sim \mathcal{N}(0,\ 0{,}25^2) \]
  • Media 0 (loc=0): el ruido suma tanto como resta; la mitad de los valores son positivos y la otra mitad negativos.
  • Desviación típica 0,25 (scale=0.25): un valor típico de ruido ronda ±0,25. Muy pocos pasan de ±0,5 (el 95 % queda entre −0,5 y +0,5).
  • size=clean.shape: un número de ruido distinto para cada píxel de cada imagen.
Ejemplo numérico: tres píxeles de un póster, con valores elegidos para el ejemplo
PíxelLimpioRuidoSumaTras clipError² (con el limpio)
A (fondo oscuro)0+0,100,100,100,0100
B (fondo oscuro)0−0,20−0,2000
C (recuadro del título)1+0,301,3010

El clip deshace en B y en C parte del ruido: el fondo nunca baja de 0 y el blanco nunca sube de 1. Consecuencia: los píxeles negros dejan de valer 0 en promedio. Cuando el ruido es positivo (la mitad de las veces) sube; cuando es negativo, el clip lo deja en 0. El promedio es \( 0{,}25/\sqrt{2\pi} \approx \) 0,0997. Y el error cuadrático medio de la imagen ruidosa es \( 0{,}25^2/2 = \) 0,03125 (la mitad del ruido al cuadrado desaparece con el clip). Con las 500 imágenes del fragmento 2 sale 0,100 y 0,0312: coincide.

Guía completa del experimento «Quitar ruido: lo que entra, lo que sale»

El experimento está más arriba, en la lección. Estas son sus instrucciones completas.

Haz esto: Espera a que termine el entrenamiento (120 épocas, unos segundos). Mira las filas «pósters con ruido» y «salida del autoencoder» (la fila de arriba es el póster limpio que queremos recuperar). Sube el slider del ruido de prueba hasta 0,60 (más del que vio al entrenar) y luego bájalo a 0. Después pulsa «entrada limpia → objetivo limpio» y compara el número «veces menos».

Fíjate en: Entrenado con ruido σ = 0,25, el autoencoder reduce el error unas 7 veces con σ = 0,25 (0,031 → 0,004). Con σ = 0,60 todavía mejora (≈ 2,6 veces) pero la imagen sale peor: nunca vio un ruido tan fuerte. Con σ = 0 (imagen sin ruido) «no mejora»: ya no hay nada que quitar y la reconstrucción añade su pequeño error propio. Y fíjate en el último experimento: incluso entrenado sin ruido, el autoencoder quita algo (≈ 3 veces), porque el cuello de botella ya filtra lo que no es estructura; pero entrenarlo con ruido lo hace claramente mejor.

Regla fácil

Autoencoder normal: fit(X, X). Autoencoder para quitar ruido: fit(X_ruidoso, X_limpio). Lo único que cambia es el objetivo.

Ojo: un denoiser es específico del ruido que vio

Un autoencoder entrenado con ruido gaussiano de 0,25 no sabe quitar manchas, rayones ni ruido de otra intensidad. Y lo que hace bien lo hace porque todas las imágenes comparten estructura (rectángulos). Con carátulas reales de películas tendrías que entrenarlo con carátulas reales.

Código

2 · Fabricar el ruido: normal, suma y clip

Para qué sirve Convertir las imágenes limpias en imágenes ruidosas (el input del autoencoder para quitar ruido) y medir exactamente cuánto ruido se ha añadido y qué hace el clip. Continúa el fragmento 1 (usa clean).

noise = np.random.normal(0, 0.25, size=clean.shape)
noisy = np.clip(clean + noise, 0, 1).astype("float32")

print("ruido: media %.3f, desviación %.3f" % (noise.mean(), noise.std()))
print("noisy: mínimo %.2f, máximo %.2f" % (noisy.min(), noisy.max()))
print("error de la imagen ruidosa (MSE): %.4f" % np.mean((noisy - clean) ** 2))
print("media de los píxeles negros:  %.3f (antes 0.000)" % noisy[clean == 0].mean())
print("media de los píxeles blancos: %.3f (antes 1.000)" % noisy[clean == 1].mean())
print("negros que el clip dejó en 0 exacto: %.1f %%" % (100 * np.mean(noisy[clean == 0] == 0)))
print("primeros 6 píxeles de la fila 0, imagen 0:", noisy[0, 0, :6, 0].round(2))
