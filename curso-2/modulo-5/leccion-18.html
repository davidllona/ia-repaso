La accuracy dice «90 %», pero ¿en qué se equivoca el 10 %? ¿Se confunden las grietas con abolladuras o al revés?

La tarea 7 llama a test_model_on_image(test_generator, model, index_to_plot=1), una función auxiliar del cuaderno: toma una imagen del conjunto de test, la muestra, la predice y compara con la etiqueta real. Una predicción puede fallar: pocos datos, ambigüedad, otra iluminación u otro ángulo… En el fragmento 17 hay una versión propia de esa función (el original lo da el laboratorio): la imagen 1 es una crack predicha como crack (probabilidad de dent 0,001), la 45 es una dent predicha como dent (0,940), y la 7 es una grieta pequeña y fina que el modelo toma por abolladura (0,659).

La matriz de confusión

Para ver qué errores comete, se cuenta cada combinación real/predicho. Llamamos «positiva» a dent:

Matriz de confusión del fragmento 16 (60 imágenes de test)
Predicho crackPredicho dent
Real crack (30)24 (verdaderos negativos)6 (falsos positivos)
Real dent (30)0 (falsos negativos)30 (verdaderos positivos)
  • Accuracy \( = (24+30)/60 = 0{,}90 \).
  • Precisión de «dent» \( = 30/(30+6) = 0{,}833 \): cuando dice «dent», acierta el 83,3 %.
  • Recall de «dent» \( = 30/(30+0) = 1{,}00 \): no se le escapa ninguna abolladura.
  • Con Netflix: la precisión sería «de las películas que te recomiendo, ¿cuántas te gustan?» y el recall, «de todas las que te habrían gustado, ¿cuántas te llegué a recomendar?».
  • El error es asimétrico: el modelo confunde grietas por abolladuras (6 veces) pero nunca al revés. En mantenimiento aeronáutico, que una grieta pase por abolladura no es un error cualquiera, y la accuracy sola lo esconde.

16 · El proyecto en miniatura: entrenar, ver el historial y la matriz de confusión

Para qué sirve Reproducir las tareas 4 a 6 del proyecto (compilar, entrenar, leer history) y la evaluación en test con una matriz de confusión, usando el dataset sintético y una CNN pequeña de 64×64 en lugar de VGG16 para que corra en segundos. La estructura es la del proyecto (misma cabeza Dense 512 → Dropout 0.3 → Dense 512 → Dropout 0.3 → Dense 1). Necesita las carpetas del fragmento 13.

import numpy as np
import random
import tensorflow as tf
import keras
from keras import layers
from keras.optimizers import Adam
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from sklearn.metrics import confusion_matrix

seed_value = 42
random.seed(seed_value); np.random.seed(seed_value); tf.random.set_seed(seed_value)
batch_size, n_epochs = 32, 10
img_rows, img_cols = 64, 64                    # 64 en vez de 224 para que corra en segundos

def generador(carpeta, mezclar):
    return ImageDataGenerator(rescale=1./255).flow_from_directory(
        "aviones_sinteticos/" + carpeta, target_size=(img_rows, img_cols), batch_size=batch_size,
        class_mode="binary", shuffle=mezclar, seed=seed_value, interpolation="bilinear")

train_generator = generador("train", True)
valid_generator = generador("valid", False)
test_generator = generador("test", False)

# Una base convolucional pequeña (sin pesos ImageNet) en lugar de VGG16
base_model = keras.Sequential([
    keras.Input(shape=(img_rows, img_cols, 3)),
    layers.Conv2D(16, 3, activation="relu"), layers.MaxPooling2D(2),
    layers.Conv2D(32, 3, activation="relu"), layers.MaxPooling2D(2),
    layers.Conv2D(32, 3, activation="relu"), layers.MaxPooling2D(2),
    layers.Flatten(),
])
model = keras.Sequential([base_model,
    layers.Dense(512, activation="relu"), layers.Dropout(0.3),
    layers.Dense(512, activation="relu"), layers.Dropout(0.3),
    layers.Dense(1, activation="sigmoid")])
model.compile(optimizer=Adam(learning_rate=0.001), loss="binary_crossentropy", metrics=["accuracy"])

history = model.fit(train_generator, epochs=n_epochs, validation_data=valid_generator, verbose=0)
train_history = model.history.history
print("claves de history:", list(train_history.keys()))
for e in (0, 4, 9):
    print("época %2d: loss %.3f acc %.3f | val_loss %.3f val_acc %.3f" % (
        e + 1, train_history["loss"][e], train_history["accuracy"][e],
        train_history["val_loss"][e], train_history["val_accuracy"][e]))

prob = model.predict(test_generator, verbose=0).ravel()
pred = (prob > 0.5).astype(int)
real = test_generator.classes
print("test accuracy: %.3f" % np.mean(pred == real))
print("matriz de confusión (filas = real crack/dent, columnas = predicho):")
print(confusion_matrix(real, pred))
print("primeras 4 imágenes de test:", np.round(prob[:4], 3), "reales:", real[:4])
