11 · Errores típicos de forma y de tipo de dato, reproducidos

Para qué sirve Provocar a propósito los errores más frecuentes con imágenes: falta el eje de canales, el canal en el sitio equivocado (channels_first frente a channels_last) y píxeles sin normalizar, y ver los mensajes reales de Keras para reconocerlos cuando te salgan.

import numpy as np
import keras
from keras import layers

def nuevo_modelo():
    return keras.Sequential([
        keras.Input(shape=(8, 8, 1)),
        layers.Conv2D(4, 3, activation="relu"),
        layers.Flatten(),
        layers.Dense(10, activation="softmax"),
    ])

def resumen_error(error):
    texto = str(error).split("incompatible with the layer:")[-1]     # nos quedamos con la parte útil
    return texto.split("\x1b")[0].strip().splitlines()[0]            # quitamos los códigos de color

print("Formato de imagen por defecto:", keras.config.image_data_format())

rng = np.random.default_rng(0)
fotos = rng.integers(0, 256, size=(5, 8, 8), dtype=np.uint8)    # 5 imágenes de 8x8, sin canal, enteros 0-255
print("dtype:", fotos.dtype, "| rango:", fotos.min(), "-", fotos.max())

print("200 + 100 en uint8:", np.array([200], dtype=np.uint8) + 100)   # ¡se desborda!

fotos = fotos.astype("float32") / 255.0                           # normalizar a 0-1
print("dtype:", fotos.dtype, "| rango: %.2f - %.2f" % (fotos.min(), fotos.max()))

casos = (("capa suelta, forma (5, 8, 8)", None, fotos),
         ("modelo con Input, (5, 8, 8)", nuevo_modelo(), fotos),
         ("modelo con Input, (5, 1, 8, 8)", nuevo_modelo(), fotos.reshape(5, 1, 8, 8)),
         ("modelo con Input, (5, 8, 8, 1)", nuevo_modelo(), fotos.reshape(5, 8, 8, 1)))

for descripcion, modelo, datos in casos:
    try:
        if modelo is None:
            salida = layers.Conv2D(4, 3)(datos)
        else:
            salida = modelo.predict(datos, verbose=0)
        print(f"{descripcion:32s} -> OK, salida {tuple(salida.shape)}")
    except Exception as error:
        print(f"{descripcion:32s} -> {type(error).__name__}: {resumen_error(error)}")

Lee las cuatro líneas. 1) Una capa Conv2D suelta con (5, 8, 8) falla: expected min_ndim=4, found ndim=3; la forma (5, 8, 8) tiene 3 dimensiones y una Conv2D necesita 4 ((lote, alto, ancho, canales)). 2) Sorprendentemente el modelo con Input sí acepta (5, 8, 8) y devuelve (5, 10): Keras 3 añade el canal que falta. Funciona, pero no te acostumbres: es mejor hacerlo tú con reshape(-1, 8, 8, 1). 3) Con el canal delante, (5, 1, 8, 8), falla con «expected axis -1 … value 1, but received … (5, 1, 8, 8)»: el último eje vale 8 y la capa esperaba 1. Es el error clásico de channels_first. 4) Con (5, 8, 8, 1) todo bien. Además, la línea de uint8 muestra que \(200+100\) da 44: normaliza siempre con .astype("float32") / 255.0 antes de operar.
