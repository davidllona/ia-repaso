La sintaxis de Python que vas a ver

Variable y el signo =
Un nombre que guarda un valor. f = 3 se lee «guarda 3 con el nombre f». Dos signos, ==, preguntan «¿es igual?».
print
Escribe algo en pantalla. Todo lo que ves en «Salida» sale de un print (o de summary).
import … as …
import trae una librería; as le pone un apodo. import numpy as np: «trae NumPy y llámala np».
from … import …
Trae solo una pieza de una librería. from keras import layers: «de Keras, trae el cajón de capas».
Punto y paréntesis
cosa.accion(dato): «a esta cosa, hazle esta acción con este dato». modelo.fit(X, y): «modelo, entrena con X e y».
Argumento con nombre
Un dato que se pasa diciendo qué es. epochs=40: «el número de épocas es 40». Si no lo pones, se usa el valor por defecto.
Lista [ ] y tupla ( )
Varios valores en orden. La lista va entre corchetes y se puede cambiar; la tupla, entre paréntesis, es fija. (16, 16, 1) es una tupla.
Diccionario { }
Parejas «nombre → valor» entre llaves. historia.history es uno: «loss» → lista de pérdidas.
Comentario # y docstring
Lo que va detrás de # es una nota para humanos. Un texto entre tres comillas """…""" justo debajo de un def explica qué hace la función. Python ignora los dos.
Sangría
Los espacios al principio de una línea. Dicen qué líneas van dentro de un def, un for o un if.
def y return
def escribe una receta con nombre (una función); return dice qué devuelve. No hace nada hasta que la llamas: hacer_formas(900, 1, 3.0).
for … in …
Un bucle: repite las líneas sangradas una vez por cada elemento. for k in range(n): da n vueltas. Si en cada vuelta salen dos cosas, se reparten en dos nombres: for p, real in ….
range y zip
range(14) cuenta de 0 a 13 (el último no entra). zip(a, b) recorre dos listas a la vez, en parejas.
if, elif y else
«Si…», «si no, si…» y «si no…». Solo se hacen las líneas del caso que se cumple. En una línea: "#" if v > 0.5 else ".".
f-string y %
Un texto con f delante: lo que va entre llaves se cambia por su valor. {x:.3f}: 3 decimales; {x:6d}: entero en 6 huecos; {x:16s}: texto en 16 huecos. El estilo antiguo "%.3f" % x hace lo mismo.
Índices y cortes [ ]
Se cuenta desde 0. [0] el primero; [-1] el último; [:3] los tres primeros; [i:i + 3] del i al i + 2; [0, :, :, 0]: imagen 0, todas las filas, todas las columnas, canal 0.
Operaciones
* multiplica, // divide quedándose con la parte entera (63 // 2 = 31), < y > comparan, & es «y», | es «o» (en tablas de verdadero/falso).
True, False y None
Verdadero, falso y «nada». En una forma, None significa «las imágenes que sean».

Paso 1 · Una fábrica de iconos de 16×16 (fragmento 8, primera parte)

Para qué sirve Escribir una función que dibuja n iconos con ruido, fabricar 900 para entrenar y 600 para el examen, y comprobar su forma, su tipo y cuántos hay de cada clase. Al final, el primer icono se dibuja con almohadillas.

import numpy as np
import keras
from keras import layers

def hacer_formas(n, semilla, dispersion):
    """n imágenes 16x16: 0 = cuadrado, 1 = círculo, 2 = cruz (dibujadas con ruido)."""
    rng = np.random.default_rng(semilla)
    ys, xs = np.mgrid[0:16, 0:16]
    X = np.zeros((n, 16, 16), dtype="float32")
    y = rng.integers(0, 3, n)
    for k in range(n):
        cy, cx = 7.5 + rng.uniform(-dispersion, dispersion, 2)   # centro de la figura
        r = rng.uniform(3, 4.2)                                   # tamaño
        dy, dx = ys - cy, xs - cx
        if y[k] == 0:
            figura = np.abs(np.maximum(np.abs(dx), np.abs(dy)) - r) < 0.8
        elif y[k] == 1:
            figura = np.abs(np.hypot(dx, dy) - r) < 0.8
        else:
            figura = ((np.abs(dx) < 0.8) | (np.abs(dy) < 0.8)) & (np.maximum(np.abs(dx), np.abs(dy)) < r)
        X[k] = figura + rng.normal(0, 0.15, (16, 16))
    return np.clip(X, 0, 1).reshape(-1, 16, 16, 1), y

X_train, y_train = hacer_formas(900, 1, 3.0)
X_test, y_test = hacer_formas(600, 3, 3.0)
nombres = ["cuadrado", "círculo", "cruz"]

print("X_train:", X_train.shape, "| X_test:", X_test.shape)
print("Tipo:", X_train.dtype, "| rango:", X_train.min(), "-", X_train.max())
print("Iconos de cada clase en train:", np.bincount(y_train))
print("El primer icono es un", nombres[y_train[0]] + ":")
for fila in X_train[0, :, :, 0]:
    print("".join("#" if v > 0.5 else "." for v in fila))

Paso 2 · Dos bucles, una ventana y una suma

icono = X_train[0, :, :, 0]                  # el primer icono, sin el eje de canales: 16x16

mapa = np.zeros((16 - f + 1, 16 - f + 1))
for i in range(mapa.shape[0]):

def hacer_formas(n, semilla, dispersion):
    """n imágenes 16x16: 0 = cuadrado, 1 = círculo, 2 = cruz (dibujadas con ruido)."""
    rng = np.random.default_rng(semilla)
    ys, xs = np.mgrid[0:16, 0:16]
    X = np.zeros((n, 16, 16), dtype="float32")
    y = rng.integers(0, 3, n)
    for k in range(n):
        cy, cx = 7.5 + rng.uniform(-dispersion, dispersion, 2)   # centro de la figura
        r = rng.uniform(3, 4.2)                                   # tamaño
        dy, dx = ys - cy, xs - cx
        if y[k] == 0:
            figura = np.abs(np.maximum(np.abs(dx), np.abs(dy)) - r) < 0.8
        elif y[k] == 1:
            figura = np.abs(np.hypot(dx, dy) - r) < 0.8
        else:
            figura = ((np.abs(dx) < 0.8) | (np.abs(dy) < 0.8)) & (np.maximum(np.abs(dx), np.abs(dy)) < r)
        X[k] = figura + rng.normal(0, 0.15, (16, 16))
    return np.clip(X, 0, 1).reshape(-1, 16, 16, 1), y

import numpy as np
import keras
from keras import layers
from keras.utils import to_categorical

keras.utils.set_random_seed(42)

def create_rgb_dataset(number_samples=180, height=100, width=100):
    """Imágenes de ruido; cada una tiene un canal 'encendido': 0 = rojo, 1 = verde, 2 = azul."""
    X = np.random.uniform(0, 0.25, size=(number_samples, height, width, 3))   # ruido de fondo
    y = np.random.randint(0, 3, size=number_samples)                         # clase de cada imagen
    for i in range(number_samples):
        X[i, :, :, y[i]] += 0.65                                             # refuerza el canal de su clase
    X = np.clip(X, 0, 1).astype("float32")
    return X, to_categorical(y, num_classes=3)

np.random.seed(42)
X, y = create_rgb_dataset(number_samples=180, height=100, width=100)
print("X:", X.shape, "| y:", y.shape, "| rango:", X.min().round(2), "-", X.max().round(2))
print("Imágenes de cada clase (rojo, verde, azul):", y.sum(axis=0).astype(int))

model = keras.Sequential([
    keras.Input(shape=(100, 100, 3)),
    layers.Conv2D(16, (3, 3), strides=(1, 1), padding="valid"),
    layers.ReLU(),
    layers.MaxPooling2D(pool_size=(2, 2), strides=(2, 2)),
    layers.Conv2D(32, (3, 3), strides=(1, 1), padding="valid"),
    layers.ReLU(),
    layers.MaxPooling2D(pool_size=(2, 2), strides=(2, 2)),
    layers.Flatten(),
    layers.Dense(100, activation="relu"),
    layers.Dense(3, activation="softmax"),
])
model.compile(optimizer="adam", loss="categorical_crossentropy", metrics=["accuracy"])
model.summary()

model.fit(X, y, epochs=5, batch_size=16, validation_split=0.2, verbose=2)
