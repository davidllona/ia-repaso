Quiero…Fórmula o código
Formato de un lote de imágenes(N, C, H, W). Desde NumPy/PIL (H, W, C): x.permute(2, 0, 1) o ToTensor(); lote NHWC: permute(0, 3, 1, 2)
Parámetros de Conv2d\( C_{out}(C_{in}k_Hk_W/\text{groups}+1) \); pesos de forma \( (C_{out},C_{in}/\text{groups},k_H,k_W) \)
Tamaño de salida\( \lfloor (n+2p-d(k-1)-1)/s\rfloor+1 \). Mismo tamaño con stride 1: padding=(k-1)//2 (k impar) o padding='same'
Poolingnn.MaxPool2d(k): stride = k. ceil_mode=True conserva la última ventana. nn.AdaptiveAvgPool2d(1): media global
Aplanarnn.Flatten() (conserva el lote). in_features = C·H·W del tensor aplanado. nn.LazyLinear(n) lo deduce
Multiplicaciones de una convolución\( C_{out}H_{out}W_{out}k^2C_{in} \)
BatchNorm2d(C)2C parámetros; una media y varianza por canal sobre N·H·W valores; eval() usa las acumuladas; momentum 0,1
Lotes por época⌈N/B⌉ (o ⌊N/B⌋ con drop_last=True)
