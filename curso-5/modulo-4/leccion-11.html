Guardar y cargar: state_dict

¿Cómo guardo la red que he afinado y cómo la recupero mañana (o en otro ordenador)?

Un state_dict es un diccionario de Python que asocia el nombre de cada tensor del modelo con su valor: "conv1.weight", "bn1.running_mean", "fc.bias"… Contiene los parámetros y los buffers de BatchNorm. Es como guardar la libreta de apuntes del crítico: cada página tiene un título y sus notas, pero la libreta no incluye el puesto de trabajo. Se guarda y se carga así:

torch.save(modelo.state_dict(), "resnet18_fotos.pth")        # guardar

modelo = models.resnet18(weights=None)                        # misma arquitectura
modelo.fc = nn.Linear(512, 10)                                # misma cabeza que cuando guardaste
modelo.load_state_dict(torch.load("resnet18_fotos.pth", map_location="cpu"))
modelo.eval()

Para cargar, primero hay que reconstruir la arquitectura idéntica (incluida tu cabeza nueva), porque el archivo solo contiene los números y los nombres, no el plano. load_state_dict compara cada clave con las del modelo, y si no encajan (otro nombre, otra forma) da error.

El fragmento 10 hace el recorrido completo con una ResNet-18 real: 122 entradas (parámetros más buffers), un archivo de 44,7 MiB, una recarga que da salidas idénticas, el error size mismatch al cargar un checkpoint de 1.000 clases en una red de 10, la solución de cargar sin la cabeza, y por qué se prefiere guardar el state_dict en vez del modelo entero.

Ojo · versiones y seguridad

Desde PyTorch 2.6, torch.load usa weights_only=True por defecto: solo carga tensores y diccionarios, y rechaza objetos arbitrarios (por ejemplo, un modelo guardado entero con torch.save(modelo, ...)). Con weights_only=False se carga cualquier cosa, pero el formato de PyTorch usa pickle, que puede ejecutar código: no cargues archivos de desconocidos con weights_only=False. Otra trampa: si entrenaste con nn.DataParallel las claves empiezan por module. y hay que quitarlo al cargar en una red sin él.

10 · Guardar y cargar con state_dict: claves, tamaño, errores de forma y la cabeza que no encaja

Para qué sirve Guardar solo los pesos (state_dict) de una ResNet-18, recargarlos en otra red y comprobar que predice igual; ver qué guarda realmente (parámetros y estadísticas de BatchNorm); reproducir el error clásico al cargar un checkpoint de 1.000 clases en una red de 10, y cargar solo el cuerpo.

import os
import tempfile
import torch
from torch import nn
from torchvision import models

torch.manual_seed(0)
modelo = models.resnet18(weights=None)
sd = modelo.state_dict()
claves = list(sd)
print(len(sd), claves[:3], claves[-2:])
print([k for k in claves if k.startswith("bn1.")])

ruta = os.path.join(tempfile.mkdtemp(), "resnet18.pth")
torch.save(sd, ruta)
print(round(os.path.getsize(ruta) / 2**20, 1), "MiB")

otro = models.resnet18(weights=None)
print(otro.load_state_dict(torch.load(ruta, map_location="cpu")))
x = torch.randn(2, 3, 64, 64)
modelo.eval()
otro.eval()
print("mismas salidas:", torch.equal(modelo(x), otro(x)))

nuevo = models.resnet18(weights=None)
nuevo.fc = nn.Linear(512, 10)
try:
    nuevo.load_state_dict(torch.load(ruta))
except RuntimeError as e:
    lineas = str(e).splitlines()
    print(lineas[0])
    print(lineas[1].strip())

sin_fc = {k: v for k, v in sd.items() if not k.startswith("fc.")}
print(nuevo.load_state_dict(sin_fc, strict=False))

ruta2 = os.path.join(os.path.dirname(ruta), "entero.pth")
torch.save(modelo, ruta2)
try:
    torch.load(ruta2)
except Exception as e:
    print(type(e).__name__, str(e)[:55])
print(type(torch.load(ruta2, weights_only=False)).__name__)

ResNet

Un state_dict de ResNet-18 tiene 122 entradas: 62 tensores de parámetros más 60 buffers de BatchNorm (20 capas BatchNorm × running_mean, running_var y num_batches_tracked). Fíjate en las claves de bn1: además de weight y bias (lo que se aprende) guarda las estadísticas que se usan en eval(); por eso cargar solo "los pesos" no basta si se omiten. El archivo ocupa 44,7 MiB: los 11.689.512 parámetros a 4 bytes y los buffers de BatchNorm suman unos 44,6 MiB, y el resto es la cabecera del formato. La recarga funciona (<All keys matched successfully>) y las salidas son idénticas bit a bit. Al cargar el checkpoint de 1.000 clases en una red con fc de 10 sale el RuntimeError de size mismatch: dice qué tensor falla y las dos formas, [1000, 512] y [10, 512]. La solución es quitar las claves fc.* y cargar con strict=False, que devuelve qué faltaba (missing_keys=['fc.weight', 'fc.bias']: justo lo que se entrena después). Por último, un modelo guardado entero con torch.save(modelo, …) ya no se carga con el torch.load por defecto (weights_only=True desde PyTorch 2.6): hace falta weights_only=False, que ejecuta código arbitrario del archivo, así que solo se usa con archivos propios. Por eso se recomienda guardar el state_dict.
