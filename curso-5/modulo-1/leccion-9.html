Sigmoide, tanh, ReLU o LeakyReLU: qué cambia al entrenar

Sabemos que las derivadas son distintas. ¿Se nota de verdad al entrenar una red pequeña que predice si un usuario termina la serie? ¿Y qué es eso de que una neurona «se muere»?

La carrera, con números

El fragmento 11 entrena la misma red 2-8-1 con las cuatro activaciones sobre dos lunas (400 puntos, ruido 0.2), con SGD sin momentum, y promedia 5 semillas (cada activación usa las mismas 5). La pérdida de entrenamiento media:

La sigmoide va claramente rezagada (0.647 frente a ~0.40 en la época 100): su derivada (máx. 0.25) frena el gradiente. Al final del entrenamiento todas aciertan casi lo mismo en test; la diferencia es cuánto tardan en llegar. Neuronas ReLU «muertas»

Una neurona ReLU con \( z\le 0 \) devuelve 0 y su derivada es 0. Si eso ocurre para todos los datos, el gradiente que le llega es exactamente 0 y su peso no se actualiza nunca más: la neurona está muerta (dying ReLU): es como un crítico que ya no se entusiasma con ninguna película, siempre responde «0» y, como nadie le corrige cuando responde 0, nunca cambia de opinión. Suele pasar con un learning rate demasiado grande: un paso brusco empuja el sesgo y los pesos a un valor donde la neurona ya nunca se enciende. El fragmento 12 lo provoca con lr = 10:

  • Con lr = 0.1: casi ninguna neurona muerta (0 en 3 de 4 semillas) y ReLU y LeakyReLU dan resultados iguales.
  • Con lr = 10: ReLU deja inactivas 7 de 8 neuronas en las semillas 0 y 1 (en la 0 acaba con pérdida 1.044 y acierto 0.50: no aprende nada); LeakyReLU, con las mismas semillas, deja 3 o 4 inactivas y en dos de ellas (1 y 3) llega a pérdidas de 0.12 y acierto 0.96.
  • El gradiente de las filas de W1 de las neuronas ReLU inactivas vale exactamente 0; en LeakyReLU, aun inactivas, es pequeño pero no nulo (2·10⁻⁴, 4·10⁻⁴…). Esa rendija es lo que les permite «resucitar».
Regla fácil

Capas ocultas: empieza con ReLU. Si ves que muchas neuronas se apagan, prueba un learning rate menor o LeakyReLU. tanh y sigmoide en capas ocultas solo en redes muy pequeñas o por razones específicas. Sigmoide en la salida solo para clasificación binaria (y mejor como logit con BCEWithLogitsLoss).

Ojo

Estas comparaciones son de una red pequeña y unos datos concretos: no son una ley. En redes más grandes, con otros datos u otro optimizador, las diferencias cambian de tamaño. Lo que sí es general: la sigmoide/tanh satura; ReLU/LeakyReLU no satura en el lado positivo; y un learning rate mal elegido puede estropear cualquier combinación.

7 · Entrenar XOR de verdad: 2 neuronas ocultas frente a 4

Para qué sirve Entrenar la red 2-H-1 sobre XOR con el bucle completo, ver la «meseta» de la pérdida y contar en cuántas de 10 semillas distintas la red consigue resolverlo con H = 2 y con H = 4.

import torch
from torch import nn

X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = torch.tensor([[0.], [1.], [1.], [0.]])

def entrenar_xor(h, semilla, epocas=3000, lr=0.5, verbose=False):
    torch.manual_seed(semilla)
    modelo = nn.Sequential(nn.Linear(2, h), nn.Sigmoid(), nn.Linear(h, 1), nn.Sigmoid())
    criterio = nn.BCELoss()
    opt = torch.optim.SGD(modelo.parameters(), lr=lr)
    for epoca in range(epocas + 1):
        loss = criterio(modelo(X), y)
        if verbose and epoca in (0, 100, 500, 1000, 3000):
            print(f"  época {epoca:4d}  pérdida {loss.item():.4f}")
        opt.zero_grad()
        loss.backward()
        opt.step()
    p = modelo(X).detach()
    acc = ((p > 0.5).float() == y).float().mean().item()
    return loss.item(), acc, p.squeeze()

print("H = 2, semilla 1:")
_, _, p = entrenar_xor(2, 1, verbose=True)
print("  probabilidades:", p.numpy().round(3))

for h in (2, 4):
    aciertos = 0
    print(f"H = {h}")
    for semilla in range(10):
        loss, acc, _ = entrenar_xor(h, semilla)
        aciertos += acc == 1.0
        print(f"  semilla {semilla}: pérdida final {loss:.3f}  accuracy {acc:.2f}")
    print(f"  -> resuelve XOR en {aciertos} de 10 semillas")

11 · Comparar activaciones con los mismos datos y la misma semilla

Para qué sirve Entrenar la misma red con sigmoide, tanh, ReLU y LeakyReLU, con SGD, y comparar cómo baja la pérdida (media de 5 semillas).

import torch
from torch import nn
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split

X, y = make_moons(n_samples=400, noise=0.2, random_state=3)
X_ent, X_test, y_ent, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
X_ent, X_test = torch.tensor(X_ent, dtype=torch.float32), torch.tensor(X_test, dtype=torch.float32)
y_ent = torch.tensor(y_ent, dtype=torch.float32).view(-1, 1)
y_test = torch.tensor(y_test, dtype=torch.float32).view(-1, 1)

activaciones = {"sigmoide": nn.Sigmoid, "tanh": nn.Tanh, "ReLU": nn.ReLU,
                "LeakyReLU": lambda: nn.LeakyReLU(0.01)}

def entrenar(nombre, semilla, lr=0.1, epocas=800):
    torch.manual_seed(semilla)
    modelo = nn.Sequential(nn.Linear(2, 8), activaciones[nombre](), nn.Linear(8, 1))
    opt = torch.optim.SGD(modelo.parameters(), lr=lr)
    criterio = nn.BCEWithLogitsLoss()
    curva = []
    for epoca in range(epocas):
        loss = criterio(modelo(X_ent), y_ent)
        opt.zero_grad()
        loss.backward()
        opt.step()
        curva.append(loss.item())
    with torch.no_grad():
        acc = ((modelo(X_test) > 0).float() == y_test).float().mean().item()
    return curva, acc

print("pérdida de entrenamiento en las épocas 1, 100, 400 y 800 (media de 5 semillas)")
print("activación   ép.1   ép.100  ép.400  ép.800   acc test")
for nombre in activaciones:
    corridas = [entrenar(nombre, s) for s in range(5)]
    medias = [sum(c[0][e] for c in corridas) / 5 for e in (0, 99, 399, 799)]
    acc = sum(c[1] for c in corridas) / 5
    print(f"{nombre:10s}  " + "  ".join(f"{m:6.3f}" for m in medias) + f"   {acc:7.3f}")

12 · Neuronas ReLU «muertas»: contarlas y ver su gradiente

Para qué sirve Provocar neuronas muertas con un learning rate absurdo (10), contarlas, y comprobar que a una neurona ReLU apagada no le llega gradiente (exactamente 0) mientras que a una LeakyReLU sí le llega un hilo.

import torch
from torch import nn
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=400, noise=0.2, random_state=3)
Xt = torch.tensor(X, dtype=torch.float32)
yt = torch.tensor(y, dtype=torch.float32).view(-1, 1)

def entrenar(activacion, lr, semilla, h=8, epocas=300):
    torch.manual_seed(semilla)
    modelo = nn.Sequential(nn.Linear(2, h), activacion, nn.Linear(h, 1))
    opt = torch.optim.SGD(modelo.parameters(), lr=lr)
    criterio = nn.BCEWithLogitsLoss()
    for _ in range(epocas):
        loss = criterio(modelo(Xt), yt)
        opt.zero_grad()
        loss.backward()
        opt.step()
    with torch.no_grad():
        z = modelo[0](Xt)
        inactivas = (z <= 0).all(dim=0)
        acc = ((modelo(Xt) > 0).float() == yt).float().mean().item()
    return modelo, inactivas, loss.item(), acc

for lr in (0.1, 10.0):
    print(f"--- lr = {lr} ---")
    for nombre, act in (("ReLU", nn.ReLU()), ("LeakyReLU", nn.LeakyReLU(0.01))):
        print(nombre)
        for semilla in range(4):
            _, ina, loss, acc = entrenar(act, lr, semilla)
            print(f"  semilla {semilla}: neuronas inactivas {int(ina.sum())} de 8   pérdida {loss:.3f}   accuracy {acc:.2f}")

# Una neurona apagada no recibe gradiente: miramos el gradiente de cada fila de W1.
for nombre, act in (("ReLU", nn.ReLU()), ("LeakyReLU", nn.LeakyReLU(0.01))):
    modelo, ina, _, _ = entrenar(act, 10.0, 2)
    loss = nn.BCEWithLogitsLoss()(modelo(Xt), yt)
    modelo.zero_grad()
    loss.backward()
    print(f"{nombre}, lr = 10, semilla 2")
    print("  inactiva?          ", " ".join("sí" if v else "no" for v in ina.tolist()))
    print("  |gradiente| de W1  ", " ".join(f"{v:.0e}" for v in modelo[0].weight.grad.norm(dim=1).tolist()))
