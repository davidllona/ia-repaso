Dígitos: una red 64-16-10 de verdad

Hasta ahora los datos tenían 2 características y se podían dibujar. ¿Cómo se ve una red clasificando imágenes de dígitos escritos a mano, con 64 características?

Ojo · sobre MNIST y los datos de este módulo

El conjunto estándar del curso es MNIST: 60 000 imágenes de entrenamiento y 10 000 de test, de 28×28 píxeles. Se descarga con torchvision.datasets.MNIST, y esta web no puede ejecutar descargas, así que ese código aparece en el fragmento 18 marcado como no ejecutado (probamos a bajarlo y falló). Lo que sí se ejecuta aquí es el equivalente de scikit-learn: load_digits, 1797 imágenes de 8×8 píxeles (valores de 0 a 16) del mismo tipo de problema. Es un «MNIST en pequeñito»: misma idea, 64 píxeles en vez de 784, y entrena en segundos.

De una imagen a un vector

Una imagen de 8×8 es una cuadrícula de 64 números, como una mini-carátula en blanco y negro con 64 casillas. Una red con capas nn.Linear no ve «filas y columnas»: recibe un vector de 64 características, así que cada imagen se aplana (flatten) en una fila de 64 valores: es leer las casillas una detrás de otra, fila a fila, como se leen los subtítulos. (En load_digits ya viene aplanada; con imágenes (1, 28, 28) se usa nn.Flatten() o x.view(-1, 784). El módulo 3 enseña las convoluciones, que sí miran la forma 2D.)

  • IMAGEN 8×80…16 por píxel
  • ESCALAR /16valores entre 0 y 1
  • 64 → 16 (ReLU)16 «detectores»
  • 16 → 10un logit por dígito

Los pasos, con las cuentas

  1. Preparar los tensores. Entradas float32 escaladas a [0, 1] (dividir por 16); etiquetas long. Escalar ayuda: con entradas de 0 a 16 los pesos iniciales (pequeños) darían sumas \( z \) grandes y la activación saturaría.
  2. Separar entrenamiento y test (train_test_split, aquí 75 %/25 % con stratify=y): 1347 y 450 imágenes. Nunca se mide el acierto con los mismos datos con los que se entrena.
  3. Servir lotes con TensorDataset y DataLoader(batch_size=64, shuffle=True) (Curso 4, módulo 2). Con 1347 imágenes y lotes de 64 hay \( \lceil 1347/64 \rceil = 22 \) lotes por época (21 de 64 y uno final de 3, porque \( 21\cdot 64 = 1344 \)), es decir, 22 actualizaciones de los pesos por época.
  4. La red \( 64\text{-}16\text{-}10 \) con 1210 parámetros, ReLU en medio y logits a la salida.
  5. El bucle: dos for anidados (épocas y lotes) y los cinco pasos de siempre dentro. Después, el acierto en test con eval() y no_grad().

El fragmento 14 hace todo eso: la pérdida media de la época baja de 2.013 (época 1) a 0.052 (época 30), el acierto de entrenamiento llega a 99.3 % y el de test a 97.3 %: de las 450 imágenes de test falla 12.

14 · Dígitos de scikit-learn con una red 64-16-10 y DataLoader

Para qué sirve Entrenar la red de dígitos de todo el módulo: pasar los píxeles a tensores, separar entrenamiento y test, servir lotes con DataLoader, entrenar 30 épocas y medir el acierto en test.

import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

digitos = load_digits()
X = torch.tensor(digitos.data / 16.0, dtype=torch.float32)
y = torch.tensor(digitos.target, dtype=torch.long)
print("imágenes:", tuple(X.shape), "  valores entre", X.min().item(), "y", X.max().item())

X_ent, X_test, y_ent, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
print("entrenamiento:", len(X_ent), "  test:", len(X_test))
cargador = DataLoader(TensorDataset(X_ent, y_ent), batch_size=64, shuffle=True)

class Net(nn.Module):
    def __init__(self, d_in, h, d_out):
        super().__init__()
        self.linear1 = nn.Linear(d_in, h)
        self.linear2 = nn.Linear(h, d_out)

    def forward(self, x):
        x = torch.relu(self.linear1(x))
        return self.linear2(x)

torch.manual_seed(0)
modelo = Net(64, 16, 10)
print("parámetros:", sum(p.numel() for p in modelo.parameters()), "= 64*16 + 16 + 16*10 + 10")
criterio = nn.CrossEntropyLoss()
opt = torch.optim.Adam(modelo.parameters(), lr=0.01)

def accuracy(X, y):
    modelo.eval()
    with torch.no_grad():
        return (modelo(X).argmax(dim=1) == y).float().mean().item()

for epoca in range(1, 31):
    modelo.train()
    perdida_total = 0.0
    for lote_x, lote_y in cargador:
        loss = criterio(modelo(lote_x), lote_y)
        opt.zero_grad()
        loss.backward()
        opt.step()
        perdida_total += loss.item() * len(lote_x)
    if epoca in (1, 2, 5, 10, 20, 30):
        print(f"época {epoca:2d}  pérdida {perdida_total / len(X_ent):.3f}  "
              f"acc entrenamiento {accuracy(X_ent, y_ent):.3f}  acc test {accuracy(X_test, y_test):.3f}")

with torch.no_grad():
    pred = modelo(X_test).argmax(dim=1)
fallos = (pred != y_test).nonzero().squeeze().tolist()
print("imágenes de test mal clasificadas:", len(fallos), "de", len(X_test))
print("primeras 5 (real -> predicha):", [(y_test[i].item(), pred[i].item()) for i in fallos[:5]])

15 · Dígitos: neuronas ocultas y activaciones

Para qué sirve Repetir el entrenamiento de dígitos variando el tamaño de la capa oculta (con Adam) y la función de activación (con SGD), para ver cuánto importan en un problema real.

import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

digitos = load_digits()
X = torch.tensor(digitos.data / 16.0, dtype=torch.float32)
y = torch.tensor(digitos.target, dtype=torch.long)
X_ent, X_test, y_ent, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
cargador = DataLoader(TensorDataset(X_ent, y_ent), batch_size=64, shuffle=True)

def entrenar(h, activacion, epocas=30, lr=0.01, optimizador="adam", semilla=0):
    torch.manual_seed(semilla)
    modelo = nn.Sequential(nn.Linear(64, h), activacion, nn.Linear(h, 10))
    if optimizador == "adam":
        opt = torch.optim.Adam(modelo.parameters(), lr=lr)
    else:
        opt = torch.optim.SGD(modelo.parameters(), lr=lr)
    criterio = nn.CrossEntropyLoss()
    for _ in range(epocas):
        for lote_x, lote_y in cargador:
            loss = criterio(modelo(lote_x), lote_y)
            opt.zero_grad()
            loss.backward()
            opt.step()
    with torch.no_grad():
        acc = (modelo(X_test).argmax(dim=1) == y_test).float().mean().item()
        perdida = criterio(modelo(X_ent), y_ent).item()
    n = sum(p.numel() for p in modelo.parameters())
    return n, perdida, acc

print("Neuronas ocultas (ReLU, Adam, 30 épocas)")
print("   H  parámetros  pérdida ent.  acc test")
for h in (2, 4, 8, 16, 64, 256):
    n, perdida, acc = entrenar(h, nn.ReLU())
    print(f"{h:4d}  {n:9d}  {perdida:12.3f}  {acc:8.3f}")

print("Activación (H = 16, SGD con lr = 0.1, 30 épocas)")
print("activación   pérdida ent.  acc test")
for nombre, act in (("sigmoide", nn.Sigmoid()), ("tanh", nn.Tanh()),
                    ("ReLU", nn.ReLU()), ("LeakyReLU", nn.LeakyReLU(0.01))):
    n, perdida, acc = entrenar(16, act, lr=0.1, optimizador="sgd")
    print(f"{nombre:10s}  {perdida:12.3f}  {acc:8.3f}")

16 · Guardar y cargar una red con state_dict

Para qué sirve Guardar los parámetros de una red en un archivo, cargarlos en una red nueva con la misma arquitectura y ver el error si la arquitectura no coincide.

import os
import tempfile
import torch
from torch import nn

class Net(nn.Module):
    def __init__(self, d_in, h, d_out):
        super().__init__()
        self.linear1 = nn.Linear(d_in, h)
        self.linear2 = nn.Linear(h, d_out)

    def forward(self, x):
        return self.linear2(torch.tanh(self.linear1(x)))

torch.manual_seed(0)
original = Net(2, 4, 3)
x = torch.tensor([[0.3, -0.8], [1.0, 2.0]])

ruta = os.path.join(tempfile.mkdtemp(), "red.pt")
torch.save(original.state_dict(), ruta)
print("guardado:", os.path.basename(ruta), "-", os.path.getsize(ruta), "bytes")

torch.manual_seed(99)
copia = Net(2, 4, 3)
print("antes de cargar, ¿igual?  ", torch.allclose(original(x), copia(x)))
copia.load_state_dict(torch.load(ruta))
print("después de cargar, ¿igual?", torch.allclose(original(x), copia(x)))

otra = Net(2, 8, 3)
try:
    otra.load_state_dict(torch.load(ruta))
except RuntimeError as error:
    print("arquitectura distinta ->", str(error).splitlines()[1].strip())
